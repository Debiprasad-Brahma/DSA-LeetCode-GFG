# Intuition  
We are asked to count how many substrings of **length 3** contain **all distinct characters**.

Key points:
- Only substrings of size exactly `3` matter
- A substring is **good** if all three characters are different
- Since the window size is fixed, we don’t need any complex data structures

So for every index `i`, we just check the substring: s[i], s[i+1], s[i+2]
If none of them are equal, it’s a valid (good) substring.

---

# Approach  
1. Initialize a counter `count = 0`.
2. Traverse the string from index `0` to `length - 3`.
3. For each index `i`, check:
   - `s[i] != s[i+1]`
   - `s[i] != s[i+2]`
   - `s[i+1] != s[i+2]`
4. If all conditions are satisfied, increment `count`.
5. Return `count`.

---

# Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(1)

---

# Code
```java []
class Solution {

    public int countGoodSubstrings(String s) {
        int count = 0;
        for (int i = 0; i < s.length() - 2; i++) {
            char ch = s.charAt(i);

            // Just check all conditions
            // 1st with 2nd
            // 1st with 3rd
            // 2nd with 3rd
            if (ch == s.charAt(i + 1) || ch == s.charAt(i + 2) || s.charAt(i + 1) == s.charAt(i + 2)) {
                continue;
            } else {
                count++;
            }
        }
        return count;
    }
}

```
