## 🪟 LeetCode 1004 — Max Consecutive Ones III

### Intuition  
We are allowed to flip **at most `k` zeros** to ones.  
The goal is to find the **longest contiguous subarray** that contains at most `k` zeros.

Since the array contains only `0`s and `1`s, this becomes a classic **sliding window** problem:
- Expand the window to the right
- Keep track of how many zeros are inside the window
- Shrink the window from the left when zeros exceed `k`

---

### Approach  
1. Use two pointers `l` (left) and `r` (right) to represent the window.
2. Maintain a counter `zeros` for the number of zeros in the current window.
3. Expand the window by moving `r`:
   - If `nums[r] == 0`, increment `zeros`.
4. If `zeros > k`, shrink the window from the left:
   - If `nums[l] == 0`, decrement `zeros`.
   - Move `l` forward.
5. If `zeros <= k`, update the maximum window length.
6. Continue until the end of the array.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
  Each element enters and leaves the window at most once.
- **Space Complexity:** O(1)

---

### Code  
```java
class Solution {

    public int longestOnes(int[] nums, int k) {
        int n = nums.length;
        int l = 0, r = 0;
        int zeros = 0, maxLen = 0;

        while (r < n) {
            if (nums[r] == 0) zeros++;

            // Shrink window if zero count exceeds k
            if (zeros > k) {
                if (nums[l] == 0) zeros--;
                l++;
            }

            // Valid window
            if (zeros <= k) {
                maxLen = Math.max(maxLen, r - l + 1);
            }

            r++;
        }

        return maxLen;
    }
}
