# 🔥 Fruit Into Baskets | Sliding Window + HashMap O(N) | Longest Subarray with At Most 2 Distinct | Classic Interview Pattern

---

## 💡 Intuition

You have **2 baskets**, each holding only **one type** of fruit.  
Pick the longest contiguous stretch of trees using at most 2 fruit types.

> Key Insight: This is just **"Longest Subarray with At Most K=2 Distinct Elements"** in disguise — a textbook Sliding Window problem.

Think of it like a **conveyor belt** — expand right freely, but the moment a 3rd fruit type appears, shrink from the left until you're back to 2 types.

> 🎯 **The real power:** This exact template solves the general "At Most K Distinct" problem — just replace `3` with `k+1`.

---

## 🧠 Approach — Sliding Window + Frequency HashMap

1. Maintain window `[left, right]` and a `map` of `{fruitType → count}`.
2. **Expand:** Add `fruits[right]` to map, increment its count.
3. **Shrink:** While `map.size() >= 3` (more than 2 distinct types):
   - Decrement count of `fruits[left]`
   - If count hits `0` → remove from map entirely
   - Move `left++`
4. **Update:** `maxLen = max(maxLen, right - left + 1)`.
5. Return `maxLen`.

## 🧪 Edge Cases

```
fruits = [1]              →  1    (single tree)
fruits = [1,1,1,1]        →  4    (all same type)
fruits = [1,2,3,4]        →  2    (all different, window always size 2)
fruits = [0,1,2,2]        →  3    (subarray [1,2,2])
fruits = [1,2,1,2,1,2]    →  6    (only 2 types throughout)
```

## ✅ Code (Java)

```java
class Solution {
    public int totalFruit(int[] fruits) {
        int n = fruits.length;
        Map<Integer, Integer> map = new HashMap<>();
        int left = 0;
        int maxLen = 0;

        for (int right = 0; right < n; right++) {

            // Expand: add right fruit to window
            map.put(fruits[right], map.getOrDefault(fruits[right], 0) + 1);

            // Shrink: too many distinct types (> 2 baskets)
            while (map.size() >= 3) {
                int leftType = fruits[left];
                map.put(leftType, map.get(leftType) - 1);
                if (map.get(leftType) == 0) map.remove(leftType); // clean up 0-count keys
                left++;
            }

            // Valid window → update answer
            maxLen = Math.max(maxLen, right - left + 1);
        }

        return maxLen;
    }
}
```

---

## ⏱ Complexity Analysis

| | Complexity | Reason |
|---|---|---|
| **Time** | O(N) | Each element added and removed from map **at most once** |
| **Space** | O(1) | Map holds **at most 3 keys** at any point — effectively constant |

> 💡 Even though `while` is inside `for`, `left` only ever moves forward — total increments across the entire run = **N**. So it's truly O(N).

> 💡 Space is technically O(K) where K = distinct types allowed. Here K=2, so O(1).

---

## 🔑 Why `map.size() >= 3` and not `> 2`? 

```
Both are identical — 3 and above means more than 2 distinct types.
But >= 3 reads more naturally:

    "While we have 3 or more fruit types, shrink."

This also makes the general K template obvious:
    while (map.size() >= K + 1) → shrink
```

---

## 🔑 Why Remove Key When Count = 0?

```
If we don't remove zero-count keys:

    fruits = [1, 2, 3]
    After shrinking: map = {1:0, 2:1, 3:1}
    map.size() = 3 ← WRONG! We only have 2 active types

HashMap size counts ALL keys including stale zeros.
Removing them keeps map.size() = true distinct count ✅
```

## 🌐 General K Distinct Template (Must Know for Interviews)

```java
// "Longest subarray with at most K distinct elements"
// Fruit Into Baskets = this problem with K = 2

public int longestAtMostKDistinct(int[] arr, int k) {
    Map<Integer, Integer> map = new HashMap<>();
    int left = 0, maxLen = 0;

    for (int right = 0; right < arr.length; right++) {
        map.put(arr[right], map.getOrDefault(arr[right], 0) + 1);

        while (map.size() > k) {                         // 👈 only change
            int leftVal = arr[left];
            map.put(leftVal, map.get(leftVal) - 1);
            if (map.get(leftVal) == 0) map.remove(leftVal);
            left++;
        }

        maxLen = Math.max(maxLen, right - left + 1);
    }
    return maxLen;
}
// Fruit Into Baskets → call with k = 2  ✅
```

## 🚨 Common Mistakes to Avoid

```
❌  Not removing 0-count keys → map.size() gives wrong distinct count
❌  Using map.size() > 2 vs >= 3 — both work but know WHY they're equal
❌  Updating maxLen inside while loop → catches invalid windows
❌  Confusing "at most K" vs "exactly K" — different shrink conditions!
```

---

## 📌 Key Takeaways (Revision Flashcard)

- 🟡 **Fruit = fruit type, basket = distinct type** — map to "at most 2 distinct" instantly
- 🟡 **HashMap** tracks frequency; **size()** tracks distinct count
- 🟡 **Remove key at 0** — otherwise map.size() overcounts distinct types
- 🟡 **Update maxLen AFTER while** — guarantees valid window
- 🟡 **General template:** `while(map.size() > K)` → works for any K
- 🟡 Time: **O(N)** | Space: **O(1)**
