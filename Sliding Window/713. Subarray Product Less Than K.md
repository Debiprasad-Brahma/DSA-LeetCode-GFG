# Intuition
A brute-force approach would generate every possible subarray and calculate its product, but that would take too much time.

Since all numbers are positive, we can use a **sliding window**.

I maintain a window `[start...end]` whose product should be less than `k`.

As I move `end` to the right, I multiply `nums[end]` into the current product. If the product becomes `>= k`, I shrink the window from the left by dividing `nums[start]` and moving `start` forward.

Once the window becomes valid again, every subarray ending at `end` and starting anywhere between `start` and `end` is valid.

So the number of valid subarrays ending at `end` is:

`end - start + 1`

# Approach

1. If `k <= 1`, return `0`.
   - Since every `nums[i] >= 1`, no subarray can have a product strictly less than `k`.

2. Initialize:
   - `start = 0` → left boundary of the window
   - `prod = 1` → product of the current window
   - `ans = 0` → total number of valid subarrays

3. Move `end` from left to right:
   - Multiply `nums[end]` into `prod`.
   - If `prod >= k`, keep removing elements from the left until `prod < k`.

4. Once the window becomes valid:
   - There are `end - start + 1` valid subarrays ending at `end`.
   - Add this count to `ans`.

5. Return `ans`.

For example, if the current valid window is:

`[2, 5, 3]`

Then the valid subarrays ending at `3` are:

`[3]`, `[5, 3]`, `[2, 5, 3]`

So there are:

`3 - 0 + 1 = 3`

valid subarrays.

# Complexity

- Time complexity: $$O(n)$$
  - `end` moves from left to right once.
  - `start` also moves only from left to right, so every element is added and removed from the window at most once.

- Space complexity: $$O(1)$$
  - Only a few variables are used.

# Code
```java []
class Solution {
    public int numSubarrayProductLessThanK(int[] nums, int k) {
        if(k <= 1) return 0;
        int n = nums.length;

        int ans = 0;

        int start = 0;
        int prod = 1;
        for (int end = 0; end < n; end++) {
            prod *= nums[end];
            while (prod >= k) {
                prod = prod / nums[start];
                start++;
            }

            ans += end - start + 1;
        }

        return ans;
    }
}
```
