## 🪟 LeetCode 209 — Minimum Size Subarray Sum

### Intuition  
We need to find the **smallest length subarray** whose sum is **greater than or equal to `target`**.

A brute-force approach would check all subarrays, but that would be too slow.  
Since all numbers are **positive**, we can use a **sliding window** to efficiently expand and shrink the subarray.

Key observation:
- Expanding the window increases the sum
- Shrinking the window decreases the sum
- This allows us to adjust the window size greedily

---

### Approach  
1. Use two pointers:
   - `left` → start of the window
   - `right` → end of the window
2. Expand the window by moving `right` and adding `nums[right]` to `currSum`.
3. While `currSum >= target`:
   - Update the minimum length found so far
   - Shrink the window from the left
4. Continue until all elements are processed.
5. If no valid subarray is found, return `0`.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
  Each element is added and removed at most once.
- **Space Complexity:** O(1)

---

### Code  
```java
class Solution {

    public int minSubArrayLen(int target, int[] nums) {
        int n = nums.length;
        int left = 0;
        int currSum = 0;
        int minLen = Integer.MAX_VALUE;

        for (int right = 0; right < n; right++) {
            currSum += nums[right];

            // Shrink window while sum is sufficient
            while (currSum >= target) {
                minLen = Math.min(minLen, right - left + 1);
                currSum -= nums[left];
                left++;
            }
        }

        return minLen != Integer.MAX_VALUE ? minLen : 0;
    }
}
