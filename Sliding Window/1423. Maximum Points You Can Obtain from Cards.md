# 🧩 LeetCode 1423 — Maximum Points You Can Obtain from Cards

## 🧠 Intuition
We have a row of cards, each with certain points. You can take exactly **k cards** — either from the **front** or the **back** — to maximize your total score.  

The key observation is:
- Taking `k` cards from the ends is equivalent to **leaving (n - k)** cards somewhere in the middle.
- So instead of trying every combination, we can use a **sliding window** to track this efficiently.

However, an intuitive alternative (like in this solution) is to:
1. Take the first `k` cards from the start.
2. Then, gradually remove one card from the start and take one from the end — computing the total each time.
3. Keep track of the maximum sum obtained.

---

## 💡 Approach
1. Compute the sum of the first `k` cards → `lsum`.
2. Initialize `maxsum = lsum`.
3. Use two pointers:
   - Start from the **end** (`ridx = n - 1`).
   - For each step:
     - Remove one card from the left side (`lsum -= cardPoints[i]`).
     - Add one card from the right side (`rsum += cardPoints[ridx]`).
     - Update `maxsum = max(maxsum, lsum + rsum)`.
4. Continue until all possible left-right splits are considered.
5. Return `maxsum`.

---

## ⏱️ Complexity
### Time Complexity:
**O(k)** —  
We only iterate through `k` elements twice (once from the start, once from the end).

### Space Complexity:
**O(1)** —  
We use only constant extra space.

---

## 🧮 Code
```java
class Solution {

    public int maxScore(int[] cardPoints, int k) {
        int n = cardPoints.length;
        int lsum = 0, rsum = 0, maxsum = 0;

        // Take first k cards from the left
        for (int i = 0; i < k; i++) {
            lsum += cardPoints[i];
        }
        maxsum = lsum;

        int ridx = n - 1; // Start taking from right
        for (int i = k - 1; i >= 0; i--) {
            lsum -= cardPoints[i];    // Remove from left
            rsum += cardPoints[ridx]; // Add from right
            ridx--;
            maxsum = Math.max(maxsum, lsum + rsum);
        }

        return maxsum;
    }
}
