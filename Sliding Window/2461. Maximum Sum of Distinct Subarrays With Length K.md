## 🪟 LeetCode 2461 — Maximum Sum of Distinct Subarrays With Length K

### Intuition  
We need to find the **maximum sum of a subarray of length `k`** such that:
- All elements in the subarray are **distinct**

This naturally points to a **sliding window** approach with:
- A window of size at most `k`
- A data structure to ensure **uniqueness**

Key idea:
- Use a `HashSet` to track distinct elements in the current window
- Maintain the **sum of the current window**
- Slide the window while keeping elements unique

---

### Approach  
1. Use two pointers `i` (left) and `j` (right) to define the sliding window.
2. Use a `HashSet` to store elements currently in the window.
3. While adding `nums[j]`:
   - If `nums[j]` is already in the set:
     - Shrink the window from the left until it becomes unique again.
4. Add `nums[j]` to the window:
   - Update the running sum.
5. If the window size becomes exactly `k`:
   - Update the answer with the maximum sum so far.
   - Slide the window forward by removing `nums[i]`.
6. Continue until the array is fully processed.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
  Each element is added and removed from the set at most once.
- **Space Complexity:** O(k)  
  HashSet stores at most `k` elements.

---

### Code  
```java
class Solution {

    public long maximumSubarraySum(int[] nums, int k) {
        long ans = 0;
        long currWindow = 0;

        HashSet<Integer> set = new HashSet<>();

        int i = 0, j = 0;

        while (j < nums.length) {

            // Remove duplicates by shrinking from left
            while (set.contains(nums[j])) {
                currWindow -= nums[i];
                set.remove(nums[i]);
                i++;
            }

            // Add current element
            currWindow += nums[j];
            set.add(nums[j]);

            // Check window size
            if (j - i + 1 == k) {
                ans = Math.max(ans, currWindow);

                // Slide window
                currWindow -= nums[i];
                set.remove(nums[i]);
                i++;
            }

            j++;
        }

        return ans;
    }
}
