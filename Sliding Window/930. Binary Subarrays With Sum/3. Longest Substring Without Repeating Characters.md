# 🧠 LeetCode Solution — Longest Substring Without Repeating Characters (Java)

### Problem Link:
[LeetCode #3 — Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)

---

## 🧩 Intuition
The goal is to find the **length of the longest substring** that contains **no repeating characters**.

If we scan from left to right, whenever we find a duplicate character, we need to adjust our current substring window so that it contains only unique characters.

This hints towards using the **Sliding Window** technique — maintaining a window that expands and contracts dynamically based on character repetition.

---

## ⚙️ Approach
1. Use two pointers:  
   - `l` (left) → marks the start of the current substring  
   - `r` (right) → scans each character of the string  

2. Use a `HashSet` to store unique characters currently in the window.

3. For each character `c = s.charAt(r)`:
   - If `c` is **not** in the set:
     - Add it to the set.  
     - Update `maxLen = Math.max(maxLen, r - l + 1)`.  
     - Move `r` forward.
   - If `c` **is already** in the set:
     - Remove characters from the left (`l`) until `c` can be safely added again.

4. Continue until `r` reaches the end of the string.

This ensures that every substring we consider has **all unique characters**, and the length is efficiently updated in **O(n)** time.

---

## 💻 Code (Java)
```java
class Solution {
    public int lengthOfLongestSubstring(String s) {

        //define left right and maxLen
        int l = 0, r = 0, maxLen = 0;
        Set<Character> set = new HashSet<>(); // it doesn't contain duplicates

        while(r < s.length()){
            char c = s.charAt(r);
            if(!set.contains(c)){ // if doesn't contain the character then add the char and find length
                set.add(c);
                maxLen = Math.max(maxLen, r - l +1);
                r++;
            }
            else{
                set.remove(s.charAt(l)); // remove the character from that place 
                l++;
            }
        }
        return maxLen;
    }
}
