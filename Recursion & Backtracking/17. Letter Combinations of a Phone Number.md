# 🔥 Letter Combinations of a Phone Number — Complete Backtracking Guide

## 🧠 Intuition (Interview-Level Understanding)

This problem looks simple, but the key is to **recognize the pattern correctly**.

Each digit (2–9) maps to a set of characters:
- 2 → abc
- 3 → def
- ...

👉 So for every digit, we have **multiple choices**

Now think carefully:
If digits = "23"

- From '2' → choose (a, b, c)
- From '3' → choose (d, e, f)

👉 Final result = all combinations of choices  
This is called a **Cartesian Product**

So the problem becomes:
> "Pick one character from each digit and form all possible strings"

---

## 🔥 Core Idea

At every index:
- Take the current digit
- Try all its mapped characters
- Move to next index

👉 This forms a **decision tree**

---

## 🌳 Visualization (Very Important)

For digits = "23"

```
Level 0: ""
        /   |   \
       a    b    c
      /|\  /|\  /|\
     d e f d e f d e f
```

Final Output:
```

bd be bf
cd ce cf
```

👉 Every path from root → leaf is a valid answer

## 🚀 Approach (Step-by-Step)

1. Create mapping array (digit → letters)

2. Start recursion from index = 0

3. At each step:
   - Get current digit
   - Get corresponding letters
   - Loop through each letter:
       - Add it to current string
       - Move to next index

4. Base case:
   - When index == digits.length
   - Add current string to result

---

## ⚠️ Important Edge Case

If input is empty:
```
digits = ""
```

👉 Return empty list `[]`

Otherwise your code returns:
```
[""]
```
which is wrong.

## 💻 Optimized Code

```java
class Solution {

    void solve(ArrayList<String> ans, String curr, int index, String[] map, String digits) {
        // base case
        if (index >= digits.length()) {
            ans.add(curr);
            return;
        }

        int number = digits.charAt(index) - '0';
        String value = map[number];

        for (int i = 0; i < value.length(); i++) {
            curr += value.charAt(i);
            solve(ans, curr, index + 1, map, digits);
            curr = curr.substring(0, curr.length() - 1);
        }
    }

    public List<String> letterCombinations(String digits) {
        String[] phone_map = { "", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz" };
        ArrayList<String> ans = new ArrayList<>();
        int index = 0;
        String str = "";
        solve(ans, str, index, phone_map, digits);
        return ans;
    }
}

```
