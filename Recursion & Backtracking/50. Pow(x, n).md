# 💡 LeetCode Solution — Power Function (myPow)

## 🧠 Intuition
The goal is to calculate \( x^n \) (x raised to the power n).  
We can solve this recursively by understanding that:
\[
x^n = x \times x^{n-1}
\]
When \( n = 0 \), the result is always 1 (since any number raised to 0 equals 1).

---

## ⚙️ Approach
1. **Base Case:**  
   If `n == 0`, return `1` because any number to the power of 0 is 1.

2. **Recursive Case:**  
   Multiply `x` with the recursive call `myPow(x, n - 1)` to gradually reduce the power until it reaches 0.

3. **Limitation:**  
   - This solution only works correctly for positive `n`.  
   - For negative powers, additional logic (e.g., `1/x` and handling `-n`) would be required.

---

## ⏱️ Complexity Analysis
- **Time Complexity:** `O(n)` — Each recursive call decreases `n` by 1, leading to `n` total calls.
- **Space Complexity:** `O(n)` — Due to the recursion stack, as each call waits for the next one to complete.

---

## 🧩 Code
```java
class Solution {
    public double myPow(double x, int n) {
        if (n == 0) {
            return 1;
        }
        return (double)(x * myPow(x, n - 1));
    }
}
