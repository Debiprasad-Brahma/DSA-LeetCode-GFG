## 🧠 Problem Understanding
We need to find all possible combinations of:
- Exactly **k numbers**
- From range **1 to 9**
- Sum of those numbers must be **n**
- Each number can be used **only once**

---

## 🔍 Core Insight
This is a **combinatorial backtracking problem**:
- We try all possibilities
- But we **prune early** to avoid useless work

At every step:
👉 "Should I pick this number or skip it?"

---

## 🌳 Recursion Tree Thinking
Each level represents:
- Choosing next number

Example (k=3, n=7):

Start:
[]
 ├── 1 → [1]
 │    ├── 2 → [1,2]
 │    │    ├── 3 → [1,2,3] ❌ sum=6
 │    │    ├── 4 → [1,2,4] ✅ sum=7
 │
 ├── 2 → [2]
 │    ├── 3 → [2,3]
 │    │    ├── ...

👉 Only valid path: [1,2,4]

---

## 🚀 Approach (Step-by-Step)
1. Start from `1`
2. Try all numbers till `9`
3. Keep track of:
   - current sum
   - current length
4. Stop when:
   - length == k
5. If sum == n → store answer

---

## ⚡ Pruning (Most Important)
We avoid useless recursion:

if (sum + i > n) break;

👉 Why break?
Because numbers are increasing — future values will also fail.

---

## ❌ Common Mistake
DO NOT do this:
list.contains(i)

👉 Already handled by:
solve(i + 1, ...)

---

## ⏱ Complexity
Time: O(C(9, k))  
Space: O(k)

---

# Code
```java []
class Solution {

    void solve(int start, int length, int sum, ArrayList<Integer> list, List<List<Integer>> ans, int k, int n) {
        // base case
        if (length == k) {
            if (sum == n) {
                ans.add(new ArrayList<>(list));
            }
            return;
        }

        for (int i = start; i <= 9; i++) {
            if (sum + i > n) break;
            list.add(i);
            solve(i + 1, length + 1, sum + i, list, ans, k, n);

            // backtrack
            list.remove(list.size() - 1);
        }
    }

    public List<List<Integer>> combinationSum3(int k, int n) {
        List<List<Integer>> ans = new ArrayList<>();
        solve(1, 0, 0, new ArrayList<>(), ans, k, n);
        return ans;
    }
}

```

## 🔥 Key Takeaways
- Backtracking = explore + undo
- Pruning = performance boost
- i+1 = ensures uniqueness

"Pick → Explore → Backtrack → Repeat"
