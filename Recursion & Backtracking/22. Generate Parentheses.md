## 🧠 Problem Summary
Generate all combinations of **n pairs of valid parentheses**.

A valid parentheses string must:
- Never have more `)` than `(` at any point
- End with equal number of `(` and `)`

---

## 💡 Key Idea
At each step, we decide:
- Add `'('`
- Add `')'`

But with constraints:
- `open < n`
- `close < open`

---

## 🌳 Recursion Tree (n = 3)

```
""
├── "("
│   ├── "(("
│   │   ├── "((("
│   │   │   ├── "((()" 
│   │   │   │   ├── "((())"
│   │   │   │   │   ├── "((()))" ✅
```

---

## 🚀 Approach
1. Start with empty string
2. Track:
   - open brackets used
   - close brackets used
3. Apply rules:
   - Add '(' if open < n
   - Add ')' if close < open
4. Stop when length = 2*n

---

## 💻 Code
```java
class Solution {

    void solve(String curr, List<String> ans, int n, int open, int close) {
        // base case
        if (curr.length() == 2 * n) {
            ans.add(curr);
            return;
        }

        if (open < n) {
            curr += '(';
            solve(curr, ans, n, open + 1, close);
            curr = curr.substring(0, curr.length() - 1);
        }

        if (close < open) {
            curr += ')';
            solve(curr, ans, n, open, close + 1);
            curr = curr.substring(0, curr.length() - 1);
        }
    }

    public List<String> generateParenthesis(int n) {
        List<String> ans = new ArrayList<>();

        int open = 0;
        int close = 0;
        solve("", ans, n, open, close);

        return ans;
    }
}

```

---

## ⏱ Complexity
- Time: **O(2^n)** (Catalan number)
- Space: **O(n)** recursion depth

---

## 🧩 Example
Input:
```
n = 3
```

Output:
```
((()))
(()())
(())()
()(())
()()()
```

---

## ⚡ Why This Works
We **never generate invalid strings**:
- `close < open` prevents imbalance
- So no filtering needed later

---

👉 Backtracking + Constraint Pruning
