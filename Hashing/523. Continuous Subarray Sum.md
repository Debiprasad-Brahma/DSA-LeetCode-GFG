# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
A brute-force solution checking every subarray sum takes $O(N^2)$ time, which leads to a Time Limit Exceeded (TLE). 

By leveraging **Prefix Sums** and modulo arithmetic, we can solve this in linear time. The key property is:
> If two different prefix sums produce the **same remainder** when divided by $k$, then the sum of elements between those two indices is a **multiple of $k$**.

For example, if prefix sum $S_a \% k = r$ and prefix sum $S_b \% k = r$ (where $b > a$), then $(S_b - S_a) \% k = 0$.

# Approach
<!-- Describe your approach to solving the problem. -->
1. Use a **HashMap** to store mapping of `<remainder, earliest_index>`.
2. Initialize the map with `map.put(0, -1)` to naturally handle cases where a valid subarray starts from index `0`.
3. Track running `sum` as we iterate through the array:
   - Calculate `remainder = sum % k`.
   - **If remainder exists in map:** Check if the length of the subarray between current index `i` and the stored index is $\ge 2$ (`i - map.get(remainder) >= 2`). If so, return `true`.
   - **If remainder does NOT exist in map:** Store `map.put(remainder, i)`.
     *(Note: We only store the **first occurrence** of a remainder to maximize the distance `i - map.get(remainder)`).*
4. If no valid subarray is found after traversing the array, return `false`.

# Complexity
- Time complexity:
$$O(n)$$ — We perform a single pass through the array, doing $O(1)$ constant time lookup operations with the HashMap.

- Space complexity:
$$O(\min(n, k))$$ — In the worst-case scenario, the HashMap stores at most $O(n)$ unique remainders (or at most $k$ distinct remainders).

# Code
```java []
class Solution {

    public boolean checkSubarraySum(int[] nums, int k) {
        int n = nums.length;

        // map<Remainder, index>
        HashMap<Integer, Integer> map = new HashMap<>();
        map.put(0, -1);

        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += nums[i];

            int reminder = sum % k;
            if (map.containsKey(reminder)) {
                if (i - map.get(reminder) >= 2) return true;
            } else {
                map.put(reminder, i);
            }
        }

        return false;
    }
}
