## 🔗 LeetCode 2956 — Find Common Elements Between Two Arrays | ArrayList Approach

### 💡 Intuition
We need to find how many elements in each array are **present in the other array**.  
Specifically:
- `cnt1`: number of elements in `nums1` that appear in `nums2`.  
- `cnt2`: number of elements in `nums2` that appear in `nums1`.  

This can be achieved by converting both arrays into lists and using the `.contains()` method to check membership.

---

### 🧠 Approach
1. Convert both arrays `nums1` and `nums2` into `ArrayList`s for easier lookup.  
2. Initialize two counters:
   - `cnt1` → counts elements in `nums1` also in `nums2`
   - `cnt2` → counts elements in `nums2` also in `nums1`
3. Loop through both arrays separately:
   - For each element in `nums1`, check if it exists in `arr2`.
   - For each element in `nums2`, check if it exists in `arr1`.
4. Return the result as a new integer array `[cnt1, cnt2]`.

---

### ⏱️ Complexity
- **Time Complexity:** O(n × m) — because `.contains()` on an `ArrayList` takes O(n).  
  ⚠️ Can be improved to O(n + m) using a `HashSet`.
- **Space Complexity:** O(n + m) — for storing both arrays as lists.

---

### 💻 Code
```java
class Solution {
    public int[] findIntersectionValues(int[] nums1, int[] nums2) {
        ArrayList<Integer> arr1 = new ArrayList<>();
        ArrayList<Integer> arr2 = new ArrayList<>();

        for (int num : nums1)
            arr1.add(num);

        for (int num : nums2)
            arr2.add(num);

        int cnt1 = 0;
        int cnt2 = 0;

        for (int val : nums1) {
            if (arr2.contains(val)) cnt1++;
        }

        for (int val : nums2) {
            if (arr1.contains(val)) cnt2++;
        }

        return new int[]{cnt1, cnt2};
    }
}
