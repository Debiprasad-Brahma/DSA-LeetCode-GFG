## 1941. Check if All Characters Have Equal Number of Occurrences

### 💡 Intuition
We need to verify whether **all characters** in the given string appear the **same number of times**.  
To do this, we can use a **HashMap** to count the frequency of each character,  
then simply check if all frequencies are equal.

---

### 🧠 Approach
1. Create a `HashMap<Character, Integer>` to store character frequencies.  
2. Iterate through the string and count occurrences using `map.put(ch, map.getOrDefault(ch, 0) + 1)`.  
3. Retrieve all frequency values from the map and check:
   - Store the first frequency as `val1`.
   - For each subsequent frequency, if it’s not equal to `val1`, return `false`.
4. If all frequencies match, return `true`.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — iterate once over the string.  
- **Space Complexity:** O(1) — at most 26 characters (constant space).

---

### 💻 Code
```java
class Solution {
    public boolean areOccurrencesEqual(String s) {
        HashMap<Character, Integer> map = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            map.put(ch, map.getOrDefault(ch, 0) + 1);
        }

        int val1 = -1;
        for (int val2 : map.values()) {
            if (val1 == -1) val1 = val2;
            if (val2 != val1) return false;
        }
        return true;
    }
}
