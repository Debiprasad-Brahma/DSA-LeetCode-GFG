## ⚡ LeetCode 217 — Contains Duplicate | HashSet Approach

### 💡 Intuition
We need to determine whether any element appears **more than once** in the array.  
The simplest and most efficient way is to use a **HashSet**,  
since sets do **not allow duplicate elements**.

---

### 🧠 Approach
1. Initialize a `HashSet<Integer>` to store unique numbers.
2. Iterate through each element in the array:
   - Try to insert the number into the set using `set.add(num)`.
   - If `add()` returns `false`, it means the number already exists → duplicate found → return `true`.
3. If no duplicates are found after the loop, return `false`.

---

### ⏱️ Complexity
- **Time Complexity:** `O(n)` — each insertion and lookup in a HashSet is `O(1)` on average.  
- **Space Complexity:** `O(n)` — in the worst case, when all elements are unique.

---

### 💻 Code
```java
class Solution {

    public boolean containsDuplicate(int[] nums) {
        HashSet<Integer> set = new HashSet<>();

        for (int num : nums) {
            if (!set.add(num))  // add() returns false if num already exists
                return true;
        }
        return false;
    }
}
