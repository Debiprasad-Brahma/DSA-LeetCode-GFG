## 🤝 LeetCode 1512 — Number of Good Pairs | HashMap Frequency Formula Approach

### 💡 Intuition
We need to count the number of **good pairs** `(i, j)` such that:
> nums[i] == nums[j] and i < j.

If a number appears `val` times,  
the number of possible pairs it can form is given by the simple formula:

**pairs = val × (val - 1) / 2**

So, the problem reduces to counting how many times each number appears,  
and then applying this formula for each frequency.

---

### 🧠 Approach
1. Use a `HashMap<Integer, Integer>` to store how many times each number appears.  
2. Traverse the array, updating the frequency map.  
3. Initialize `cnt = 0` to store the total number of good pairs.  
4. For each frequency `val` in the map:
   - Add `val * (val - 1) / 2` to `cnt`.  
5. Return `cnt` as the result.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — one pass to count, one to compute pairs.  
- **Space Complexity:** O(n) — for storing frequencies in the map.

---

### 💻 Code
```java
class Solution {

    public int numIdenticalPairs(int[] nums) {
        int n = nums.length;
        HashMap<Integer, Integer> map = new HashMap<>();

        // Step 1: Count frequency of each number
        for (int i = 0; i < n; i++) {
            map.put(nums[i], map.getOrDefault(nums[i], 0) + 1);
        }

        // Step 2: Calculate total good pairs
        int cnt = 0;
        for (int val : map.values()) {
            cnt += (val * (val - 1)) / 2; // pairs = val × (val - 1) / 2
        }

        return cnt;
    }
}
