## 💫 LeetCode 1748 — Sum of Unique Elements | HashMap Counting Approach

### 💡 Intuition
We need to find the **sum of elements** that appear **exactly once** in the array.  
To achieve this, we can first count the frequency of each number using a `HashMap`,  
and then sum up all numbers whose frequency equals `1`.

---

### 🧠 Approach
1. Create a `HashMap<Integer, Integer>` to store frequencies of each number.  
   - The key represents the number.  
   - The value represents how many times it appears.
2. Iterate through the array:
   - Update frequency count using `map.put(num, map.getOrDefault(num, 0) + 1)`.
3. Initialize `sum = 0`.
4. Iterate through all map entries:
   - If a number’s frequency is `1`, add it to `sum`.
5. Return the final `sum`.

---

### ⏱️ Complexity
- **Time Complexity:** `O(n)` — each element is processed once for counting and once for summing.  
- **Space Complexity:** `O(n)` — for storing frequency counts in the map.

---

### 💻 Code
```java
class Solution {

    public int sumOfUnique(int[] nums) {
        HashMap<Integer, Integer> map = new HashMap<>();

        // Step 1: Count frequency of each number
        for (int i = 0; i < nums.length; i++) {
            map.put(nums[i], map.getOrDefault(nums[i], 0) + 1);
        }

        // Step 2: Add only unique numbers
        int sum = 0;
        for (int i : map.keySet()) {
            if (map.get(i) == 1)
                sum += i;
        }

        return sum;
    }
}
