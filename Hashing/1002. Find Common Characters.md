## 🔤 LeetCode 1002 — Find Common Characters | Frequency Intersection Approach

### 💡 Intuition  
We need to find characters that appear **in all words**, including duplicates.  
Example:  
`["bella","label","roller"]` → common = `["e","l","l"]`.

This is a **frequency intersection** problem:
- Count frequency of each character for the first word → **globalFreq**
- For every other word:
  - Count local frequency → **localFreq**
  - Update `globalFreq[ch] = min(globalFreq[ch], localFreq[ch])`

At the end, `globalFreq` contains the count of common characters across all words.

---

### 🧠 Approach  
1. Build a frequency map for the **first** word.  
2. For every additional word:
   - Build a local frequency map.
   - Reduce global frequency map using `min(global, local)` for each character.
3. Convert the final frequency map into the resulting list.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n * k)  
  - n = number of words  
  - k = average length of each word  
- **Space Complexity:** O(1)  
  - Bound by 26 characters (only lowercase letters)

---

### 💻 Code  
```java
class Solution {

    public List<String> commonChars(String[] words) {

        // Add the frequency for the first word
        HashMap<Character, Integer> globeFreq = new HashMap<>();
        for (char ch : words[0].toCharArray()) {
            globeFreq.put(ch, globeFreq.getOrDefault(ch, 0) + 1);
        }

        // For rest of the words
        int n = words.length;
        for (int i = 1; i < n; i++) {
            HashMap<Character, Integer> localFreq = new HashMap<>();

            for (char ch : words[i].toCharArray()) {
                localFreq.put(ch, localFreq.getOrDefault(ch, 0) + 1);
            }

            // Reduce global freq using minimum of both
            for (char ch : globeFreq.keySet()) {
                int gf = globeFreq.get(ch);
                int lf = localFreq.getOrDefault(ch, 0);
                globeFreq.put(ch, Math.min(gf, lf));
            }
        }

        ArrayList<String> ans = new ArrayList<>();

        for (char ch : globeFreq.keySet()) {
            int count = globeFreq.get(ch);
            for (int i = 0; i < count; i++) {
                ans.add(String.valueOf(ch));
            }
        }

        return ans;
    }
}
