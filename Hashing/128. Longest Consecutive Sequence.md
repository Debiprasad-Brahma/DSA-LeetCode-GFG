## 🔢 LeetCode 128 — Longest Consecutive Sequence

### Intuition  
We need to find the **length of the longest consecutive elements sequence** in an unsorted array.  
The key constraint is that the solution must run in **O(n)** time.

Important observation:
- If a number is the **start of a sequence**, then `num - 1` will **not** exist in the array.
- From such a starting number, we can keep checking `num + 1`, `num + 2`, … to count the length of the sequence.

Using a `HashSet` allows us to check existence in **O(1)** time.

---

### Approach  
1. Insert all elements of the array into a `HashSet` to allow fast lookups.
2. Iterate through each number in the set:
   - Only start counting if `num - 1` is **not** present (this ensures we start from the beginning of a sequence).
3. From that number, keep checking consecutive numbers (`num + 1`, `num + 2`, …).
4. Track the length of the current sequence.
5. Update the maximum sequence length found so far.
6. Return the maximum length.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
  Each number is visited at most twice.
- **Space Complexity:** O(n)  
  Extra space used by the `HashSet`.

---

### Code  
```java
class Solution {

    public int longestConsecutive(int[] nums) {
        HashSet<Integer> hs = new HashSet<>();

        // Store all elements in the set
        for (int num : nums) hs.add(num);

        int maxCount = 0;

        for (int num : hs) {
            // Check if this is the start of a sequence
            if (!hs.contains(num - 1)) {
                int currNum = num;
                int count = 1;

                // Count consecutive numbers
                while (hs.contains(currNum + 1)) {
                    currNum++;
                    count++;
                }

                maxCount = Math.max(maxCount, count);
            }
        }

        return maxCount;
    }
}
