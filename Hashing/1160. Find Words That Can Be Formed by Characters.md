## 🔤 LeetCode 1160 — Find Words That Can Be Formed by Characters

### Intuition  
You are given:
- An array of strings `words`
- A string `chars` containing available characters

A word is **good** if:
- Every character in the word exists in `chars`
- Each character is used **at most as many times** as it appears in `chars`

For every good word, you add its **length** to the final answer.

Key idea:
- Count the frequency of characters in `chars`
- For each word, check if it can be built using those frequencies **without reuse**

---

### Approach  

#### Step 1: Build base frequency map  
- Store the frequency of each character in `chars` using a HashMap

#### Step 2: Check each word  
- For every word:
  - Create a **fresh copy** of the base frequency map
  - Traverse characters of the word:
    - If a character is missing or its count is `0`, the word is invalid
    - Otherwise, decrement the count
  - If valid, add the word’s length to the answer

Using a fresh map for each word ensures one word does not affect another.

---

### Time & Space Complexity  
- **Time Complexity:** O(total characters in all words)  
- **Space Complexity:** O(1)  
  (At most 26 lowercase letters in the maps)

---

### Code  
```java
class Solution {

    private boolean goodString(String curr, Map<Character, Integer> map) {
        int n = curr.length();

        for (int i = 0; i < n; i++) {
            char ch = curr.charAt(i);

            // Character not available
            if (map.getOrDefault(ch, 0) <= 0) {
                return false;
            }

            // Use the character
            map.put(ch, map.get(ch) - 1);
        }

        return true;
    }

    public int countCharacters(String[] words, String chars) {
        Map<Character, Integer> baseMap = new HashMap<>();

        // Build frequency map for chars
        for (int i = 0; i < chars.length(); i++) {
            char ch = chars.charAt(i);
            baseMap.put(ch, baseMap.getOrDefault(ch, 0) + 1);
        }

        int ans = 0;

        // Check each word
        for (String curr : words) {
            Map<Character, Integer> map = new HashMap<>(baseMap);

            if (goodString(curr, map)) {
                ans += curr.length();
            }
        }

        return ans;
    }
}
