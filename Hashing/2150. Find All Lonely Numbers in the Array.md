## 🧍‍♂️ LeetCode 2150 — Find All Lonely Numbers in the Array | HashMap Frequency Check

### 💡 Intuition  
A number is considered **lonely** if:
1. It appears **exactly once** in the array, and  
2. **Neither** `num - 1` nor `num + 1` exists in the array.

So for each number, we need to know:
- How many times it appears
- Whether its adjacent values exist

A `HashMap` helps us efficiently track frequencies and existence.

---

### 🧠 Approach  
1. Build a frequency map using `HashMap<Integer, Integer>`.
2. Iterate over all unique numbers (keys of the map).
3. For each number `num`:
   - If `num - 1` exists → not lonely
   - If `num + 1` exists → not lonely
   - If frequency > 1 → not lonely
4. If none of the above conditions apply, add `num` to the result list.
5. Return the list of lonely numbers.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — one pass to build map, one pass to evaluate  
- **Space Complexity:** O(n) — for the frequency map

---

### 💻 Code  
```java
class Solution {

    public List<Integer> findLonely(int[] nums) {
        Map<Integer, Integer> map = new HashMap<>();

        // Count frequency of each number
        for (int num : nums) {
            map.put(num, map.getOrDefault(num, 0) + 1);
        }

        ArrayList<Integer> list = new ArrayList<>();

        // Check lonely condition
        for (int num : map.keySet()) {
            if (map.containsKey(num - 1) 
                || map.containsKey(num + 1) 
                || map.get(num) > 1) {
                continue;
            } else {
                list.add(num);
            }
        }

        return list;
    }
}
