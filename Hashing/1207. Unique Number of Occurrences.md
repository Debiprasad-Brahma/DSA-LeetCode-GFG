## 1207. Unique Number of Occurrences

### 💡 Intuition
We need to determine whether the **frequency of each number** in an array is **unique**.  
In other words, no two numbers should have the same occurrence count.

We can do this easily by:
1. Counting how many times each number appears.
2. Checking whether any frequency repeats.

---

### 🧠 Approach
1. Use a `HashMap<Integer, Integer>` to count the occurrences of each integer in the array.  
   - The key represents the number.  
   - The value represents how many times it appears.
2. Create a `List<Integer>` to store all unique frequencies.
3. For each frequency in the map:
   - If it’s already in the list → return `false` (duplicate frequency).  
   - Otherwise, add it to the list.
4. If all frequencies are unique, return `true`.

---

### ⏱️ Complexity
- **Time Complexity:** O(n²) — because `List.contains()` is O(n) and you call it for each frequency.  
  (For small arrays, this is fine, but it’s not optimal.)
- **Space Complexity:** O(n) — for the map and list.

💡 **Optimization Tip:**  
Use a `HashSet` instead of a `List` to reduce the complexity to O(n).

---

### 💻 Code
```java
class Solution {

    public boolean uniqueOccurrences(int[] arr) {
        int n = arr.length;

        HashMap<Integer, Integer> map = new HashMap<>();

        // Count frequency of each number
        for (int i = 0; i < n; i++) {
            map.put(arr[i], map.getOrDefault(arr[i], 0) + 1);
        }

        List<Integer> al = new ArrayList<>();

        // Check for duplicate frequencies
        for (int freq : map.values()) {
            if (al.contains(freq)) return false;
            al.add(freq);
        }

        return true;
    }
}
