## 🧍‍♂️ LeetCode 2418 — Sort the People | HashMap + TreeMap (Descending Order)

### 💡 Intuition  
Each person has a **name** and a corresponding **height**.  
We need to sort people in **descending order of height** and return the names in that order.

A clean way to do this:
- Map each `height → name`
- Use a `TreeMap` with **reverse order** to automatically sort by height (keys)
- Extract names from the sorted map

Since heights are **unique** (as per problem constraints), this approach is safe.

---

### 🧠 Approach  
1. Create a `HashMap<Integer, String>` to map each height to its name.
2. Insert all `(height, name)` pairs.
3. Create a `TreeMap` with `Collections.reverseOrder()` to sort heights in descending order.
4. Transfer all entries from the HashMap to the TreeMap.
5. Iterate over `sortedMap.values()` to build the result array.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n log n) — TreeMap insertion  
- **Space Complexity:** O(n) — HashMap + TreeMap

---

### 💻 Code  
```java
class Solution {

    public String[] sortPeople(String[] names, int[] heights) {
        HashMap<Integer, String> map = new HashMap<>();

        int n = heights.length;
        int i = 0;
        while (i < n) {
            map.put(heights[i], names[i]);
            i++;
        }

        // TreeMap to sort heights in descending order
        TreeMap<Integer, String> sortedMap =
                new TreeMap<>(Collections.reverseOrder());
        sortedMap.putAll(map);

        String[] ans = new String[n];
        i = 0;
        for (String name : sortedMap.values()) {
            ans[i++] = name;
        }

        return ans;
    }
}
