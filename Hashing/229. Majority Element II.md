# 🗳️ LeetCode 229 — Majority Element II | Frequency HashMap Approach

### 💡 Intuition  
We are asked to find all elements that appear **more than ⌊n / 3⌋ times** in the array.

Key observations:
- At most **two elements** can satisfy this condition.
- A simple and clear approach is to **count frequencies** of all elements and then filter those whose count exceeds `n / 3`.

Your solution uses a `HashMap` to track frequencies, which is perfectly valid and easy to understand.

---

# 🧠 Approach  
1. Traverse the array and store the frequency of each number in a `HashMap`.
2. Compute the required frequency threshold: reqFreq = n / 3
3. Iterate over the map:
- If `freq > reqFreq`, add the element to the answer list.
4. Return the list of majority elements.

---

# ⏱️ Complexity  
- **Time Complexity:** O(n) — one pass to build the map, one pass to filter  
- **Space Complexity:** O(n) — HashMap storing frequencies

---

# Code
```java []
class Solution {

    public List<Integer> majorityElement(int[] nums) {
        Map<Integer, Integer> freq = new HashMap<>();

        int n = nums.length;
        for (int i = 0; i < n; i++) {
            freq.put(nums[i], freq.getOrDefault(nums[i], 0) + 1);
        }

        int reqFreq = n / 3;

        ArrayList<Integer> ans = new ArrayList<>();
        for (int val : freq.keySet()) {
            if (freq.get(val) > reqFreq) ans.add(val);
        }

        return ans;
    }
}

```
