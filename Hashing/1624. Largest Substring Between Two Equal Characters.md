## 🔁 LeetCode 1624 — Largest Substring Between Two Equal Characters | HashMap First Occurrence

### 💡 Intuition  
We are asked to find the **maximum length of a substring** that lies **between two equal characters**.  
If no character appears at least twice, the answer should be `-1`.

Key idea:
- For each character, only the **first occurrence matters**.
- When the same character appears again at index `i`, the substring length between them is: (i - firstIndex - 1)
- Track the **maximum such distance**.

---

### 🧠 Approach  
1. Use a `HashMap<Character, Integer>` to store the **first index** of each character.
2. Traverse the string character by character:
 - If the character has appeared before:
   - Compute distance between current index and first occurrence (excluding both ends).
   - Update `maxDist`.
 - Else:
   - Store the current index as the first occurrence.
3. If no valid pair exists, `maxDist` remains `-1`.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — single pass through the string  
- **Space Complexity:** O(1) — at most 26 characters stored

---

### 💻 Code  
```java
class Solution {
  public int maxLengthBetweenEqualCharacters(String s) {
      Map<Character, Integer> map = new HashMap<>();
      int maxDist = -1;

      char[] ch = s.toCharArray();

      for (int i = 0; i < ch.length; i++) {
          char tempCh = ch[i];

          // If character already seen, calculate distance
          if (map.containsKey(tempCh)) {
              int firstIndex = map.get(tempCh);
              int dist = (i - firstIndex) - 1;
              maxDist = Math.max(dist, maxDist);
          } 
          // Store first occurrence only
          else {
              map.put(tempCh, i);
          }
      }
      return maxDist;
  }
}
