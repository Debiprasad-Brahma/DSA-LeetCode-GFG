## 🍬 LeetCode 575 — Distribute Candies | HashSet Approach

### 💡 Intuition
You are given an array `candyType` representing different types of candies.  
You must distribute all candies equally between two people — meaning one person gets **n / 2 candies**.

The goal is to **maximize the number of different candy types** one person can eat.  
Since each type can only be eaten once, the answer is simply:

> **min(unique_candy_types, n / 2)**

---

### 🧠 Approach
1. Use a `HashSet<Integer>` to store all **unique candy types**.  
   - The `HashSet` automatically ignores duplicates.
2. Compute how many candies one person can eat → `canEat = n / 2`.
3. Return the minimum of:
   - The number of **unique candy types** (`hs.size()`), and  
   - The **number of candies** one person can eat (`canEat`).

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — we iterate through the array once.  
- **Space Complexity:** O(n) — for the HashSet storing unique types.

---

### 💻 Code
```java
class Solution {

    public int distributeCandies(int[] candyType) {
        int n = candyType.length;
        int canEat = n / 2;
        HashSet<Integer> hs = new HashSet<>();

        for (int i = 0; i < n; i++) {
            hs.add(candyType[i]);
        }

        return Math.min(hs.size(), canEat);
    }
}
