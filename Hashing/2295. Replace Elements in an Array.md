# 💡 Intuition  
We are given an array `nums` and a list of operations.  
Each operation replaces **one value with another**: [oldValue, newValue]

The challenge is to update the array **efficiently**, because naïvely scanning the array each time would cost **O(n × operations)**.

A perfect solution:
- Use a **HashMap to track each value’s index** in `nums`.
- Whenever an operation occurs:
  - Look up the index of the old value in O(1)
  - Update the array at that index
  - Update the map accordingly

This makes every operation **constant time**, giving an overall optimal solution.

---

### 🧠 Approach  
1. Build a `HashMap<value, index>` from the initial array.
2. For each operation `[oldVal, newVal]`:
   - Retrieve index of `oldVal` from the map.
   - Replace `nums[index] = newVal`.
   - Update the map:
     - Remove `oldVal`
     - Store `newVal → index`
3. Return the modified array.

This ensures the right value always sits in the right place with O(1) lookup and update.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n + m)  
  - n = length of array  
  - m = number of operations  
- **Space Complexity:** O(n) — HashMap for element → index mapping

---

# Code
```java []
class Solution {

    public int[] arrayChange(int[] nums, int[][] operations) {
        int n = nums.length;

        HashMap<Integer, Integer> map = new HashMap<>();

        // Put the things in the map
        for (int i = 0; i < n; i++) {
            map.put(nums[i], i);
        }

        for(int [] opr : operations){
            int oldVal = opr[0];
            int newVal = opr[1];

            int index = map.get(oldVal); // get the index
            nums[index] = newVal; // add the new value at that index

            map.put(newVal, index); // put the new value at that index
            map.remove(oldVal);
        }

        return nums;
    }
}

```
