# Leet Code - 1653. Minimum Deletions to Make String Balanced
## 🧩 Minimum Deletions to Make String Balanced | Stack-Based Solution

### 🔍 Intuition
We need to make the string **balanced**, meaning all `'a'`s should appear **before** any `'b'`.  
If an `'a'` comes after a `'b'`, it creates an imbalance.  

To handle this, we can use a **stack**:
- Push each character while traversing.  
- If we see `'a'` after `'b'`, that means imbalance → we can delete one `'b'` (pop it) and increment the count.

---

### 💡 Approach
1. Initialize an empty stack and a counter `count = 0`.
2. Traverse each character in the string:
   - If the top of the stack is `'b'` and current char is `'a'`, pop `'b'` and increment `count`.
   - Else, push the current character.
3. After traversal, `count` gives the **minimum deletions** required.

---

### ⏱️ Complexity
- **Time Complexity:** O(n)  
- **Space Complexity:** O(n) — due to the stack

---

### 💻 Code
```java
class Solution {
    public int minimumDeletions(String s) {
        Stack<Character> stk = new Stack<>();
        int count = 0;

        for (char c : s.toCharArray()) {
            if (!stk.isEmpty() && stk.peek() == 'b' && c == 'a') {
                count++;
                stk.pop();
            } else stk.push(c);
        }
        return count;
    }
}
