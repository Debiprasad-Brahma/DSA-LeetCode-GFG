## ✂️ LeetCode 1249 — Minimum Remove to Make Valid Parentheses

### Intuition  
A string is valid if every opening parenthesis `'('` has a matching closing parenthesis `')'` in the correct order.  
To make the string valid with **minimum removals**, we should:
- Remove extra closing brackets `')'` that have no matching `'('`
- Remove extra opening brackets `'('` that are never closed

Using a stack helps us track unmatched opening brackets efficiently.

---

### Approach  
1. Traverse the string from left to right:
   - If the character is `'('`, store its index in the stack.
   - If the character is `')'`:
     - If the stack is empty, mark this index for removal.
     - Otherwise, pop one `'('` index from the stack (valid match).
2. After traversal, any indices left in the stack correspond to unmatched `'('`. Mark them for removal.
3. Build the final string by skipping all indices marked for removal.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(n)

---

### Code  
```java
class Solution {

    public String minRemoveToMakeValid(String s) {
        int n = s.length();
        boolean[] remove = new boolean[n];
        Stack<Integer> stk = new Stack<>();

        // First pass: identify invalid parentheses
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);

            if (ch == '(') {
                stk.push(i);
            } else if (ch == ')') {
                if (stk.isEmpty()) {
                    remove[i] = true; // unmatched ')'
                } else {
                    stk.pop(); // matched '('
                }
            }
        }

        // Remaining '(' in stack are unmatched
        while (!stk.isEmpty()) {
            remove[stk.pop()] = true;
        }

        // Build result string
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (!remove[i]) {
                sb.append(s.charAt(i));
            }
        }
        return sb.toString();
    }
}
