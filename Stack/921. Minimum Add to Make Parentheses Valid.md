## ➕ LeetCode 921 — Minimum Add to Make Parentheses Valid

### Intuition  
A parentheses string is valid if every opening bracket `'('` has a corresponding closing bracket `')'` and they are correctly ordered.  
By removing already valid pairs `"()"`, any remaining parentheses must be fixed by adding the minimum number of brackets.

---

### Approach  
1. Use a stack to track unmatched parentheses.
2. Traverse the string character by character:
   - If the current character is `')'` and the top of the stack is `'('`, pop the stack (a valid pair is formed).
   - Otherwise, push the current character onto the stack.
3. After processing the entire string, the number of unmatched parentheses left in the stack represents the minimum number of additions required.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(n)

---

### Code  
```java
class Solution {

    public int minAddToMakeValid(String s) {
        if (s.length() == 0) return 0;

        Stack<Character> stk = new Stack<>();

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);

            if (!stk.isEmpty() && ch == ')' && stk.peek() == '(') {
                stk.pop();
            } else {
                stk.push(ch);
            }
        }
        return stk.size();
    }
}
