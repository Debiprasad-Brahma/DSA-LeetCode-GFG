## 👀 LeetCode 1944 — Number of Visible People in a Queue

### Intuition  
Each person can see people **to their right** until someone taller (or equal height) blocks the view.

Rules:
- A person can see another person if **everyone between them is shorter**
- The first taller or equal-height person blocks further visibility

This naturally fits a **monotonic decreasing stack** approach.

---

### Approach  
1. Traverse the array from **right to left**.
2. Use a stack to keep heights in **decreasing order**.
3. For each person:
   - Pop all shorter people from the stack:
     - Each popped person is visible.
   - If the stack is not empty after popping:
     - The next taller/equal person is also visible.
4. Push the current height onto the stack.
5. Store counts in the result array.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
  Each person is pushed and popped once.
- **Space Complexity:** O(n)

---

### Code  
```java
class Solution {

    public int[] canSeePersonsCount(int[] heights) {
        int n = heights.length;
        Stack<Integer> stk = new Stack<>();
        int[] res = new int[n];

        for (int i = n - 1; i >= 0; i--) {

            // Pop all shorter people
            while (!stk.isEmpty() && stk.peek() < heights[i]) {
                res[i]++;
                stk.pop();
            }

            // First taller or equal person (if exists)
            if (!stk.isEmpty()) {
                res[i]++;
            }

            stk.push(heights[i]);
        }

        return res;
    }
}
