## 🔤 LeetCode 316 — Remove Duplicate Letters

### Intuition  
The goal is to remove duplicate letters so that:
- Every character appears **exactly once**
- The resulting string is **lexicographically smallest**
- The relative order of characters from the original string is preserved

So we are not just removing duplicates — we are choosing the **best possible order**.

Key observations:
- If a character appears again later, we can safely remove its earlier occurrence
- If a larger character appears before a smaller one and the larger one occurs again later, removing it helps make the string smaller lexicographically

---

### Approach  
1. Store the **last index** of every character in the string.
2. Use a boolean array `taken[]` to track which characters are already included.
3. Use a `StringBuilder` as a stack-like structure to build the result.
4. Traverse the string:
   - If the character is already taken, skip it.
   - Otherwise, while:
     - The result is not empty
     - The last character in the result is **greater than the current character**
     - The last character appears again later  
     → remove the last character from the result and mark it as not taken.
5. Add the current character and mark it as taken.
6. Return the final string.

This ensures:
- Each character appears once
- The result is lexicographically smallest

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
  Each character is added and removed at most once.
- **Space Complexity:** O(1)  
  Only fixed-size arrays (26 letters) are used.

---

### Code  
```java
class Solution {

    public String removeDuplicateLetters(String s) {
        int n = s.length();

        int[] lastIdx = new int[26];
        boolean[] taken = new boolean[26];
        StringBuilder res = new StringBuilder();

        // Store last occurrence of each character
        for (int i = 0; i < n; i++) {
            lastIdx[s.charAt(i) - 'a'] = i;
        }

        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            int idx = ch - 'a';

            // Skip if already used
            if (taken[idx]) continue;

            // Remove larger characters that appear later
            while (res.length() > 0) {
                char lastChar = res.charAt(res.length() - 1);
                if (lastChar > ch && lastIdx[lastChar - 'a'] > i) {
                    taken[lastChar - 'a'] = false;
                    res.deleteCharAt(res.length() - 1);
                } else {
                    break;
                }
            }

            res.append(ch);
            taken[idx] = true;
        }

        return res.toString();
    }
}
