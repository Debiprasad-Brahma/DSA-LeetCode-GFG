# Intuition  
Each car moves toward the target at its own speed.  
If a faster car starts behind a slower car, it **cannot overtake** it. Instead, it forms a **fleet** and both cars reach the target together.

So the key idea is:
- Cars that take **longer or equal time** to reach the target will merge with the car in front.
- Cars that take **strictly more time** form a new fleet.

---

# Approach  
1. Combine `position` and `speed` into a single array so each car is treated as a pair.
2. Sort cars by **starting position in descending order** (closest to the target first).
3. Traverse cars in that order and compute the **time required** to reach the target: time = (target - position) / speed

4. Use a stack to track fleet times:
- If the stack is empty, push the time.
- If the current car’s time is **greater than the time at the top of the stack**, it forms a new fleet → push it.
- Otherwise, it merges with the fleet ahead (do nothing).
5. The number of fleets equals the stack size.

---

# Time & Space Complexity  
- **Time Complexity:** O(n log n)  
Sorting dominates the runtime.
- **Space Complexity:** O(n)  
Stack usage.

---


# Code
```java []
class Solution {

    public int carFleet(int target, int[] position, int[] speed) {
        int n = position.length;
        int[][] cars = new int[n][2];

        for (int i = 0; i < n; i++) {
            cars[i][0] = position[i];
            cars[i][1] = speed[i];
        }

        Arrays.sort(cars, (a, b) -> b[0] - a[0]);

        Stack<Double> stk = new Stack<>();
        for (int[] car : cars) {
            double timeTaken = (double) (target - car[0]) / car[1];

            if (stk.isEmpty() || timeTaken > stk.peek()) {
                stk.push(timeTaken);
            }
        }
        return stk.size();
    }
}

```
