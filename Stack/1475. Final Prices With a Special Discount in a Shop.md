## 🛒 LeetCode 1475 — Final Prices With a Special Discount  
### Monotonic Stack (Next Smaller or Equal Element)

### 💡 Intuition  
For every item, we want to apply a **discount equal to the price of the first item to its right** that is **less than or equal to it**.

Brute force would be:
- For each index `i`, scan to the right until you find a smaller/equal price  
This works, but it’s **O(n²)** and too slow.

Instead, we can process prices **in one pass** using a **monotonic stack**.

---

### 🧠 Thought Process (How a human would reason)  
- As we move from left to right, we don’t yet know the discount for an item.
- But the moment we see a **smaller or equal price**, it becomes the discount for **all previous prices that were waiting for a discount**.
- A stack helps us remember the indices of items that haven’t found their discount yet.

So:
- Keep indices in a stack
- Maintain the stack such that prices are in **increasing order**
- When a smaller price comes, apply discount immediately

---

### 🧩 Approach  
1. Use a stack to store **indices** of prices.
2. Traverse the array from left to right:
   - While stack is not empty **and**
     ```
     prices[stack.peek()] >= prices[i]
     ```
     → apply discount  
     ```
     prices[stack.pop()] -= prices[i]
     ```
3. Push current index to the stack.
4. Items left in the stack don’t get any discount.
5. Return the modified prices array.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n)  
  - Each index is pushed and popped at most once
- **Space Complexity:** O(n)  
  - Stack in the worst case

---

### 💻 Code  
```java
class Solution {

    public int[] finalPrices(int[] prices) {
        int n = prices.length;
        Stack<Integer> stk = new Stack<>();

        for (int i = 0; i < n; i++) {
            // Apply discount to previous prices if possible
            while (!stk.isEmpty() && prices[stk.peek()] >= prices[i]) {
                prices[stk.pop()] -= prices[i];
            }
            // Current price waits for its discount
            stk.push(i);
        }
        return prices;
    }
}
