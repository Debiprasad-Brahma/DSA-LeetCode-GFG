# Next Greater Element II – Circular Array

## Problem Overview
Given a circular integer array `nums`, for each element, find the **next greater element**.  
The next greater element of a number `x` is the first number greater than `x` when traversing the array clockwise.  
If no greater number exists, return `-1` for that position.


---

## Intuition
For a **non-circular array**, the monotonic stack approach is optimal for finding the next greater element in O(n) time.  
In a **circular array**, elements at the end must also check elements at the beginning.  
We can simulate the circular nature by iterating through the array **twice** (`2n` iterations), effectively unrolling the circle into a linear sequence.

---

## Approach
1. **Initialization**  
   - Create an array `ans` of size `n`, initialized with `-1` (default answer when no greater element exists).
   - Create an empty stack to store **indices** of elements.

2. **Traverse in reverse order from `2n-1` to `0`**  
   - Use `i % n` to wrap around the array and simulate circular traversal.
   - **Pop from stack** while the current element is greater or equal to the element at the top of the stack (those popped can’t be the next greater for future elements).
   - If `i < n` (meaning we're in the first pass for real indices), update `ans[i]` with the value at the top of the stack if the stack isn't empty.
   - **Push the current index** onto the stack.

3. **Return `ans`** as the result.

---

## Complexity Analysis
- **Time Complexity:** O(n)  
  Each index is pushed and popped from the stack at most once, and we make `2n` iterations.
- **Space Complexity:** O(n)  
  Stack can hold at most `n` indices.

---

## Dry Run Example
Input: `nums = [1, 2, 1]`

| Iteration | i   | nums[i % n] | Stack (top→bottom) | ans            |
|-----------|-----|-------------|--------------------|----------------|
| Start     |     |             | []                 | [-1, -1, -1]   |
| i=5       | 5%3=2 → 1 | []→push 2   | [2]                | [-1, -1, -1]   |
| i=4       | 4%3=1 → 2 | pop(2)      | []→push 1          | [-1, -1, -1]   |
| i=3       | 3%3=0 → 1 | push 0      | [0,1]              | [-1, -1, -1]   |
| i=2       | 2%3=2 → 1 | pop(0)      | [1]                | [-1, -1, 2]    |
| i=1       | 1%3=1 → 2 | push 1      | [1,1]              | [-1, -1, 2]    |
| i=0       | 0%3=0 → 1 | top=2       | push 0             | [2, -1, 2]     |

Output: `[2, -1, 2]`

## Code
```java
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        Arrays.fill(ans, -1);
        
        Stack<Integer> stk = new Stack<>();
        
        for (int i = 2 * n - 1; i >= 0; i--) {
            while (!stk.isEmpty() && nums[stk.peek()] <= nums[i % n]) {
                stk.pop();
            }
            if (i < n) {
                ans[i] = stk.isEmpty() ? -1 : nums[stk.peek()];
            }
            stk.push(i % n);
        }
        
        return ans;
    }
}

class Solution {
    public ArrayList<Integer> nextLargerElement(int[] arr) {
        int n = arr.length;
        int[] res = new int[n];
        Stack<Integer> stk = new Stack<>();
        
        for (int i = n * 2 - 1; i >= 0; i--) {
            while (!stk.isEmpty() && arr[stk.peek()] <= arr[i % n]) {
                stk.pop();
            }
            if (i < n) {
                res[i] = stk.isEmpty() ? -1 : arr[stk.peek()];
            }
            stk.push(i % n);
        }
        
        ArrayList<Integer> ans = new ArrayList<>();
        for (int val : res) ans.add(val);
        return ans;
    }
}
