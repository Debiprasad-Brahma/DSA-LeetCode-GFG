## 🔗 LeetCode 32 — Longest Valid Parentheses  
### Stack + Index Gap Method

---

### Intuition  
A valid parentheses substring must be **continuous** and correctly matched.  
Instead of directly building valid substrings, we can take a reverse idea:

> **Find the indices that break validity**, then compute the maximum gap between them.

If we know all the indices that **cannot** be part of a valid parentheses sequence,  
the longest valid substring will lie **between those indices**.

---

### Key Idea  
- Use a stack to store **indices of unmatched parentheses**
- Matched pairs `()` cancel each other out
- At the end:
  - The stack contains indices that break valid substrings
  - The longest valid substring is the **maximum distance between consecutive invalid indices**

---

### Approach  

#### Step 1: Build stack of invalid indices
- Traverse the string
- If current char is `')'` and top of stack is `'('`, pop (valid pair)
- Otherwise, push the index
- After traversal, stack contains indices of unmatched parentheses

#### Step 2: Handle edge cases
- If stack size == `n` → no valid substring → return `0`
- If stack is empty → whole string is valid → return `n`

#### Step 3: Compute maximum valid length
- Valid substrings exist **between invalid indices**
- Compute:
  - From last invalid index to end
  - Between consecutive invalid indices
  - From start to first invalid index

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(n)

---

### Code  
```java
class Solution {

    public int longestValidParentheses(String s) {
        int n = s.length();
        Stack<Integer> stk = new Stack<>();

        // Store indices of unmatched parentheses
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            if (ch == ')' && !stk.isEmpty() && s.charAt(stk.peek()) == '(') {
                stk.pop();
            } else {
                stk.push(i);
            }
        }

        // If all indices are invalid
        if (stk.size() == n) return 0;

        // If entire string is valid
        if (stk.isEmpty()) return n;

        int ans = 0;

        // Distance from last invalid index to end
        ans = n - stk.peek() - 1;

        // Distance between invalid indices
        while (!stk.isEmpty()) {
            if (stk.size() == 1) {
                ans = Math.max(ans, stk.pop());
                return ans;
            }
            ans = Math.max(ans, stk.pop() - stk.peek() - 1);
        }

        return ans;
    }
}
