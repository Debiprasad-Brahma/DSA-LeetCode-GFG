# Intuition
We are given a sequence of log operations that simulate navigating between folders.  
- `"./"` means stay in the current folder (do nothing).  
- `"../"` means go one step back (move up to the parent folder).  
- Any other string like `"x/"` means move into a new child folder.  

We want to find the minimum number of steps required to go back to the main folder (root) after processing all the logs.

---

# Approach
1. Use a **stack** to keep track of the folder path.  
   - Push folder names when we go inside (`"x/"`).  
   - Pop from stack when `"../"` is encountered (only if not empty).  
   - Ignore `"./"` as it means stay in the same folder.  
2. Maintain a counter (`count`) to track the current depth.  
   - Increment when we go deeper.  
   - Decrement when we go back.  
3. After processing all operations, `count` (or stack size) will give the depth, which is the minimum number of steps to return to the root.

---

# Complexity
- **Time Complexity:**  
  We loop through all logs once → **O(n)**  

- **Space Complexity:**  
  In the worst case, all operations are folder entries, so the stack stores all of them → **O(n)**  

---

# Code
```java []
class Solution {

    public int minOperations(String[] logs) {
        int n = logs.length;
        Stack<String> stk = new Stack<>();
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (logs[i].equals("../")) {
                if (!stk.isEmpty()) { // check for it
                    stk.pop();
                    count--;
                }
            } else if (!logs[i].equals("../") && !logs[i].equals("./")) {
                stk.push(logs[i]);
                count++;
            }
        }
        return count;
    }
}

```
