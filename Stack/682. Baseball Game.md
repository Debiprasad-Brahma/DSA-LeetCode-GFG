# 📘 Baseball Game – Explanation

### 🔹 Intuition
We are given some operations about a game:
- A number → add it to the score.
- `"C"` → remove the last score.
- `"D"` → double the last score and add.
- `"+"` → add the sum of the last two scores.

We just need to **simulate the game step by step** while keeping track of all valid scores.  
A **stack** is perfect here because:
- It stores scores in order.
- We can easily add/remove/peek recent scores.

---

### 🔹 Approach
1. Create a stack to keep scores.  
2. Loop through each operation:
   - If it’s a number → convert to integer and push.  
   - If `"C"` → remove the last score using `pop()`.  
   - If `"D"` → double the last score (`peek * 2`) and push.  
   - If `"+"` → take the last two scores, sum them, and push.  
3. At the end, sum all elements in the stack → this is the answer.  

---

### 🔹 Complexity
- **Time Complexity:**  
  Each operation is processed once → **O(n)**  
  (where `n` = number of operations).  

- **Space Complexity:**  
  Stack stores scores → at most **O(n)**.  

---

### 🔹 Code (Java)

```java
class Solution {

    public int calPoints(String[] operations) {
        int n = operations.length;
        Stack<Integer> stk = new Stack<>();

        for (int i = 0; i < n; i++) {
            // If equals to nothing that means a number
            if(!operations[i].equals("+") && !operations[i].equals("C") && !operations[i].equals("D")){
                int num = Integer.parseInt(operations[i]);
                stk.push(num);
            }
            else if(operations[i].equals("C")){
                stk.pop();
            }
            else if(operations[i].equals("D")){
                int num1 = stk.peek();
                stk.push(num1*2);
            }
            else if(operations[i].equals("+")){
                int num2 = stk.pop(); // pop first one
                int num3 = stk.peek(); // store curr peek
                stk.push(num2); // push the poped one 
                stk.push(num2+num3); // push the addition
            }
        }

        int ans = 0;
        while(!stk.isEmpty()){
            ans += stk.pop();
        }

        return ans;
    }
}
