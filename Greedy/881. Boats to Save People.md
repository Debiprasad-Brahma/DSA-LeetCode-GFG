## ⛵ LeetCode 881 — Boats to Save People | Two-Pointer Greedy Pairing

### 💡 Intuition  
Each boat can carry **at most 2 people** and their total weight must not exceed `limit`.

To **minimize the number of boats**, pair:
- The **heaviest person** with the **lightest person** whenever possible.
- If the heaviest cannot pair with the lightest, they must go alone.

This leads naturally to a **two-pointer greedy** strategy after sorting.

---

### 🧠 Approach  
1. Sort the `people` array.  
2. Use two pointers:
   - `i` → lightest person  
   - `j` → heaviest person  
3. While `i <= j`:
   - If the lightest + heaviest fit in one boat → pair them → `i++`, `j--`
   - Otherwise, the heaviest goes alone → `j--`
   - In both cases, a boat is used → `count++`
4. Return `count` as the minimum number of boats needed.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n log n) — sorting step  
- **Space Complexity:** O(1) — only two pointers and counters

---

### 💻 Code  
```java
class Solution {
    public int numRescueBoats(int[] people, int limit){ 
        Arrays.sort(people);
        int n = people.length;
        int i = 0;
        int j = n - 1;
        int count = 0;

        while (i <= j) {
            if (people[i] + people[j] <= limit) {
                count++;
                i++;
                j--;
            } else {
                count++;
                j--;
            }
        }
        return count;
    }
}
