## 🍬 LeetCode 135 — Candy | Two-Pass Greedy Approach

### 💡 Intuition  
Each child must receive:
1. **At least one candy**, and  
2. More candies than neighbors if their rating is higher.

This is a classic greedy problem solved elegantly using **two passes**:
- Left-to-right scan to enforce left-side constraints  
- Right-to-left scan to enforce right-side constraints

Because each direction may increase a child's candy count, we take the **maximum required** from both passes.

---

### 🧠 Approach  
1. Create an array `candies[n]` and fill with `1` (minimum each child must get).
2. **Left-to-right pass:**
   - If `ratings[i] > ratings[i-1]`, child `i` gets `candies[i-1] + 1`.
3. **Right-to-left pass:**
   - If `ratings[i] > ratings[i+1]`, child `i` gets  
     `max(candies[i], candies[i+1] + 1)`  
     (max ensures both left and right constraints are satisfied).
4. Sum all candies and return the result.

This ensures correctness with minimal candies.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — two linear passes  
- **Space Complexity:** O(n) — to store candy distribution

---

### 💻 Code  
```java
class Solution {

    public int candy(int[] ratings) {
        int n = ratings.length;
        int[] candies = new int[n];
        Arrays.fill(candies, 1);

        // Left check
        for (int i = 1; i < n; i++) {
            if (ratings[i] > ratings[i - 1]) {
                candies[i] = candies[i - 1] + 1;
            }
        }

        // Right check
        for (int i = n - 2; i >= 0; i--) {
            if (ratings[i] > ratings[i + 1]) {
                candies[i] = Math.max(candies[i], candies[i + 1] + 1);
            }
        }

        // Count total
        int minCan = 0;
        for (int can : candies) minCan += can;

        return minCan;
    }
}
