## ⚙️ LeetCode 2244 — Minimum Rounds to Complete All Tasks | Greedy Frequency Grouping

### 💡 Intuition  
Each task has a difficulty value.  
You can only complete tasks in rounds of size **2** or **3**, and all tasks in a round must have the **same difficulty**.

So for every difficulty value:
- Count how many times it occurs.
- Convert that count into the **minimum number of rounds** using only 2s and 3s.

Key rule:
- If frequency = **1**, it's impossible → return `-1`
- Otherwise, the minimum rounds needed for frequency `f` is: (f + 2) / 3

This formula is derived because:
- We prefer groups of **3**, since they reduce total rounds.
- If f % 3 = 1 or 2, using one 2-sized group works.

---

### 🧠 Approach  
1. Sort the tasks.
2. Count consecutive frequencies and store them in a list.
3. For each frequency:
 - If it is 1 → return -1 (cannot form group of 2 or 3)
 - Otherwise use formula `(f + 2) / 3` to compute rounds
4. Sum all rounds and return the result.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n log n) — sorting  
- **Space Complexity:** O(n) — list storing frequencies  
(Can be reduced to O(1) using a map, but logic is same)

---

### 💻 Code  
```java
class Solution {

  public int minimumRounds(int[] tasks) {
      if (tasks.length == 1) return -1; // Only one task cannot be grouped

      int n = tasks.length;
      Arrays.sort(tasks);

      ArrayList<Integer> al = new ArrayList<>();
      int count = 1;

      // Count frequencies of each task difficulty
      for (int i = 1; i < n; i++) {
          if (tasks[i] != tasks[i - 1]) {
              al.add(count);
              count = 1;
          } else {
              count++;
          }
      }

      // Add frequency of last group
      al.add(count);

      // Convert frequencies to number of rounds
      count = 0;
      for (int num : al) {
          if (num == 1) return -1; // Impossible case

          count += (num + 2) / 3; // Greedy grouping into 3's
      }

      return count;
  }
}
