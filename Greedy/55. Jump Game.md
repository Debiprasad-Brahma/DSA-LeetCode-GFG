## 🏃 LeetCode 55 — Jump Game | Greedy Maximum Reach Approach

### 💡 Intuition  
The goal is to check whether we can reach the **last index** starting from index **0**,  
given that each element `nums[i]` tells you the **maximum jump length** from that position.

A greedy idea works beautifully:
- Track the **maximum index** we can reach at any point (`maxLen`).
- If we ever reach an index `i` that is **beyond** `maxLen`, it means we are stuck → return `false`.
- Otherwise, keep updating `maxLen = max(maxLen, i + nums[i])`.

If the loop completes, it means we never got stuck → return `true`.

---

### 🧠 Approach  
1. Initialize `maxLen = 0` → the farthest we can reach so far.
2. Loop through all indices:
   - If `i > maxLen`, we cannot jump to this index → return `false`.
   - Update reachability: `maxLen = Math.max(maxLen, i + nums[i])`.
3. If loop ends, the last index is reachable → return `true`.

This works because we only need to ensure each index we land on is accessible.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — one linear pass.  
- **Space Complexity:** O(1) — constant additional variables.

---

### 💻 Code  
```java
class Solution {

    public boolean canJump(int[] nums) {
        int maxLen = 0;

        for (int i = 0; i < nums.length; i++) {
            if (i > maxLen) return false;
            maxLen = Math.max(maxLen, i + nums[i]);
        }

        return true;
    }
}
