## 🍋 LeetCode 860 — Lemonade Change | Greedy Cash Management

### 💡 Intuition  
You are selling lemonade for **$5**.  
Customers pay using **$5, $10, or $20** bills, and you must return the correct change using the bills you have received so far.

A greedy approach works perfectly:
- Always give change using the **largest bill combination** possible.
- This preserves smaller bills ($5) for future transactions.

---

### 🧠 Approach  
Maintain two counters:
- `five` → number of $5 bills  
- `ten` → number of $10 bills  

Process each bill one-by-one:

#### Case 1: Customer pays **$5**
- No change needed → just increment `five`

#### Case 2: Customer pays **$10**
- Must give one $5 as change  
- If no $5 available → return false

#### Case 3: Customer pays **$20**
- Best option: give change as **$10 + $5** (preserves $5 bills)
- If not possible: give **three $5 bills**
- If neither possible → return false

If all transactions complete successfully → return `true`.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — iterate through each bill once  
- **Space Complexity:** O(1) — constant counters only

---

### 💻 Code  
```java
class Solution {
    public boolean lemonadeChange(int[] bills) {
        int five = 0, ten = 0;

        for (int bill : bills) {

            if (bill == 5) {
                five++;
            } 
            else if (bill == 10) {
                if (five <= 0) return false;
                five--;
                ten++;
            } 
            else { // bill == 20
                if (ten > 0 && five > 0) {
                    ten--;
                    five--;
                } 
                else if (five >= 3) {
                    five -= 3;
                } 
                else {
                    return false;
                }
            }
        }
        return true;
    }
}
