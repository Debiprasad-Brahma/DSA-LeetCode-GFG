💡 Intuition  
We are given a palindrome string and must change **exactly one character** so that:
- The resulting string is **not a palindrome**
- And it is **lexicographically smallest**

Key observations:
1. The best way to make the string lexicographically smaller is to replace a character with `'a'`.
2. We only need to search the **first half** of the palindrome because changing a mirrored character in the second half gives the same effect.
3. If the entire first half is `'a'`, then replacing any character with `'a'` changes nothing.  
   → In this case, the only option is to change the **last character** to `'b'`.

If the string length is 1, it is impossible to form a non-palindrome → return `""`.

---

### 🧠 Approach  
1. If length = 1 → return `""`.
2. Convert the string to a char array.
3. Iterate through the **first half**:
   - If a character is **not 'a'**, replace it with `'a'` → return the result.
4. If the loop completes, all first-half characters were `'a'`:
   - Replace the **last character** with `'b'`
   - Return the result.

This ensures the smallest lexicographical outcome.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — single pass through half the string  
- **Space Complexity:** O(n) — due to creating a modified char array
