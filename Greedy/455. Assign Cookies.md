## 🍪 LeetCode 455 — Assign Cookies | Greedy Two-Pointer Approach

### 💡 Intuition  
Each child has a **greed factor** (minimum cookie size required).  
Each cookie has a **size**.  
A child is satisfied if they receive a cookie with size **≥ greed factor**.

To maximize satisfied children:
- Give the **smallest possible cookie** that can satisfy each child.
- Sort both arrays and use a two-pointer greedy approach.

---

### 🧠 Greedy Approach  
1. Sort `g` (greed factors) and `s` (cookie sizes).  
2. Use two pointers:
   - `i` → tracks current child  
   - `j` → tracks current cookie  
3. While both pointers are in range:
   - If cookie `s[j]` satisfies child `g[i]`, increment `i` and `cnt`.  
   - Always move `j` (try next cookie).  
4. Return `cnt`, the number of satisfied children.

This ensures the smallest available cookie that can satisfy a child is used.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n log n + m log m)** — due to sorting.  
- **Space Complexity:** O(1) — aside from sorting, no extra space used.

---

### 💻 Code  
```java
class Solution {

    public int findContentChildren(int[] g, int[] s) {
        Arrays.sort(g);
        Arrays.sort(s);

        int i = 0, j = 0;
        int cnt = 0;

        while (i < g.length && j < s.length) {
            if (s[j] >= g[i]) {
                i++;
                cnt++;
            }
            j++;
        }

        return cnt;
    }
}
