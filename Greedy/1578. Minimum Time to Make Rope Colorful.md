## 🎨 LeetCode 1578 — Minimum Time to Make Rope Colorful | Greedy Group Compression

### 💡 Intuition  
We have a rope represented by colors, and removing a balloon takes some time.  
The rule is:

> **For every group of consecutive balloons of the same color, keep exactly one — the one with maximum needed time — and remove the rest.**

So for each such group:
- You want to **minimize total removal time**.
- The optimal strategy is:
  - Track the **maximum** time in the group.
  - Add the sum of all smaller times to the answer.

This ensures the balloon kept is the most expensive one, and you remove all cheaper ones.

---

### 🧠 Approach  
Use a greedy linear scan:

1. Maintain:
   - `prevMax` → largest removal time in the current color group  
   - `time` → total removal time  

2. For each balloon:
   - If it's a **new color group**, reset `prevMax` to 0.
   - Compare `curr` with `prevMax`:
     - You must remove the smaller one → add `min(prevMax, curr)`  
     - The larger one stays as the `prevMax` for the group.

3. Continue until the end.

This naturally removes all but the highest-valued balloon in every color segment.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(1)

---

### 💻 Code  
```java
class Solution {
    public int minCost(String colors, int[] neededTime) {
        int n = neededTime.length;
        int time = 0;
        int prevMax = 0;

        for (int i = 0; i < n; i++) {

            // New color group → reset
            if (i > 0 && colors.charAt(i) != colors.charAt(i - 1)) {
                prevMax = 0;
            }

            int curr = neededTime[i];

            // Remove the smaller one in the group
            time += Math.min(prevMax, curr);

            // Keep track of the one we keep
            prevMax = Math.max(prevMax, curr);
        }

        return time;
    }
}
