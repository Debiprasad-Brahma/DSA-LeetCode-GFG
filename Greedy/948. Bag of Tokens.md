## 🎮 LeetCode 948 — Bag of Tokens | Two-Pointer Greedy Strategy

### 💡 Intuition  
You have tokens with certain power costs.  
You can play tokens in **two ways**:

1. **Face Up**  
   - Spend `power` to gain **+1 score**  
   - Use this when you have enough power.

2. **Face Down**  
   - Lose **1 score** to gain power back  
   - Use this when you don't have enough power to play a token face up  
     but you still have unused large tokens.

The goal is to **maximize score**.

A **two-pointer greedy approach** works best:
- Use the **smallest tokens** to gain score cheaply.
- When stuck, trade score for power using your **largest token**.

---

### 🧠 Approach  
1. Sort the tokens.
2. Use two pointers:
   - `i` → smallest token (for face up)  
   - `j` → largest token (for face down)
3. While tokens remain:
   - If you can afford `tokens[i]`, use **face up**:
     - `power -= tokens[i]`  
     - `score++`  
     - Update `maxScore`
     - Move `i++`
   - Else if you have score to sacrifice, use **face down**:
     - `power += tokens[j]`  
     - `score--`  
     - Move `j--`
   - Else break (cannot play anymore)

Finally, return `maxScore`.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n log n) — sorting  
- **Space Complexity:** O(1) — two-pointer approach

---

### 💻 Code  
```java
class Solution {

    public int bagOfTokensScore(int[] tokens, int power) {
        int n = tokens.length;
        Arrays.sort(tokens);

        int i = 0, j = n - 1;
        int score = 0, maxScore = 0;

        while (i <= j) {

            // Play face up: gain score
            if (power >= tokens[i]) {
                power -= tokens[i++];
                score++;
                maxScore = Math.max(maxScore, score);
            }

            // Play face down: regain power
            else if (score > 0) {
                power += tokens[j--];
                score--;
            }

            // Cannot play any move
            else {
                break;
            }
        }

        return maxScore;
    }
}
