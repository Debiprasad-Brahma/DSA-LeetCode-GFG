# 26. Remove Duplicates from Sorted Array�

### 🔍 Intuition
The array is **sorted**, so all duplicates are adjacent.  
We can use **two pointers** to efficiently overwrite duplicate values and keep only unique elements.

- One pointer (`i`) tracks the **position of the last unique element**.
- The other pointer (`j`) explores the array for new unique values.

Whenever a new unique element is found, we move it next to the last unique element.

---

### 💡 Approach
1. Initialize two pointers:  
   - `i = 0` (points to the last unique element)  
   - `j = 0` (used to traverse the array)
2. Traverse the array using `j`:
   - If `arr[j]` is different from `arr[i]`, it means we found a new unique element.
   - Increment `i` and copy `arr[j]` to `arr[i]`.
3. Continue until the end of the array.
4. The count of unique elements will be `i + 1`.

---

### ⏱️ Complexity
| Type | Complexity |
|------|-------------|
| **Time Complexity** | O(n) |
| **Space Complexity** | O(1) — done in-place |

---

### 💻 Code
```java
class Solution {
    public int removeDuplicates(int[] arr) {
        int n = arr.length;

        int i = 0;
        int j = 0;

        while (i < n && j < n) {
            if (arr[i] != arr[j]) {
                arr[i + 1] = arr[j];
                i++;
            }
            j++;
        }
        return i + 1;
    }
}
