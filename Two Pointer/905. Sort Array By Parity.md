# ⚖️ LeetCode 905 — Sort Array by Parity

### 🧠 Intuition
We need to rearrange an array so that **all even numbers come before all odd numbers**.  
The **relative order doesn’t matter**, so an **in-place two-pointer approach** works efficiently.

---

### 💡 Approach
1. Initialize two pointers:
   - `left` at the start of the array.
   - `right` at the end of the array.
2. Move `left` forward while it points to an even number.  
3. Move `right` backward while it points to an odd number.  
4. When both pointers are at misplaced elements (odd on left and even on right), **swap them**.  
5. Continue until `left` crosses `right`.
6. Return the modified array.

---

### ⏱️ Complexity
- **Time Complexity:** `O(n)` — Each element is checked at most once.  
- **Space Complexity:** `O(1)` — In-place rearrangement without extra space.

---

### ✅ Code
```java
class Solution {
    public int[] sortArrayByParity(int[] arr) {
        int left = 0;
        int right = arr.length - 1;

        while (left < right) {
            // Move left if element is even
            if (left < right && arr[left] % 2 == 0) {
                left++;
            }
            // Move right if element is odd
            else if (left < right && arr[right] % 2 != 0) {
                right--;
            }
            // Swap misplaced even/odd
            else {
                int temp = arr[left];
                arr[left] = arr[right];
                arr[right] = temp;
                left++;
                right--;
            }
        }
        return arr;
    }
}
