## 💧 LeetCode 11 — Container With Most Water | Two-Pointer Approach

### 💡 Intuition
You are given an array `height[]`, where each element represents the height of a vertical line on the x-axis.  
We need to find two lines that, together with the x-axis, form a container holding the **maximum amount of water**.

The **area** between two lines is determined by:
> `Area = min(height[left], height[right]) × (right - left)`

To maximize area, we use a **two-pointer approach** starting from both ends and move inward strategically.

---

### 🧠 Approach
1. Initialize two pointers:
   - `left = 0` (start of array)
   - `right = height.length - 1` (end of array)
2. Calculate the current area:
   - `width = right - left`
   - `h = min(height[left], height[right])`
   - `area = h × width`
3. Update `maxarea` if `area` is larger.
4. Move the pointer pointing to the **smaller height** inward:
   - If `height[left] < height[right]`, move `left++`
   - Else, move `right--`
   - Because moving the smaller height might help find a taller line.
5. Continue until both pointers meet.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — each pointer moves at most once.  
- **Space Complexity:** O(1) — only a few variables used.

---

### 💻 Code
```java
class Solution {

    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxarea = 0;

        while (left <= right) {
            int width = right - left;
            int h = Math.min(height[left], height[right]);
            int area = h * width;

            maxarea = Math.max(maxarea, area);

            if (height[left] > height[right]) 
                right--; 
            else 
                left++;
        }
        return maxarea;
    }
}
