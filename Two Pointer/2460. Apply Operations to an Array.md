# Leet Code -:  2460. Apply Operations to an Array
---
# 🔍 Intuition
We are given an array `nums` and need to perform two tasks:
1. If two consecutive elements are equal, **double the first one** and **set the second to 0**.
2. After performing step 1 across the array, **move all zeros to the end** while keeping the order of non-zero elements.

This can be efficiently solved in **two passes** using the **two-pointer technique**.

---

# 💡 Approach
#### Step 1️⃣: Apply the operations
- Traverse the array from left to right.
- If `nums[i] == nums[i+1]`,  
  - Set `nums[i] = 2 * nums[i]`
  - Set `nums[i+1] = 0`

#### Step 2️⃣: Move all zeros to the end
- Use two pointers `i` and `j`:
  - `i` points to a possible zero.
  - `j` searches ahead for a non-zero to swap.
- Swap when `nums[i] == 0` and `nums[j] != 0`.
- Move both pointers forward based on conditions.

---

# ⏱️ Complexity
| Type | Complexity |
|------|-------------|
| **Time Complexity** | O(n) |
| **Space Complexity** | O(1) — done in-place |

--- 

# Code
```java []
class Solution {

    void swap(int []nums, int i, int j){
        int num1 = nums[i];
        int num2 = nums[j];

        nums[i] = num2;
        nums[j] = num1;
    }
    public int[] applyOperations(int[] nums) {
        int n = nums.length;

        int i = 0;
        int j = i+1;

        // Do the first task
        while(i < n && j < n){
            if(nums[i] == nums[j]){
                nums[i] = 2 * nums[i];
                nums[j] = 0;
            }
            i++;
            j++;
        }

        // Now we have to move zeros to end
        i = 0;
        j = i+1;

        while(i < n && j < n){
            // [0, 4] -> in this situation swap
            if(nums[i] == 0 && nums[j] != 0){
                swap(nums, i, j);
                i++;
                j++;
            }
            // [0(i), 0(j), 5] -> just move j
            else if(nums[i] == 0 && nums[j] == 0){
                j++;
            }
            // [5(i), 6(j), 0 ,6] -> move both i and j
            else if(nums[i] != 0 && nums[j] != 0){
                i++;
                j++;
            }
            // [5(i), 0(j), 6] -> move both i and j
            else{
                i++;
                j++;
            }
        }
        return nums;
    }
}
```
