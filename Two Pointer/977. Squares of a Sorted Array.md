# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
Since the array is sorted, the largest absolute values—and therefore the largest squares—will always sit at the extreme ends (either the most negative numbers on the far left or the largest positive numbers on the far right). Instead of squaring and then sorting ($O(N \log N)$), we can use **two pointers** to compare both ends and place the larger square into the result array from back to front ($O(N)$).

# Approach
<!-- Describe your approach to solving the problem. -->
1. Create a result array `ans` of the same size $N$ and set an index pointer `idx = n - 1` to fill it from right to left (largest to smallest).
2. Use two pointers: `start = 0` (left end) and `end = n - 1` (right end).
3. At each step, compare `nums[start]^2` and `nums[end]^2`:
   - If `sq2 >= sq1`, place `sq2` at `ans[idx]` and move the `end` pointer left (`end--`).
   - Otherwise, place `sq1` at `ans[idx]` and move the `start` pointer right (`start++`).
4. Decrement `idx` and repeat until all elements are placed.

# Complexity
- Time complexity:
$$O(n)$$ — We process each element exactly once with our two pointers converging toward the middle.

- Space complexity:
$$O(1)$$ — Ignoring the memory allocated for the output array `ans`, we only use constant extra memory for pointer variables.

# Code
```java []
class Solution {

    public int[] sortedSquares(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];

        int start = 0;
        int end = n - 1;

        int idx = n - 1;

        while (idx >= 0 && start <= end) {
            int sq1 = nums[start] * nums[start];
            int sq2 = nums[end] * nums[end];

            if (sq2 >= sq1) {
                ans[idx] = sq2;
                end--;
            } else {
                ans[idx] = sq1;
                start++;
            }
            idx--;
        }

        return ans;
    }
}
