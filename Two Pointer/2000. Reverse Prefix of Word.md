## 🔁 LeetCode 2000 — Reverse Prefix of Word | Two-Pointer String Reversal

### 💡 Intuition
We are asked to reverse the **prefix** of a given string up to the **first occurrence** of a specific character `ch`.  
If `ch` is not found in the string, return the original word unchanged.  

This can be efficiently done by converting the string into a character array and using a **two-pointer swap** until the target character’s index.

---

### 🧠 Approach
1. Find the index of the first occurrence of `ch` using `word.indexOf(ch)`.  
   - If it doesn’t exist (`index == -1`), simply return the original word.
2. Convert the string to a character array (`char[] arr`) for in-place swapping.
3. Use two pointers:
   - `i = 0` (start of prefix)
   - `j = index` (first occurrence of `ch`)
4. Swap characters at `i` and `j` while moving inward (`i++`, `j--`).
5. After reversing, convert the array back to a string and return it.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — single pass to find `ch`, another to reverse prefix.  
- **Space Complexity:** O(n) — character array used to modify string (strings in Java are immutable).

---

### 💻 Code
```java
class Solution {

    public String reversePrefix(String word, char ch) {
        int i = 0;
        int j = word.indexOf(ch);
        if (j == -1) return word;

        char[] arr = word.toCharArray();

        while (i <= j) {
            char temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;

            i++;
            j--;
        }

        return new String(arr);
    }
}
