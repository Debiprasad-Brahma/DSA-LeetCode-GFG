# 🏔️ Longest Mountain in Array (Java Solution)

## Problem
Given an array of integers `arr`, a **mountain** is defined as a sequence that:
1. Strictly increases to a peak,  
2. Then strictly decreases,  
3. And has a length of at least 3.  

The task is to return the length of the **longest mountain** in the array.

---

## 💡 Intuition
To identify a mountain, we must:
- First, locate a **peak** (an element greater than both of its neighbors).  
- Then, **expand left** to include the strictly increasing sequence.  
- Next, **expand right** to include the strictly decreasing sequence.  
- Keep track of the maximum length found.

---

## 🚀 Approach
1. Iterate through the array starting from index `1` to `arr.length - 2`.  
2. For each element, check if it is a **peak**:  
   `arr[i] > arr[i - 1] && arr[i] > arr[i + 1]`  
3. If it’s a peak:
   - Expand **left** while `arr[left] > arr[left - 1]`.  
   - Expand **right** while `arr[right] > arr[right + 1]`.  
4. Compute the mountain length as `right - left + 1`.  
5. Update the answer with the maximum length found.  
6. Return the result.  

---

## ⏱️ Complexity
- **Time Complexity:** `O(n)`  
  - Each element is visited at most twice (during expansion).  
- **Space Complexity:** `O(1)`  
  - Only a few variables are used, no extra data structures.

---

## 📝 Code
```java
class Solution {

    public int longestMountain(int[] arr) {
        int ans = 0;
        int count = 0;

        if (arr.length >= 3) {
            for (int i = 1; i < arr.length - 1; i++) {
                // Peak condition: strictly greater than both neighbors
                if (arr[i] > arr[i - 1] && arr[i] > arr[i + 1]) {
                    // expand left
                    int left = i - 1;
                    while (left > 0 && arr[left] > arr[left - 1]) {
                        left--;
                    }

                    // expand right
                    int right = i + 1;
                    while (right < arr.length - 1 && arr[right] > arr[right + 1]) {
                        right++;
                    }

                    count = right - left + 1;
                    ans = Math.max(ans, count);
                }
            }
        }

        return ans;
    }
}
