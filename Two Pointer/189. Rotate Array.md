## 🔁 189. Rotate Array 💡

### 🔍 Intuition
To rotate an array by `k` steps to the right, we can think of the array as two parts.  
Instead of moving each element one by one, we can **reverse sections of the array** to achieve rotation efficiently.

The key idea:
1. Reverse the **whole array**.
2. Reverse the **first k elements**.
3. Reverse the **remaining n - k elements**.

This rearranges the array as if it has been rotated `k` times to the right.

---

### 💡 Approach
1. Calculate `k = k % n` to handle cases where `k > n`.
2. Reverse the entire array.
3. Reverse the first `k` elements.
4. Reverse the remaining `n - k` elements.
5. The array will now be rotated correctly.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — each element is reversed at most twice  
- **Space Complexity:** O(1) — in-place reversal, no extra space used  

---

### 💻 Code
```java
class Solution {
    public void rotate(int[] arr, int k) {
        int n = arr.length;
        k = k % n;
        
        reverse(arr, 0, n - 1);
        reverse(arr, 0, k - 1);
        reverse(arr, k, n - 1);
    }

    void reverse(int[] arr, int left, int right) {
        while (left < right) {
            int temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;
            left++;
            right--;
        }
    }
}
