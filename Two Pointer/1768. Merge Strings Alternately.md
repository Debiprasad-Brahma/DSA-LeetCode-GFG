## 🔤 LeetCode 1768 — Merge Strings Alternately | Two-Pointer Approach

### 💡 Intuition
We are given two strings `word1` and `word2`.  
We need to **merge them alternately**, meaning take one character from `word1`, then one from `word2`, and so on.  
If one string is longer, append the remaining characters at the end.

Example:  
`word1 = "abc"`, `word2 = "pqr"` → `"apbqcr"`

---

### 🧠 Approach
1. Use two pointers `i` and `j` to iterate over both strings.
2. Initialize a `StringBuffer` (or `StringBuilder`) to build the merged result efficiently.
3. While either pointer hasn’t reached the end of its respective string:
   - Append `word1[i]` if available.
   - Append `word2[j]` if available.
4. After the loop, return the final merged string using `toString()`.

---

### ⏱️ Complexity
- **Time Complexity:** O(n + m) — each character from both strings is processed once.  
- **Space Complexity:** O(n + m) — output string builder holds the merged string.

---

### 💻 Code
```java
class Solution {

    public String mergeAlternately(String word1, String word2) {
        int i = 0, j = 0;
        StringBuffer sb = new StringBuffer();

        while (i < word1.length() || j < word2.length()) {
            if (i < word1.length()) sb.append(word1.charAt(i));
            if (j < word2.length()) sb.append(word2.charAt(j));

            i++;
            j++;
        }

        return sb.toString();
    }
}
