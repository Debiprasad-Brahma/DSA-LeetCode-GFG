## 🔁 LeetCode 125 — Valid Palindrome | Two-Pointer String Cleaning Approach

### 💡 Intuition
We need to determine whether a given string is a **palindrome**, considering only **alphanumeric characters** and ignoring **case differences**.

For example:  
`"A man, a plan, a canal: Panama"` → `"amanaplanacanalpanama"` → ✅ palindrome  

By preprocessing the string to remove unwanted characters and comparing characters from both ends, we can efficiently solve this.

---

### 🧠 Approach
1. **Normalize the string**:
   - Convert all letters to lowercase.
   - Remove all non-alphanumeric characters using regex:  
     `s.replaceAll("[^a-z0-9]", "")`
2. **Use two pointers**:
   - `i` starts from the beginning.
   - `j` starts from the end.
3. Compare characters:
   - If they differ, return `false`.
   - Otherwise, move both pointers inward.
4. If all pairs match, return `true`.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — one pass through the string.  
- **Space Complexity:** O(n) — due to the cleaned string copy (regex replacement).

---

### 💻 Code
```java
class Solution {

    public boolean isPalindrome(String s) {
        // Step 1: Clean and normalize string
        s = s.toLowerCase().replaceAll("[^a-z0-9]", "");

        // Step 2: Use two-pointer check
        int i = 0;
        int j = s.length() - 1;

        while (i < j) {
            if (s.charAt(i) != s.charAt(j))
                return false;

            i++;
            j--;
        }

        return true;
    }
}
