## 💬 LeetCode 345 — Reverse Vowels of a String | Two-Pointer Approach

### 💡 Intuition
We need to reverse **only the vowels** in a given string while keeping all other characters in place.  
Vowels are `'a', 'e', 'i', 'o', 'u'` (both uppercase and lowercase).  

The most efficient method is to use a **two-pointer approach**:
- One pointer starts from the beginning (`i`)
- Another from the end (`j`)
Both move toward each other and swap vowels when found.

---

### 🧠 Approach
1. Create a `HashSet<Character>` containing all vowels (uppercase and lowercase) for quick lookup.
2. Convert the string into a character array for easy modification.
3. Initialize two pointers:
   - `i = 0` (start)
   - `j = arr.length - 1` (end)
4. Move `i` forward until it points to a vowel.  
   Move `j` backward until it points to a vowel.
5. Swap the vowels at positions `i` and `j`.
6. Continue until both pointers meet or cross.
7. Return the new string after reassembling the modified character array.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — each character is checked at most once.  
- **Space Complexity:** O(n) — due to character array (strings in Java are immutable).  
  HashSet takes constant space since it always holds 10 vowels.

---

### 💻 Code
```java
class Solution {

    public String reverseVowels(String s) {
        HashSet<Character> vowels = new HashSet<>();
        Collections.addAll(vowels, 'A', 'E', 'I', 'O', 'U', 'a', 'e', 'i', 'o', 'u');

        char[] arr = s.toCharArray();
        int i = 0;
        int j = arr.length - 1;

        while (i <= j) {
            // Move left pointer until a vowel is found
            while (i < j && !vowels.contains(arr[i])) {
                i++;
            }

            // Move right pointer until a vowel is found
            while (i < j && !vowels.contains(arr[j])) {
                j--;
            }

            // Swap vowels
            char temp = arr[i];
            arr[i] = arr[j];
            arr[j] = temp;

            i++;
            j--;
        }

        return new String(arr);
    }
}
