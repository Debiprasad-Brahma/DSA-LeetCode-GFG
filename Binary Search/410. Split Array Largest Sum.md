# 🧠 Intuition
We want to split the array into **`k` subarrays** such that the **maximum subarray sum is minimized**.

Key observation:
- If we allow a **large max sum**, we can split easily (fewer subarrays)
- If we restrict to a **small max sum**, we need more subarrays

👉 This creates a **monotonic relationship**:
- Small max sum → **not possible**
- Large max sum → **possible**

So we apply **Binary Search on Answer (max subarray sum)**.

---

# 🚀 Approach
## 1. Define search space
- **Minimum possible answer** = `max(nums)`  
  (because one element itself must fit)

- **Maximum possible answer** = `sum(nums)`  
  (if we take entire array as one subarray)

---

## 2. Binary search on max sum
For each `mid` (candidate max sum):
- Check if we can split into **≤ k subarrays**

---

## 3. Feasibility check (`ifPossible`)
- Traverse array
- Keep adding elements to current subarray
- If sum exceeds `mid`:
  - Start new subarray
  - Increase `count`

Finally:
- If `count <= k` → valid
- Else → invalid

---

## 4. Adjust search
- If possible → try smaller (`end = mid - 1`)
- Else → increase (`start = mid + 1`)

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(n \log S)$$  
  - \(n\) = array size  
  - \(S\) = sum of array  

- **Space complexity:**  
  $$O(1)$$  

---

# 💻 Code
```java
class Solution {
    
    boolean ifPossible(int[] nums, int mid, int k) {
        int count = 1;
        int sum = 0;

        for (int num : nums) {
            if (sum + num > mid) {
                sum = num;
                count++;
            } else {
                sum += num;
            }
        }

        return count <= k;
    }

    public int splitArray(int[] nums, int k) {
        int start = nums[0];
        int end = 0;
        
        // Define bounds
        for (int num : nums) {
            start = Math.max(num, start);
            end += num;
        }

        int ans = 0;

        while (start <= end) {
            int mid = start + (end - start) / 2;

            if (ifPossible(nums, mid, k)) {
                ans = mid;
                end = mid - 1; // try smaller max sum
            } else {
                start = mid + 1; // increase limit
            }
        }

        return ans;
    }
}
