# Intuition
The problem gives us a number between `1` and `n`, and we must find it using the provided `guess()` API.

Each call to `guess(num)` tells us:

- `0` → Correct guess  
- `-1` → Our guess is too high  
- `1` → Our guess is too low  

Since the numbers are in a **sorted range**, this is a perfect use case for **Binary Search**.  
Instead of checking every number one by one, we repeatedly divide the search space in half.

---

# Approach
1. Initialize:
   - `start = 1`
   - `end = n`

2. While `start <= end`:
   - Compute the middle safely:
     ```
     int mid = start + (end - start) / 2;
     ```
     (Prevents integer overflow.)

3. Call `guess(mid)`:
   - If it returns `0`, we found the number → return `mid`
   - If it returns `-1`, the guess is too high → search left → `end = mid - 1`
   - If it returns `1`, the guess is too low → search right → `start = mid + 1`

4. If no number is found (which theoretically shouldn't happen), return `-1`.

# Code
```java []
/**
 * Forward declaration of guess API.
 * @param  num   your guess
 * @return 	     -1 if num is higher than the picked number
 *			      1 if num is lower than the picked number
 *               otherwise return 0
 * int guess(int num);
 */

public class Solution extends GuessGame {

    public int guessNumber(int n) {
        int start = 1;
        int end = n;
        while (start <= end) {
            int mid = start + (end - start) / 2;

            if (guess(mid) == 0) return mid; 
            else if (guess(mid) == -1) end = mid - 1; 
            else start = mid + 1;
        }

        return -1;
    }
}

```
