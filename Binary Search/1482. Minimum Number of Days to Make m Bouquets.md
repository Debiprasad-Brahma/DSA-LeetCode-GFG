# 🧠 Intuition
We need the **minimum number of days** required to make `m` bouquets, where:
- Each bouquet needs **`k` adjacent flowers**
- A flower blooms on `bloomDay[i]`

Key observation:
- If we wait **more days**, more flowers bloom → easier to make bouquets
- If we wait **fewer days**, fewer flowers bloom → harder

👉 This creates a **monotonic condition**:
- Small days → not possible  
- Large days → possible  

So we can apply **Binary Search on Answer (days)**.

---

# 🚀 Approach
1. Define search space:
   - `start = min(bloomDay)`
   - `end = max(bloomDay)`

2. For a given day `mid`:
   - Check if we can form **at least `m` bouquets**

3. To check feasibility:
   - Traverse array
   - If `bloomDay[i] <= mid` → flower is usable
   - Count consecutive usable flowers
   - When count reaches `k` → one bouquet formed
   - Reset count

4. If total bouquets ≥ `m`:
   - Store answer
   - Try smaller day (`end = mid - 1`)
5. Else:
   - Increase days (`start = mid + 1`)

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(n \log D)$$  
  - \(n\) = number of flowers  
  - \(D\) = range of days  

- **Space complexity:**  
  $$O(n)$$ *(due to boolean array)*

---

# 💻 Code
```java
public class Solution {
    public static int roseGarden(int[] arr, int r, int b) {
        // Write your code here.
       
        int start = arr[0];
        int end = arr[0];

        // find the range of answer
        for(int num : arr){
            start = Math.min(start, num);
            end = Math.max(end, num);
        }

        int ans = -1;

        while(start <= end){
            int mid = start + (end - start) / 2;

            int count = 0;
            int finalCount = 0; // match it at last with m bouquet
            
            for(int i = 0; i < arr.length; i++){
                if(arr[i] <= mid) count++;

                if(arr[i] > mid) count = 0;

                if(count == r){ // reset the count 
                    finalCount++;
                    count = 0;
                }   
            }

            if(finalCount >= b){
                ans = mid; // update the answer
                end = mid - 1;
            }
            else{
                start = mid + 1;
            }
        }

        return ans;
    }
}
