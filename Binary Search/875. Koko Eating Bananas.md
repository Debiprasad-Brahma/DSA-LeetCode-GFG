# 🧠 Intuition
This is a classic **binary search on answer** problem.

We are not searching for an index — we are searching for the **minimum eating speed (k)** such that Koko can finish all bananas within `h` hours.

Key observation:
- If Koko eats **slowly (small k)** → takes **more time**
- If Koko eats **faster (large k)** → takes **less time**

So:
👉 The answer space is **monotonic**
- For small `k` → invalid (time > h)
- For large `k` → valid (time ≤ h)

This makes it perfect for **binary search**.

---

# 🚀 Approach
1. Define search space:
   - `start = 1` (minimum possible speed)
   - `end = max(piles)` (maximum needed speed)

2. Apply binary search:
   - Pick `mid` as current speed

3. Compute time required:
   - For each pile:
     ```
     time += ceil(pile / mid)
     ```
   - Optimized as:
     ```
     (pile + mid - 1) / mid
     ```

4. If `time <= h`:
   - Speed is valid → try smaller speed (`end = mid - 1`)
   - Store answer

5. Else:
   - Speed too slow → increase speed (`start = mid + 1`)

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(n \log m)$$  
  - \(n\) = number of piles  
  - \(m\) = max pile value  

- **Space complexity:**  
  $$O(1)$$

---

# 💻 Code
```java
class Solution {

    public int minEatingSpeed(int[] piles, int h) {
        int start = 1;

        // maximum pile determines upper bound
        int end = piles[0];
        for (int num : piles) {
            end = Math.max(num, end);
        }

        int ans = end;

        while (start <= end) {
            int mid = start + (end - start) / 2;

            int time = 0;

            for (int pile : piles) {
                // ceil(pile / mid)
                time += (pile + mid - 1) / mid;

                // optimization: stop early if already exceeded
                if (time > h) break;
            }

            if (time <= h) {
                ans = mid;      // valid speed
                end = mid - 1;  // try smaller
            } else {
                start = mid + 1; // increase speed
            }
        }

        return ans;
    }
}
