# 🧩 Binary Search | Clean & Efficient Java Solution | O(log n) | Beats 100%**

---

## 🧠 Intuition
In a sorted array, every element appears **exactly twice**, except for one element that appears **only once**.  
The key observation is that **pairs appear in a pattern** before the single element —  
- Before the single element, the first instance of each pair appears at **even** indices.  
- After the single element, this pattern **breaks**, and the first instance appears at **odd** indices.

We can use **binary search** to efficiently find where this pattern breaks.

---

## ⚙️ Approach
1. Initialize two pointers:
   - `l = 0`
   - `r = arr.length - 1`

2. While `l < r`:
   - Compute `mid = l + (r - l) / 2`.
   - Check the pattern:
     - If `mid` is **even** and `arr[mid] == arr[mid + 1]`,  
       the single element is **after mid** → move left pointer `l = mid + 1`.
     - If `mid` is **odd** and `arr[mid] == arr[mid - 1]`,  
       the single element is **after mid** → move left pointer `l = mid + 1`.
     - Otherwise, the single element is **on the left side** → move right pointer `r = mid`.

3. When the loop ends, `l` will point to the single non-duplicate element.

---

## 🧮 Example
**Input:** `[1,1,2,3,3,4,4,8,8]`  
**Process:**
- Pairs match correctly until `2`, where the pattern breaks.  
- Binary search focuses around that region.  
**Output:** `2`

---

## ⏱️ Complexity Analysis
- **Time Complexity:** `O(log n)` — Binary search reduces the range by half each iteration.  
- **Space Complexity:** `O(1)` — Constant extra space used.

---

## 🧩 Code
```java
class Solution {
    public int singleNonDuplicate(int[] arr) {
        int l = 0;
        int r = arr.length - 1;
        while (l < r) {
            int mid = l + (r - l) / 2;
            // Condition for checking even and odd index pairing pattern
            if ((mid % 2 == 0 && arr[mid] == arr[mid + 1]) || 
                (mid % 2 != 0 && arr[mid] == arr[mid - 1])) {
                l = mid + 1;
            } else {
                r = mid;
            }
        }
        return arr[l];
    }
}
