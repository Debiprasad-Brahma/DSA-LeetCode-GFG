## 🏔️ LeetCode 852 — Peak Index in a Mountain Array | Binary Search on Mountain Slope

### 💡 Intuition  
A **mountain array** has three parts:
- Strictly increasing sequence
- A single peak
- Strictly decreasing sequence

Since the array first rises and then falls, we can use **binary search** to find the peak efficiently.

Key idea:
- If `arr[mid] < arr[mid + 1]`, we are on the **ascending slope**, so the peak is to the **right**.
- Otherwise, we are on the **descending slope or at the peak**, so the peak is to the **left (or mid)**.

---

### 🧠 Approach  
1. Initialize two pointers:
   - `start = 0`
   - `end = n - 1`
2. While `start < end`:
   - Compute `mid`
   - Compare `arr[mid]` with `arr[mid + 1]`
     - If increasing → move `start = mid + 1`
     - Else → move `end = mid`
3. When the loop ends, `start == end` → peak index found.
4. Return `start`.

---

### ⏱️ Complexity  
- **Time Complexity:** O(log n) — binary search  
- **Space Complexity:** O(1)

---

### 💻 Code  
```java
class Solution {
    public int peakIndexInMountainArray(int[] arr) {
        int n = arr.length;
        int start = 0;
        int end = n - 1;

        while (start < end) {
            int mid = start + (end - start) / 2;

            if (arr[mid] <= arr[mid + 1]) {
                start = mid + 1;  // move towards the peak
            } else {
                end = mid;        // peak is at mid or left
            }
        }
        return start;
    }
}
