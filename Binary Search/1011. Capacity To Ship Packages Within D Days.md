# 🚢 LeetCode 1011 — Capacity To Ship Packages Within D Days | Binary Search on Answer

# 💡 Intuition  
We need to find the **minimum ship capacity** so that all packages can be shipped within `days`.

Key observations:
- The **minimum capacity** must be at least the **maximum single package weight** (you can’t split a package).
- The **maximum capacity** can be the **sum of all weights** (ship everything in one day).
- If a certain capacity works (can ship within `days`), then **any larger capacity will also work**.

This monotonic behavior makes the problem perfect for **binary search on the answer**.

---

# 🧠 Approach  

#### Helper Function: `reqireDays(weights, capacity)`
- Simulates shipping with a given `capacity`
- Greedily loads packages in order
- If current load exceeds capacity → move to the next day
- Returns the number of days required

#### Main Logic:
1. Set search range:
   - `low` = max weight in `weights`
   - `high` = sum of all weights
2. Binary search on capacity:
   - If `reqireDays(mid) <= days` → capacity works, try smaller
   - Else → capacity too small, increase it
3. Return the minimum valid capacity found

---

# ⏱️ Complexity  
- **Time Complexity:** O(n log S)  
  - `n` = number of packages  
  - `S` = sum of weights (search space)
- **Space Complexity:** O(1)

// Optimized answer
class Solution {
    int reqireDays(int []weights, int capacity){
        int day = 1;
        int currLoad = 0;

        for(int w : weights){
            if(currLoad + w > capacity){
                day++;
                currLoad = w;
            }
            else{
                currLoad += w;
            }
        }
        return day;
    }
    public int shipWithinDays(int[] weights, int days) {
        int low = weights[0];
        int high = 0;
        int n = weights.length;

        for (int i = 0; i < n; i++) {
            low = Math.max(low, weights[i]); // Find maximum from where you have to start
            high += weights[i]; // find out last where you have to stop
        }

        int ans = high;

        while (low <= high) {
            int mid = low + (high - low) / 2;
            if (reqireDays(weights, mid) <= days) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }
        return ans;
    }
}
