## 🏔️ LeetCode 162 — Find Peak Element | Binary Search on Slope

### 💡 Intuition  
A **peak element** is an element that is **strictly greater than its neighbors**.  
The array may have multiple peaks — returning **any one peak index** is valid.

Key observation:
- If `arr[mid] < arr[mid + 1]`, the array is **increasing**, so a peak must exist on the **right side**.
- Otherwise, the array is **decreasing or flat**, so a peak lies on the **left side (including mid)**.

This directional behavior allows us to use **binary search** instead of linear scanning.

---

### 🧠 Approach  
1. Initialize two pointers:
   - `start = 0`
   - `end = arr.length - 1`
2. While `start < end`:
   - Compute `mid`
   - Compare `arr[mid]` with `arr[mid + 1]`
     - If increasing → move right (`start = mid + 1`)
     - Else → move left (`end = mid`)
3. When loop ends, `start == end` and points to a **peak index**.
4. Return `start`.

---

### ⏱️ Complexity  
- **Time Complexity:** O(log n) — binary search  
- **Space Complexity:** O(1)

---

### 💻 Code  
```java
class Solution {
    public int findPeakElement(int[] arr) {
        int start = 0;
        int end = arr.length - 1;

        while (start < end) {
            int mid = start + (end - start) / 2;

            if (arr[mid] < arr[mid + 1]) {
                start = mid + 1;   // peak lies on the right
            } else {
                end = mid;         // peak lies on the left or at mid
            }
        }
        return start;
    }
}
