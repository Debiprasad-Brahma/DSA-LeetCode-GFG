# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->

The goal is to maximize the minimum distance between any two balls. Instead of directly searching for the best arrangement, we can think of the answer itself as the search space.

If we can successfully place all `m` balls such that the minimum distance between every two consecutive balls is at least `d`, then any distance smaller than `d` is also possible. On the other hand, if a distance `d` is not achievable, then any larger distance will also be impossible.

This monotonic property makes the problem a perfect candidate for **Binary Search on Answer**.

To verify whether a particular distance is feasible, we use a greedy strategy:
- Place the first ball in the first basket.
- Always place the next ball in the earliest basket that maintains the required minimum distance.
- If all balls can be placed, the distance is valid.

---

# Approach
<!-- Describe your approach to solving this problem. -->

1. Sort the basket positions so that distances can be checked in increasing order.
2. Define the binary search range:
   - Minimum possible answer = `1`
   - Maximum possible answer = `position[n-1] - position[0]`
3. For every middle distance:
   - Greedily place the first ball.
   - Continue placing each remaining ball in the first basket whose distance from the last placed ball is at least `mid`.
4. If all balls can be placed:
   - Store the answer.
   - Try a larger minimum distance.
5. Otherwise:
   - Reduce the search space.
6. The stored answer is the maximum possible minimum distance.

---

# Complexity

- **Time complexity:**
  - Sorting the array: **O(n log n)**
  - Binary Search: **O(log D)** iterations, where `D = position[n-1] - position[0]`
  - Feasibility check for each iteration: **O(n)**

  **Overall:** `O(n log n + n log D)`

- **Space complexity:**

  `O(1)`

  Only constant extra space is used apart from the input array.

# Code
```java []
class Solution {

    private boolean canPlaceBalls(int mid, int[] position, int m) {
        int n = position.length;
        int ballsRemaining = m - 1;
        int start = 0;

        for (int end = 1; end < n; end++) {
            if (position[end] - position[start] >= mid) {
                ballsRemaining--;
                start = end;

                if (ballsRemaining == 0) return true;
            }
        }

        return ballsRemaining <= 0 ? true : false;
    }

    public int maxDistance(int[] position, int m) {
        // my intuation behind this is answer is going to lie between 1 to (position[n - 1] - position[0]);

        int n = position.length;
        Arrays.sort(position);

        int start = 1;
        int end = position[n - 1] - position[0];
        int ans = -1;
        while (start <= end) {
            int mid = start + (end - start) / 2;

            if (canPlaceBalls(mid, position, m)) {
                ans = mid;
                start = mid + 1;
            } else {
                end = mid - 1;
            }
        }

        return ans;
    }
}
```
