## 🍬 LeetCode 2226 — Maximum Candies Allocated to K Children | Binary Search on Answer

### 💡 Intuition  
You are given piles of candies.  
You can **split** piles but cannot merge them.  
Each child must receive the **same number of candies**, and each child can take candies from **only one pile**.

The goal is to **maximize** the number of candies each child gets while serving at least `k` children.

Key observation:
- If we can give `x` candies to each child, then we can also give **any smaller number**.
- If we **cannot** give `x` candies, then we cannot give any larger number.

This monotonic behavior makes the problem ideal for **binary search on the answer**.

---

### 🧠 Approach  

#### Helper: `canDistribute(candies, mid, k)`
- Checks if it is possible to give `mid` candies to at least `k` children.
- For each pile:
children += pile / mid

- If total children ≥ `k`, distribution is possible.

#### Main Logic:
1. Search space:
 - `start = 1` (minimum candies per child)
 - `end = max(candies[])` (maximum possible)
2. Binary search:
 - If `mid` is feasible → try larger value
 - Else → try smaller value
3. Store the best feasible value as the answer.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n log M)  
- `n` = number of piles  
- `M` = maximum pile size  
- **Space Complexity:** O(1)

### 💻 Code  
```java
class Solution {

  boolean canDistribute(int[] candies, int mid, long k) {
      long count = 0;

      for (int c : candies) {
          count += c / mid;
          if (count >= k) return true; // early stop
      }
      return false;
  }

  public int maximumCandies(int[] candies, long k) {
      int n = candies.length;

      int start = 1;
      int end = candies[0];

      // Find maximum pile size
      for (int i = 1; i < n; i++) {
          end = Math.max(end, candies[i]);
      }

      int ans = 0;

      // Binary search on answer
      while (start <= end) {
          int mid = start + (end - start) / 2;

          if (canDistribute(candies, mid, k)) {
              ans = mid;        // possible, try bigger
              start = mid + 1;
          } else {
              end = mid - 1;    // not possible, reduce
          }
      }

      return ans;
  }
}
