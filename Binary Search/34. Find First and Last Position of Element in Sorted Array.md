# 🎯 LeetCode — Find First and Last Position of Element in Sorted Array

## 💡 Title for Submission
**💡 Simple Java Solution | Linear Search | Easy to Understand | O(n) | Beats 95%**

---

## 🧠 Intuition
The problem asks to find the **first and last index** of a given target value in a **sorted array**.  
If the target doesn’t exist, we return `[-1, -1]`.  

The most straightforward way to achieve this is by scanning from both ends:
- The **first occurrence** will be found from the **left side**.
- The **last occurrence** will be found from the **right side**.

---

## ⚙️ Approach
1. Initialize two variables:  
   `s = -1` (start index), `e = -1` (end index).
2. **Left Scan:**  
   Loop from the beginning of the array until you find the first occurrence of `target`, then break.
3. **Right Scan:**  
   Loop from the end of the array until you find the last occurrence of `target`, then break.
4. Return `[s, e]`.  
   If the element isn’t found, both remain `-1`.

> ✅ This approach is very clean and simple for beginners to understand.  
> ❗ For a faster binary search solution, we can achieve `O(log n)` — but this one is still accepted and easy to debug.

---

## ⏱️ Complexity Analysis
- **Time Complexity:** `O(n)` — At worst, we traverse the array twice.
- **Space Complexity:** `O(1)` — Uses only constant extra space.
