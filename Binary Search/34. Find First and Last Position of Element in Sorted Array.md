## 🔍 LeetCode 34 — Find First and Last Position of Element in Sorted Array | Dual Binary Search

### 💡 Intuition  
The array is **sorted**, so binary search is the natural choice.  
However, a normal binary search only finds *one* occurrence.  
To get **both first and last positions**, we slightly modify binary search:

- One search biased to the **left** (first occurrence)
- One search biased to the **right** (last occurrence)

This keeps the solution efficient and clean.

---

### 🧠 Approach  

#### 1️⃣ Find Leftmost Index (`findLeft`)
- Perform binary search
- When `nums[mid] == target`:
  - Save index
  - Continue searching in the **left half** (`right = mid - 1`)
- Final stored index is the **first occurrence**

#### 2️⃣ Find Rightmost Index (`findRight`)
- Perform binary search
- When `nums[mid] == target`:
  - Save index
  - Continue searching in the **right half** (`left = mid + 1`)
- Final stored index is the **last occurrence**

#### 3️⃣ Combine Results
- Call both functions and return `[leftIndex, rightIndex]`
- If target doesn’t exist, both return `-1`

---

### ⏱️ Complexity  
- **Time Complexity:** O(log n)  
- **Space Complexity:** O(1)

---

### 💻 Code  
```java
class Solution {

    private int findLeft(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;
        int leftIdx = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                leftIdx = mid;
                right = mid - 1; // keep searching left
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return leftIdx;
    }

    private int findRight(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;
        int rightIdx = -1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                rightIdx = mid;
                left = mid + 1; // keep searching right
            } else if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        return rightIdx;
    }

    public int[] searchRange(int[] nums, int target) {
        int left = findLeft(nums, target);
        int right = findRight(nums, target);
        return new int[] { left, right };
    }
}
