# 💡 Simple Java Approach | Step-by-Step Missing Number Count | O(k + n) | Beats 100%

## 🧠 Intuition
We are given a **sorted positive integer array** and need to find the **kth missing positive number** that does not appear in the array.  
The main idea is to simulate counting positive numbers starting from `1`, comparing each with elements in the array.  
If a number is not found in the array, it counts as "missing".  
We continue this process until we reach the **kth missing number**.

---

## 💡 Approach
1. Initialize:
   - `missingNum = 1` → start checking from the first positive number.
   - `i = 0` → pointer for array traversal.
2. Iterate infinitely (or until we find the kth missing number):
   - If `missingNum` is present in `arr` (i.e., `arr[i] == missingNum`), move the pointer `i` forward.
   - Otherwise, it's a missing number → decrement `k`.
   - Once `k` becomes `0`, the current `missingNum` is the answer.
3. Increment `missingNum` after each step.

This method efficiently counts missing numbers without using extra space.

---

## ⏱️ Complexity
### Time Complexity:
**O(k + n)**  
We may check up to `k` missing numbers or traverse through all `n` elements of the array once.

### Space Complexity:
**O(1)**  
We use only constant extra variables.

---

## 🧮 Code
```java
class Solution {

    public int findKthPositive(int[] arr, int k) {
        int n = arr.length;
        int missingNum = 1;
        int i = 0;

        while (true) {
            if (i < arr.length && arr[i] == missingNum) {
                i++;
            } else {
                k--;
                if (k == 0) return missingNum;
            }
            missingNum++;
        }
    }
}
