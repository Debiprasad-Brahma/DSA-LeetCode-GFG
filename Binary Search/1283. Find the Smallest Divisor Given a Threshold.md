# ✅ Simple & Clear Java Code | Binary Search + Math.ceil Trick | Easy to Understand

## 🧠 Intuition
We are asked to find the smallest integer divisor such that the sum of each element in the array divided by this divisor (rounded up) is **less than or equal to a given threshold**.  

If the divisor is **small**, the quotient for each element becomes **large**, and the total sum increases.  
If the divisor is **large**, the quotient becomes **small**, and the total sum decreases.  

Hence, the relationship between the **divisor** and the **sum** is **monotonic decreasing**, which means we can use **binary search** to efficiently find the smallest valid divisor.

---

## 🔍 Approach
1. **Define the search space:**  
   - The smallest possible divisor is `1`.
   - The largest possible divisor is the **maximum element** in the array (since dividing by anything larger will make all quotients ≤ 1).

2. **Binary Search:**  
   - Use binary search between `low = 1` and `high = max(nums)`.
   - For each `mid` (potential divisor), compute the sum of all `ceil(nums[i] / mid)` using the helper function `sumOfDivision()`.
   - If the sum ≤ threshold, it means we can try a **smaller divisor** (move `high = mid - 1`).
   - Otherwise, we need a **larger divisor** (move `low = mid + 1`).

3. **Helper Function — sumOfDivision():**  
   - For each element `val` in `nums`, compute `ceil(val / mid)` and accumulate the total.
   - Stop early if the sum exceeds the threshold for efficiency.

4. **Return the answer:**  
   - The smallest divisor found that satisfies the condition.

---

## ⏱️ Complexity Analysis
- **Time Complexity:** `O(n * log(max(nums)))`  
  - Each binary search iteration computes the sum across all elements.
- **Space Complexity:** `O(1)`  
  - Uses only a few variables for computation.

---

## 🧩 Code
```java
class Solution {
    int sumOfDivision(int[] nums, int mid, int threshold){
        int sum = 0;
        for(int val : nums){
            sum += Math.ceil((double) val / mid);
            if(sum > threshold) break;
        }
        return sum; 
    }

    public int smallestDivisor(int[] nums, int threshold) {
        int low = 1;
        int high = Arrays.stream(nums).max().getAsInt();
        int ans = -1;

        while(low <= high){
            int mid = low + (high - low) / 2;

            if(sumOfDivision(nums, mid, threshold) <= threshold){
                ans = mid;
                high = mid - 1; // Try to find a smaller divisor
            } else {
                low = mid + 1; // Need a larger divisor
            }
        }
        return ans;
    }
}
