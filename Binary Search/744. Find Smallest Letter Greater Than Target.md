## 🔤 LeetCode 744 — Find Smallest Letter Greater Than Target | Binary Search with Wrap-Around

### 💡 Intuition  
You are given a **sorted array of characters** `letters` and a `target` character.  
You need to find the **smallest character strictly greater than `target`**.

Important detail:
- The letters wrap around, meaning if no character is greater than `target`,  
  you must return the **first character** in the array.

Because the array is sorted, **binary search** is the optimal choice.

---

### 🧠 Approach  
1. Initialize:
   - `start = 0`, `end = n - 1`
   - `ans = letters[0]` (default wrap-around answer)
2. Perform binary search:
   - If `letters[mid] > target`:
     - This is a valid candidate
     - Store it in `ans`
     - Continue searching left to find a smaller valid letter
   - Else:
     - Move right (`start = mid + 1`)
3. After the loop:
   - If no letter was strictly greater, `ans` remains `letters[0]`
4. Return `ans`.

This guarantees the **smallest letter greater than target**, respecting wrap-around.

---

### ⏱️ Complexity  
- **Time Complexity:** O(log n) — binary search  
- **Space Complexity:** O(1)

---

### 💻 Code  
```java
class Solution {

    public char nextGreatestLetter(char[] letters, char target) {
        int n = letters.length;
        int start = 0;
        int end = n - 1;

        // Default wrap-around answer
        char ans = letters[0];

        while (start <= end) {
            int mid = start + (end - start) / 2;

            if (letters[mid] > target) {
                ans = letters[mid];
                end = mid - 1;   // try to find smaller valid character
            } else {
                start = mid + 1;
            }
        }
        return ans;
    }
}
