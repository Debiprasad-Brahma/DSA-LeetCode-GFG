# 💡 Intuition  
An array is **special** if there exists a number `x` such that:
- Exactly `x` elements in the array are **greater than or equal to `x`**.

Observations:
- The possible value of `x` lies between `0` and `n` (length of array).
- If for a value `x`, the count of elements `>= x` is:
  - **equal to `x`** → valid answer
  - **greater than `x`** → we need a larger `x`
  - **less than `x`** → we need a smaller `x`

This monotonic behavior allows us to use **binary search on the answer**.

---

# 🧠 Approach  

## Helper Method — `isSpecial(nums, mid)`
- Counts how many elements in `nums` are `>= mid`.

## Main Logic
1. Binary search in the range `[0, n]`.
2. For each `mid`:
   - Count elements `>= mid`.
   - If `count == mid` → return `mid`.
   - If `count > mid` → search right half.
   - Else → search left half.
3. If no valid `x` is found, return `-1`.

---

# ⏱️ Complexity  
- **Time Complexity:** O(n log n)  
  - Binary search × linear count check
- **Space Complexity:** O(1)

---
# Code
```java []
class Solution {
    private int isSpecial(int []nums, int mid){
        int cnt = 0;
        for(int num : nums){
            if(num >= mid) cnt++;
        }
        return cnt;
    }
    public int specialArray(int[] nums) {
        int n = nums.length;

        int start = 0;
        int end = n; // The answer should be among 0 to min number of the nums array

        while(start <= end){
            int mid = start + (end - start) / 2;
            int count = isSpecial(nums, mid);
            if(count == mid) return count;
            else if(count > mid) start = mid + 1;
            else end = mid - 1;
        }
        return -1;
    }
}
```
