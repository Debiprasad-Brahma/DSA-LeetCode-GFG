# 🚚 Count All Valid Pickup and Delivery Options

## 🧠 Intuition  
We need to count the number of valid sequences of pickup and delivery tasks for `n` orders.  
Each order has two tasks:  
- Pickup (`Pi`)  
- Delivery (`Di`)  

The constraint is that each delivery must happen **after its corresponding pickup**.  

So the problem reduces to:  
- Arrange `2n` events, but ensure `Pi` appears before `Di` for each `i`.

---

## 📌 Approach  
1. **Total arrangements without constraints**  
   - There are `(2n)!` ways to arrange `2n` events.  

2. **Apply pickup-before-delivery constraint**  
   - For each pair `(Pi, Di)`, only half of the permutations are valid (since pickup must come before delivery).  
   - So divide by `2` for each of the `n` pairs.  
   - Formula:  
    $$\frac{(2n)!}{2^n}$$


3. **Rewriting the formula**  
   Another way to think:  
   - Place pickups first → `n!` ways.  
   - For each delivery `Di`, insert it into one of the `(2i - 1)` slots that appear after `Pi`.  
   - Multiply these choices together:  
     $$\frac{(2n)!}{2^n}$$

4. **Implementation details**  
   - Use modulo `1e9+7` since numbers grow huge.  
   - Iterate `i` from `1` to `n`, updating result with `(res * i * (2i - 1))`.  

---

## ⏱️ Complexity
- **Time Complexity**:  
  `O(n)` → We loop once through `n`.  
- **Space Complexity**:  
  `O(1)` → Only a few variables used.

---

## 💻 Code (Java)
```java
class Solution {
    public int countOrders(int n) {
        long MOD = 1000000007;
        long res = 1;

        for (int i = 1; i <= n; i++) {
            res = (res * i) % MOD;            // choices for pickup
            res = (res * (2L * i - 1)) % MOD; // choices for delivery
        }

        return (int) res;
    }
}
