# 🧠 Intuition
Pascal’s Triangle follows a simple pattern where each row is built using values from the **previous row**.

🔑 **Key Observations**
- Every row starts and ends with **1**
- Each inner element is the **sum of the two elements directly above it**
- The triangle grows **row by row**

### 📌 Example
Row 0: 1
Row 1: 1 1
Row 2: 1 2 1
Row 3: 1 3 3 1
Row 4: 1 4 6 4 1

### 📐 Mathematical Relationship
triangle[i][j] = triangle[i-1][j-1] + triangle[i-1][j]

Instead of computing combinations (`nCr`), we simply **construct the triangle iteratively using previously computed rows**.

This makes the implementation **clean, intuitive, and efficient**.

---

# ⚙️ Approach
We construct the triangle **row by row**.

### Step-by-step

1️⃣ Create a list `ans` to store the final Pascal's Triangle.

2️⃣ Iterate from `0 → numRows - 1` to generate each row.

3️⃣ For every row:

- Create a new list `curr`
- Iterate through all positions `0 → i`

4️⃣ For each position `j`:

- If it is the **first or last element**, insert `1`
j == 0 || j == i


- Otherwise:
  - Fetch the **previous row**
  - Add the two elements above
prev[j-1] + prev[j]


5️⃣ Add the completed row into the result list.

6️⃣ After generating all rows, **return the triangle**.

---

# ⏱ Complexity Analysis

### `Time Complexity:` **O(n²)**

- We generate **n rows**
- Each row contains up to **n elements**

Therefore total operations ≈ 1 + 2 + 3 + ... + n

Which equals **O(n²)**.

---

### `Space Complexity:` **O(n²)**

- We store the **entire Pascal's Triangle**
- Total stored elements:
n(n+1)/2


Which results in **O(n²)** space usage.

# Code
```java []
class Solution {

    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> ans = new ArrayList<>();

        for (int i = 0; i < numRows; i++) {
            List<Integer> curr = new ArrayList<>();

            for (int j = 0; j <= i; j++) {
                if (j == 0 || j == i) {
                    curr.add(1);
                } else {
                    // get the prev list and add accordingly
                    List<Integer> prev = ans.get(i - 1);
                    curr.add(prev.get(j - 1) + prev.get(j));
                }
            }

            // at last add the curr list to ans list
            ans.add(curr);
        }

        return ans;
    }
}

```
