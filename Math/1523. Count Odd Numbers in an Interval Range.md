# Intuition  
To count how many **odd numbers** lie between `low` and `high` (inclusive),  we only need to consider the **total number of integers** in the range : num = high - low + 1

In any sequence of consecutive numbers:
- If `num` is **even**, exactly half are odd.
- If `num` is **odd**, then:
  - If the range **ends with an odd number**, odd count becomes `num/2 + 1`
  - Otherwise, odd count is `num/2`

This gives us a constant-time solution.

---

# Approach  
1. Compute number of elements in range.  
2. If the count is even → half of them are odd.  
3. If the count is odd → check if `high` is odd to determine if the range has an extra odd number.

---

# Time & Space Complexity  
- **Time Complexity:** O(1)  
- **Space Complexity:** O(1)

---

# Code
```java []
class Solution {

    public int countOdds(int low, int high) {
        int num = (high - low) + 1;

        if(num % 2 == 0){
            return num / 2;
        }
        return high % 2 == 0 ? num/2 : num/2 + 1;
    }
}

```
