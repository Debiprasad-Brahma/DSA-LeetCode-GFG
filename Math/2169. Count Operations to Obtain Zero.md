## 🔁 LeetCode 2169 — Count Operations to Obtain Zero | Simulation Approach

### 💡 Intuition
We are given two positive integers `num1` and `num2`.  
In each operation, we must **subtract the smaller number from the larger one** until either becomes `0`.  
We need to count how many such operations are performed.

This can be simulated using a simple while loop.

---

### 🧠 Approach
1. Initialize a counter `count = 0` to track the number of operations.
2. While both numbers are **non-zero**:
   - If `num1 > num2`, subtract `num2` from `num1`.
   - Otherwise, subtract `num1` from `num2`.
   - Increment `count` after every operation.
3. Once one of them becomes zero, stop and return `count`.

---

### ⏱️ Complexity
- **Time Complexity:** O(max(num1, num2)) — In the worst case, subtraction repeats many times (though typically fast).  
- **Space Complexity:** O(1) — constant space used.

---

### 💻 Code
```java
class Solution {

    public int countOperations(int num1, int num2) {
        int count = 0;

        while (num1 != 0 && num2 != 0) {
            if (num1 > num2) {
                num1 -= num2;
            } else {
                num2 -= num1;
            }
            count++;
        }

        return count;
    }
}
