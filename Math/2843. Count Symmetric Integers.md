# 🔢 Count Symmetric Integers | Brute Force with String Conversion | O(n * d) Time

## Intuition
We need to count numbers in the range `[low, high]` that are **symmetric**.  
A number is symmetric if:  
- It has an even number of digits.  
- The sum of the first half of its digits equals the sum of the second half.  

The straightforward approach is to check every number in the range and compute digit sums.

---

## Approach
1. Iterate through all numbers from `low` to `high`.  
2. Convert each number into a string.  
3. Skip numbers with an odd number of digits.  
4. Divide the string into two halves:  
   - Compute the sum of the first half.  
   - Compute the sum of the second half.  
5. If both sums are equal → increment the count.  
6. Return the total count at the end.  

---

## Complexity
- **Time Complexity:**  
  For each number, we compute digit sums. If `d` = max digits, total cost = **O((high - low + 1) * d)**.  
- **Space Complexity:**  
  String conversion takes extra space proportional to digits → **O(d)**.  

---

## Code
```java
class Solution {
    public int countSymmetricIntegers(int low, int high) {
        int count = 0;
        for (int i = low; i <= high; i++) {
            String str = Integer.toString(i);
            if (str.length() % 2 != 0) continue;

            int half = str.length() / 2;
            int leftSum = 0;
            int rightSum = 0;

            for (int j = 0; j < half; j++) {
                leftSum += str.charAt(j) - '0';
            }
            for (int k = str.length() - 1; k >= half; k--) {
                rightSum += str.charAt(k) - '0';
            }

            if (leftSum == rightSum) count++;
        }
        return count;
    }
}
