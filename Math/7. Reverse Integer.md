# Intuition

The goal is to reverse the digits of a 32-bit signed integer.  
We repeatedly take the **last digit** of the number using the modulus operator `%` and append it to a new number.

However, reversing a number may cause **integer overflow** because the reversed value might exceed the range of a 32-bit signed integer : [-2^31, 2^31 - 1]


So before updating the reversed number, we must check whether multiplying the current result by `10` will exceed the allowed integer range.

If overflow is detected, we return `0`.

---

# Approach

1. Initialize a variable `ans` to store the reversed number.
2. While the input number `x` is not `0`:
   - Extract the last digit using:
     ```
     reminder = x % 10
     ```
   - Check whether `ans * 10` would overflow the integer range.
   - If overflow might occur, return `0`.
   - Otherwise update:
     ```
     ans = ans * 10 + reminder
     ```
   - Remove the last digit from `x`:
     ```
     x = x / 10
     ```
3. Continue until all digits are processed.
4. Return the reversed integer.

---

# Complexity

**Time Complexity:**  
$$O(\log_{10}(n))$$  
We process each digit of the integer once.

**Space Complexity:**  
$$O(1)$$  
Only a few variables are used.

---

# Code
```java []
class Solution {

    public int reverse(int x) {
        int ans = 0;

        while (x != 0) {
            int reminder = x % 10;

            if (ans > Integer.MAX_VALUE / 10 || ans < Integer.MIN_VALUE / 10) return 0;
            ans = (ans * 10) + reminder;
            x = x / 10;
        }

        return ans;
    }
}

```
