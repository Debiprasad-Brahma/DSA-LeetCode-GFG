# 💡 Bulb Switcher | Math + Perfect Squares | O(1) Time

## Intuition
The problem describes toggling bulbs in rounds:  
- In the 1st round, toggle every bulb.  
- In the 2nd round, toggle every 2nd bulb.  
- In the 3rd round, toggle every 3rd bulb … and so on.  

A bulb ends up **on** if it is toggled an odd number of times.  
- Bulb `i` is toggled once for each of its divisors.  
- Most numbers have divisors in pairs (e.g., 12 → (1,12), (2,6), (3,4)).  
- Only **perfect squares** have an odd number of divisors (since one divisor is repeated, e.g., 16 → (1,16), (2,8), (4,4)).  

Therefore, the number of bulbs left **on** equals the number of perfect squares ≤ `n`.  

---

## Approach
1. The count of perfect squares up to `n` is simply `⌊√n⌋`.  
2. Return `(int) Math.sqrt(n)`.  

---

## Complexity
- **Time Complexity:** **O(1)** → direct math computation.  
- **Space Complexity:** **O(1)** → no extra memory.  

---

## Code
```java
class Solution {
    public int bulbSwitch(int n) {
        return (int)Math.sqrt(n);
    }
}
