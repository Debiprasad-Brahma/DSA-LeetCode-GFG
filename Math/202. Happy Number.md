## 😊 LeetCode 202 — Happy Number

### Intuition  
A number is called **happy** if repeatedly replacing the number with the **sum of the squares of its digits** eventually leads to `1`.

If during this process the number **never becomes 1** and instead starts repeating, it means we are stuck in a **cycle**, and the number is not happy.

So the key idea is:
- Keep generating the next number
- Detect if we ever **see the same number again**

---

### Approach  
1. Use a `HashSet` to store numbers that have already appeared.
2. Repeat until `n == 1`:
   - If `n` is already in the set, a cycle is detected → return `false`
   - Add `n` to the set
   - Compute the sum of squares of digits of `n`
   - Update `n` with this new sum
3. If `n` becomes `1`, return `true`

The set ensures we never loop infinitely.

---

### Time & Space Complexity  
- **Time Complexity:** O(log n) per iteration, with a small constant number of iterations  
- **Space Complexity:** O(log n) due to storing previously seen numbers

---

### Code  
```java
class Solution {

    public boolean isHappy(int n) {
        Set<Integer> seen = new HashSet<>();

        while (n != 1) {
            if (seen.contains(n)) {
                return false; // cycle detected
            }
            seen.add(n);

            int sum = 0;
            while (n > 0) {
                int d = n % 10;
                sum += d * d;
                n = n / 10;
            }
            n = sum;
        }
        return true;
    }
}
