## 🔄 LeetCode 557 — Reverse Words in a String III | StringBuilder Approach

### 💡 Intuition
We are given a string consisting of multiple words separated by spaces.  
The task is to **reverse each word individually** while keeping the order of the words the same.  

For example:  
`"Let's code"` → `"s'teL edoc"`

Using Java’s `StringBuilder` makes this very easy since it has a built-in `.reverse()` method.

---

### 🧠 Approach
1. Split the given string `s` into words using `split(" ")`.  
   - This creates an array of words.
2. Initialize a `StringBuilder` (`sb`) to build the result.
3. For each word:
   - Create a new `StringBuilder` for that word.
   - Reverse it using `.reverse()`.
   - Append it to `sb` followed by a space.
4. After processing all words, use `.trim()` to remove the trailing space.
5. Return the final string.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — every character is visited once.  
- **Space Complexity:** O(n) — for storing the reversed string.

---

### 💻 Code
```java
class Solution {

    public String reverseWords(String s) {
        String Words[] = s.split(" ");
        StringBuilder sb = new StringBuilder();

        for (String w : Words) {
            sb.append(new StringBuilder(w).reverse());
            sb.append(" ");
        }

        return sb.toString().trim();
    }
}
