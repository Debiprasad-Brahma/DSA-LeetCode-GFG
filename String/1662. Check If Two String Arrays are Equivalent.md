# 🔗 Check If Two String Arrays are Equivalent | StringBuilder Approach | O(n) Time

## Intuition
We are given two string arrays `word1` and `word2`. The task is to check if both arrays represent the **same string** when concatenated.  
The simplest way is to join all strings in each array and compare the results.  

---

## Approach
1. Use a `StringBuilder` (or `StringBuffer`) to efficiently concatenate all strings in `word1` and `word2`.  
2. Convert the `StringBuilder` results into two final strings.  
3. Compare both strings using `.equals()`.  
4. If they are the same, return `true`; otherwise return `false`.  

---

## Complexity
- **Time Complexity:**  
  Concatenation requires traversing all characters once → **O(n)**, where `n` is the total length of characters across both arrays.  
- **Space Complexity:**  
  We use extra space to build the concatenated strings → **O(n)**.  

---

## Code
```java
class Solution {
    public boolean arrayStringsAreEqual(String[] word1, String[] word2) {
        StringBuffer str1 = new StringBuffer();
        StringBuffer str2 = new StringBuffer();

        for (String w : word1) {
            str1.append(w);
        }
        for (String w : word2) {
            str2.append(w);
        }

        String ans1 = str1.toString();
        String ans2 = str2.toString();

        return ans1.equals(ans2);
    }
}
