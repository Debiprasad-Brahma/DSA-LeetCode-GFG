## 🧩 LeetCode 3120 — Count the Number of Special Characters I | HashMap + Index Tracking

### 💡 Intuition
A **special character** is defined as a lowercase letter `'x'` such that:
- `'x'` appears in the string before its uppercase version `'X'`.  
- Both `'x'` and `'X'` exist in the word.

We can track the **first and last occurrence indices** of every character using a custom `Pair` class.  
Then, we simply check for each lowercase letter if its **last occurrence** is before the **first occurrence** of its uppercase counterpart.

---

### 🧠 Approach
1. Define a `Pair` class to store two indices for each character:
   - `firstidx` → the first occurrence index.
   - `lastidx` → the last occurrence index.
2. Traverse the string once:
   - For each character, if it doesn’t exist in the map → create a new `Pair` with current index.
   - If it already exists → update its `lastidx`.
3. After building the map, iterate through all lowercase letters `'a'` to `'z'`:
   - Compute the corresponding uppercase letter.
   - If both versions exist in the map, and `lastidx(lowercase) < firstidx(uppercase)` → count it as a special character.
4. Return the total count.

---

### ⏱️ Complexity
- **Time Complexity:** O(n + 26) ≈ O(n) — one full traversal and one fixed loop over letters.  
- **Space Complexity:** O(1) — at most 52 characters (constant space).

---

### 💻 Code
```java
class Solution {

    class Pair {
        int firstidx, lastidx;

        Pair(int firstidx, int lastidx) {
            this.firstidx = firstidx;
            this.lastidx = lastidx;
        }
    }

    public int numberOfSpecialChars(String word) {
        HashMap<Character, Pair> map = new HashMap<>();

        // Step 1: Store first and last occurrences
        for (int i = 0; i < word.length(); i++) {
            char ch = word.charAt(i);
            if (!map.containsKey(ch))
                map.put(ch, new Pair(i, i));
            else
                map.get(ch).lastidx = i;
        }

        // Step 2: Count special lowercase characters
        int count = 0;
        for (char c = 'a'; c <= 'z'; c++) {
            char upper = (char) (c - 32); // Convert to uppercase
            if (map.containsKey(c) && map.containsKey(upper)) {
                if (map.get(c).lastidx < map.get(upper).firstidx)
                    count++;
            }
        }

        return count;
    }
}
