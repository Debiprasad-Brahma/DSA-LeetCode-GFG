## 🧮 LeetCode 856 — Score of Parentheses

### Intuition  
The score of a parentheses string is defined by these rules:
- `"()"` has a score of `1`
- `"AB"` has a score of `A + B`
- `"(A)"` has a score of `2 * A`

Instead of explicitly breaking the string into parts, we can observe how **nesting depth** affects the score:
- Every time we see a simple pair `"()"`, its score depends on **how deeply nested it is**
- If `"()"` appears at depth `d`, it contributes `2^(d-1)` to the total score

So the main idea is:
- Track the current depth of parentheses
- Whenever we encounter a `"()"`, add `2^depth` (after decreasing depth) to the answer

---

### Approach  
1. Initialize:
   - `depth = 0` to track nesting level
   - `ans = 0` to store the total score
2. Traverse the string character by character:
   - If the character is `'('`, increase `depth`
   - If the character is `')'`:
     - Decrease `depth`
     - If the previous character was `'('`, it means we found `"()"`
       - Add `2^depth` to the answer
3. Return the final score

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(1)

---

### Code  
```java
class Solution {

    public int scoreOfParentheses(String s) {
        int n = s.length();
        int depth = 0;
        int ans = 0;

        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);

            if (ch == '(') {
                depth++;
            } else {
                depth--;
                if (s.charAt(i - 1) == '(') {
                    ans += Math.pow(2, depth);
                }
            }
        }
        return ans;
    }
}
