## 🔤 LeetCode 387 — First Unique Character in a String

### Intuition  
We need to find the **first character** in the string that appears **exactly once** and return its index.  
If no such character exists, return `-1`.

A direct way to do this is:
1. Count how many times each character appears.
2. Traverse the string again and return the index of the first character with frequency `1`.

---

### Approach  
1. Use a `HashMap<Character, Integer>` to store the frequency of each character.
2. Traverse the string once to build the frequency map.
3. Traverse the string again from left to right:
   - If the frequency of the current character is `1`, return its index.
4. If no unique character is found, return `-1`.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(1)  
  (At most 26 lowercase English letters are stored)

---

### Code  
```java
class Solution {

    public int firstUniqChar(String s) {
        int n = s.length();
        HashMap<Character, Integer> map = new HashMap<>();

        // Count frequency of each character
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            map.put(ch, map.getOrDefault(ch, 0) + 1);
        }

        // Find first character with frequency 1
        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);
            if (map.get(ch) == 1) {
                return i;
            }
        }

        return -1;
    }
}
