# Intuition  
For each index `i` in the array, we need to compute:
| sum of elements to the left of i − sum of elements to the right of i |

The key is to **exclude the current element** from both sums.

To do this efficiently, we:
- Keep track of cumulative sums from the left
- Keep track of cumulative sums from the right

Then, for each index, we simply take the absolute difference of those two values.

---

# Approach  

1. Create two arrays:
   - `leftSum[i]`: sum of all elements **before** index `i`
   - `rightSum[i]`: sum of all elements **after** index `i`
2. Build `leftSum` by traversing from left to right.
3. Build `rightSum` by traversing from right to left.
4. For each index `i`, update:nums[i] = | leftSum[i] - rightSum[i] |

5. Return the modified `nums` array.

---

# Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(n)  
(Two auxiliary arrays are used)

---

# Code
```java []
class Solution {

    public int beautySum(String s) {
        int n = s.length();
        int ans = 0;
        for (int i = 0; i < n; i++) {
            int[] freq = new int[26];

            for (int j = i; j < n; j++) {
                freq[s.charAt(j) - 'a']++;

                int maxFreq = Integer.MIN_VALUE;
                int minFreq = Integer.MAX_VALUE;

                for (int k = 0; k < 26; k++) {
                    if (freq[k] > 0) {
                        maxFreq = Math.max(maxFreq, freq[k]);
                        minFreq = Math.min(minFreq, freq[k]);
                    }
                }

                ans += (maxFreq - minFreq);
            }
        }

        return ans;
    }
}

```
