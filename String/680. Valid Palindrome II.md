# 💡 Intuition

A string can become a palindrome after deleting **at most one** character if we can process it from both ends using two pointers. 

When both characters match at `start` and `end`, we shrink our window by moving inwards (`start++`, `end--`). When a mismatch occurs (`s.charAt(start) != s.charAt(end)`), we have reached our single allowed deletion. We then have two choices:
1. Skip the character at `start` (check if substring `s[start + 1 ... end]` is a palindrome).
2. Skip the character at `end` (check if substring `s[start ... end - 1]` is a palindrome).

If either remaining substring forms a valid palindrome, the result is `true`. Otherwise, it's impossible to form a palindrome with only one deletion, so we return `false`.

---

# 🛠️ Step-by-Step Approach

1. **Initialize Two Pointers:** Place `start` at index `0` and `end` at `s.length() - 1`.
2. **Traverse Toward Center:**
   - If `s.charAt(start) == s.charAt(end)`, move `start` right and `end` left.
   - If a mismatch is detected:
     - Check if skipping `start` (`start + 1` to `end`) forms a valid palindrome.
     - Check if skipping `end` (`start` to `end - 1`) forms a valid palindrome.
     - Return `true` if either check succeeds; otherwise return `false`.
3. **Return True:** If the loop finishes without unresolvable mismatches, the string is already a palindrome.

---

- Time complexity: $O(N)$ — In the worst-case scenario, we iterate through the string once and perform at most one additional sub-check on a substring of length at most $N$.

# Code
```java []
class Solution {

    private boolean isValidPalindrome(int start, int end, String s) {
        while (start < end) {
            if (s.charAt(start) == s.charAt(end)) {
                start++;
                end--;
            } else {
                return false;
            }
        }
        return true;
    }

    public boolean validPalindrome(String s) {
        int start = 0;
        int end = s.length() - 1;

        while (start < end) {
            if (s.charAt(start) == s.charAt(end)) {
                start++;
                end--;
            } else {
                if (isValidPalindrome(start + 1, end, s)) return true; else if (isValidPalindrome(start, end - 1, s)) return true; else return false;
            }
        }

        return true;
    }
}

```
