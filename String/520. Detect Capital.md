# Detect Capital Usage

## Intuition
We need to check whether a given word uses capitals correctly. According to the rules:
1. All letters are uppercase (e.g., "USA"), or  
2. All letters are lowercase (e.g., "leetcode"), or  
3. Only the first letter is uppercase, and the rest are lowercase (e.g., "Google").  

If the word follows any of these three patterns, then it is valid; otherwise, it's invalid.

## Approach
1. Count the number of uppercase and lowercase characters in the word.  
2. If all characters are uppercase → valid.  
3. If all characters are lowercase → valid.  
4. If the first character is uppercase and all remaining are lowercase → valid.  
5. Otherwise, return false.  

This ensures all cases are covered in a single pass.

## Complexity
- **Time complexity:** `O(n)` — We traverse the string once.  
- **Space complexity:** `O(1)` — Only a few counters are used, regardless of input size.  

## Code
```java
class Solution {
    public boolean detectCapitalUse(String word) {
        int n = word.length();
        int capcnt = 0; // Capital letter count
        int lowcnt = 0; // Small letter count
        
        for (int i = 0; i < n; i++) {
            char currChar = word.charAt(i);
            if (Character.isUpperCase(currChar)) capcnt++;
            else lowcnt++;
        }

        if (capcnt == n) return true;  // All uppercase
        else if (lowcnt == n) return true;  // All lowercase
        else if (Character.isUpperCase(word.charAt(0)) && (lowcnt == n - 1)) return true; // First uppercase, rest lowercase
        return false;
    }
}
