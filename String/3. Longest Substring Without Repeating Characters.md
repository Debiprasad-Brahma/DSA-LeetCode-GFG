# 🔥 Longest Substring Without Repeating Characters (Sliding Window + HashSet)

---

## 🧠 Intuition

The problem asks for the length of the longest substring without repeating characters.

A brute-force solution would generate all substrings and check whether each one contains duplicate characters. That approach would take **O(n²)** time, which is not efficient for large inputs.

Instead, we can observe:

- We are dealing with a **substring**, so elements must be contiguous.
- We only need to ensure that the current window contains **unique characters**.
- If a duplicate appears, we should shrink the window from the left until the duplicate is removed.

This naturally leads to using a **Sliding Window** technique along with a **HashSet** for fast duplicate checking.

---

## 🚀 Approach

We maintain two pointers:

- `l` → Left pointer (start of the window)
- `r` → Right pointer (end of the window)

We also use a `HashSet<Character>` to store the characters currently inside the window.

### Algorithm Steps:

1. Initialize:
   - `l = 0`
   - `r = 0`
   - `HashSet<Character> set`
   - `ans = 0`

2. Traverse the string using the right pointer (`r`):

   - Get the current character:
     ```java
     char ch = s.charAt(r);
     ```

3. If the character already exists in the set:
   - Shrink the window from the left
   - Remove characters until the duplicate is removed
   - Move `l` forward

4. Once no duplicate remains:
   - Add the character to the set
   - Update the maximum length:
     ```java
     ans = Math.max(ans, r - l + 1);
     ```

5. Move `r` forward and continue.

The window always maintains **unique characters only**.

---

## 💻 Code

```java
class Solution {

    public int lengthOfLongestSubstring(String s) {
        int l = 0;
        int r = 0;
        HashSet<Character> set = new HashSet<>();
        int ans = 0;

        while (r < s.length()) {
            char ch = s.charAt(r);

            while (set.contains(ch)) {
                set.remove(s.charAt(l));
                l++;
            }

            set.add(ch);
            ans = Math.max(ans, r - l + 1);
            r++;
        }
        
        return ans;
    }
}

```

---

## ⏱ Complexity Analysis

### Time Complexity:
**O(n)**

Each character is:
- Added to the set at most once
- Removed from the set at most once

So overall operations are linear.

---

### Space Complexity:
**O(min(n, m))**

Where:
- `n` = length of the string  
- `m` = size of the character set (e.g., 128 for ASCII)

In the worst case, the set stores all unique characters from the string.

---

## 🔎 Key Takeaway

This is a classic **Variable Size Sliding Window** problem.

Whenever you see:
- Longest/shortest substring
- Contiguous segment
- Condition on characters

Think → **Two Pointers + HashSet/HashMap**
