# 🚀 Buddy Strings | Two Pointers + HashSet | O(n) Time, O(1) Space

## Intuition
We need to check if we can make two strings `s` and `goal` equal by swapping exactly **one pair of characters** in `s`.  
There are a few cases to handle:
1. If `s` and `goal` have different lengths, they can never match.  
2. If `s` already equals `goal`, then the only way they can be buddy strings is if `s` contains **at least one duplicate character** (so swapping duplicates keeps the string the same).  
3. Otherwise, track the indices where characters differ. For buddy strings to be valid, there must be **exactly two mismatches**, and swapping them should make the strings equal.  

---

## Approach
1. **Check lengths**: If `s` and `goal` have different lengths → return `false`.  
2. **Case 1: Strings are equal**  
   - Use a `HashSet` to check if there’s any duplicate character.  
   - If duplicates exist → return `true`. Otherwise → `false`.  
3. **Case 2: Strings are different**  
   - Store indices where characters differ.  
   - If mismatches ≠ 2 → return `false`.  
   - If exactly 2 mismatches → check if swapping makes them equal.  

---

## Complexity
- **Time Complexity:**  
  We scan both strings once → **O(n)**.  
- **Space Complexity:**  
  HashSet + mismatch list → **O(1)** (since alphabet is fixed, max 26 for lowercase).  

---

## Code
```java
class Solution {
    public boolean buddyStrings(String s, String goal) {
        int m = s.length();
        int n = goal.length();

        // 1st edge case
        if (m != n) return false;

        // 2nd edge case
        if (s.equals(goal)) {
            Set<Character> temp = new HashSet<>();
            for (char c : s.toCharArray()) {
                temp.add(c);
            }
            return temp.size() < goal.length();
        }

        ArrayList<Integer> arr = new ArrayList<>();
        for (int i = 0; i < m; i++) {
            if (s.charAt(i) != goal.charAt(i))
                arr.add(i);
        }

        if (arr.size() != 2) return false;

        return s.charAt(arr.get(0)) == goal.charAt(arr.get(1)) &&
               s.charAt(arr.get(1)) == goal.charAt(arr.get(0));
    }
}
