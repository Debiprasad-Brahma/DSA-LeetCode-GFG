## 🔤 LeetCode 1832 — Check if the Sentence Is Pangram | ArrayList Approach

### 💡 Intuition
A **pangram** is a sentence that contains **every letter of the English alphabet** at least once.  
To check this, we just need to verify that the string has **all 26 unique letters (a–z)**.

---

### 🧠 Approach
1. Initialize an `ArrayList<Character>` to keep track of unique letters found.  
2. Traverse through each character of the sentence:
   - If the character is **not already in the list**, add it.
3. At the end, if the list size is **26**, it means every alphabet letter appeared → return `true`.  
   Otherwise, return `false`.

---

### ⏱️ Complexity
- **Time Complexity:** O(n²) — because `list.contains(ch)` takes O(n) for each character.  
- **Space Complexity:** O(1) — the list size is limited to 26 unique characters.

💡 **Optimization Tip:**  
Use a `HashSet<Character>` instead of an `ArrayList` to make lookup O(1), reducing total time to O(n).

---

### 💻 Code
```java
class Solution {
    public boolean checkIfPangram(String sentence) {
        int n = sentence.length();
        ArrayList<Character> list = new ArrayList<>();

        for (char ch : sentence.toCharArray()) {
            if (!list.contains(ch))
                list.add(ch);
        }

        return list.size() == 26 ? true : false;
    }
}
