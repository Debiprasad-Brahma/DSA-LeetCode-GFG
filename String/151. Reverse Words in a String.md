# 🔄 Reverse Words in a String (Stack Approach | Java)

## Intuition

The task is to reverse the order of words in a string while removing extra spaces.  
Instead of reversing characters directly, we can think of the string as a collection of **words separated by spaces**.

A convenient way to reverse the order of words is to use a **stack**:

- Stacks follow **Last-In-First-Out (LIFO)**.
- If we push words into the stack as we read them, popping them later will automatically give the words in **reverse order**.

We also ensure that:
- Multiple spaces between words are ignored.
- Leading and trailing spaces are removed.

---

## Approach

1. Create:
   - A `Stack<String>` to store words.
   - A `StringBuilder` to build words while scanning the string.

2. Traverse the string character by character:
   - If the character is not a space, append it to `StringBuilder`.
   - If a space is encountered and `StringBuilder` contains a word, push the word into the stack and reset the builder.

3. After finishing the traversal:
   - Push the last word into the stack if it exists.

4. Pop all words from the stack and append them to `StringBuilder`:
   - Add a space between words.

5. Return the final string.

---

## Complexity

- **Time complexity:**  
  $$O(n)$$  
  We traverse the string once and process each word once.

- **Space complexity:**  
  $$O(n)$$  
  Extra space is used for the stack and the output string.

---

## Code

```java
class Solution {

    public String reverseWords(String s) {
        Stack<String> stk = new Stack<>();
        StringBuilder str = new StringBuilder();

        int n = s.length();

        for (int i = 0; i < n; i++) {
            char ch = s.charAt(i);

            if (ch == ' ') {
                if (str.length() > 0) {
                    stk.push(str.toString());
                    str.setLength(0);
                }
            } else {
                str.append(ch);
            }
        }

        if (str.length() > 0) {
            stk.push(str.toString());
        }

        str.setLength(0);

        while (!stk.isEmpty()) {
            str.append(stk.pop());
            if (!stk.isEmpty()) {
                str.append(" ");
            }
        }

        return str.toString();
    }
}
