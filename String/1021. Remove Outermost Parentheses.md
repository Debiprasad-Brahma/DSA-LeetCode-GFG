# 1021. Remove Outermost Parentheses

## Problem Statement
You are given a valid parentheses string `s`.  
A valid parentheses string is either:
- `"()"`, or  
- a concatenation of two valid parentheses strings, or  
- wrapped by a pair of parentheses around a valid parentheses string.  

The **primitive** valid parentheses string is one that is not the concatenation of two non-empty valid parentheses strings.  

Your task is to **remove the outermost parentheses** of every primitive string in the given `s`.

---

## Intuition
When reading the string character by character:
- A primitive starts when the first `'('` of that primitive is encountered (depth changes from 0 to 1).
- A primitive ends when the last `')'` of that primitive is encountered (depth changes from 1 to 0).
- We only want to keep characters **inside** these outermost parentheses.
- We can track the current depth using a counter:
  - Increment for `'('`.
  - Decrement for `')'`.
- Append the character **only when the depth is not zero** after processing it.

---

## Approach
1. Initialize:
   - `StringBuilder ans` → to store the final string.
   - `count` → to track the depth of parentheses.
2. Loop over each character in `s` (except the last one if needed for logic):
   - If the current character is `')'`, **decrement** `count` first (closing step).
   - If `count` is not zero, append the current character to `ans` (means it’s not an outermost one).
   - If the current character is `'('`, **increment** `count` after appending logic (opening step).
3. Return the built string.

---

## Code with Comments
```java
class Solution {
    public String removeOuterParentheses(String s) {
        StringBuilder ans = new StringBuilder();
        int count = 0; // Tracks depth of parentheses

        // Iterate over the string
        for (int i = 0; i < s.length(); i++) {
            // If we find a closing bracket, decrease depth first
            if (s.charAt(i) == ')') count--;

            // Append character if we are inside an inner layer
            if (count != 0) ans.append(s.charAt(i));

            // If we find an opening bracket, increase depth after appending logic
            if (s.charAt(i) == '(') count++;
        }

        return ans.toString();
    }
}
