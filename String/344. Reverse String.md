## 🔄 LeetCode 344 — Reverse String | Two-Pointer Approach

### 💡 Intuition
We need to reverse a given array of characters **in place**, meaning no extra array or data structure should be used.  
The most straightforward way is to use **two pointers**:
- One starting at the beginning.
- One starting at the end.

By swapping the characters at these pointers and moving them toward each other, we can reverse the string efficiently.

---

### 🧠 Approach
1. Initialize two pointers:
   - `start = 0`
   - `end = s.length - 1`
2. Swap characters at these positions.
3. Move `start++` and `end--` after each swap.
4. Continue until both pointers meet or cross each other.
5. Since the array is modified in place, no need to return anything.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — each character is swapped at most once.  
- **Space Complexity:** O(1) — reversal done in place, no extra memory used.

---

### 💻 Code
```java
class Solution {

    public void reverseString(char[] s) {
        int start = 0;
        int end = s.length - 1;

        while (start <= end) {
            char temp = s[start];
            s[start] = s[end];
            s[end] = temp;

            start++;
            end--;
        }
    }
}
