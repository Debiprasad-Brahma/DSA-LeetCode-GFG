# ✅ Two Pointers Approach | Easy & Efficient Solution for "Is Subsequence"

# Intuition
We need to check if string `s` is a subsequence of string `t`.  
A subsequence means all characters of `s` should appear in `t` **in order**, but not necessarily consecutively.  

# Approach
We can solve this problem using the **two-pointer technique**:  
- Use two pointers `i` for `s` and `j` for `t`.  
- Traverse through `t` using `j`.  
- Whenever `s.charAt(i)` matches `t.charAt(j)`, move both `i` and `j`.  
- Otherwise, move only `j`.  
- Keep a `count` of matches.  
- At the end, if `count == s.length()`, then `s` is a subsequence of `t`.  

# Complexity
- **Time Complexity:**  
  We only traverse through `t` once → **O(n)** where `n` is the length of `t`.  

- **Space Complexity:**  
  We only use a few variables (`i`, `j`, `count`) → **O(1)**.  

# Code
```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int m = s.length();
        int n = t.length();

        int i = 0, j = 0, count = 0;
        while (j < n) {
            if (i < m && (s.charAt(i) == t.charAt(j))) {
                i++;
                j++;
                count++;
            }
            else
                j++;
        }
        return count == m ? true : false;
    }
}
