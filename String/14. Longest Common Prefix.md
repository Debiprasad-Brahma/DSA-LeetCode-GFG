# 🔥 Longest Common Prefix | Sort Trick O(N log N) | No Trie Needed | Clean & Clever Approach

---

## 💡 Intuition

Most people loop through **all strings** comparing character by character — works, but verbose.

> The key insight: **After sorting lexicographically, only the FIRST and LAST strings matter.**

Why? Because sorting brings the **most different** strings to the two ends. If a prefix is common to the first and last string, it's guaranteed to be common to **every string in between**.

Think of it like a classroom sorted by name — the common prefix between "Alice" and "Almond" covers everyone between them.

---

## 🧠 Approach — Sort + Compare Extremes

1. **Sort** the array lexicographically.
2. Take `firstStr = strs[0]` and `lastStr = strs[strs.length - 1]`.
3. Compare characters of both strings **position by position**.
4. Stop as soon as characters **differ** → return what's built so far.
5. If loop finishes → entire shorter string is the common prefix.

---

## 📊 Dry Run

```
strs = ["flower", "flow", "flight"]
```

**After Sort:** `["flight", "flow", "flower"]`

| i | firstStr[i] | lastStr[i] | Match? |
|---|-------------|------------|--------|
| 0 | f           | f          | ✅ → ans = "f" |
| 1 | l           | l          | ✅ → ans = "fl" |
| 2 | i           | o          | ❌ → return "fl" |

**Output:** `"fl"` ✅

---

## 🧪 Edge Cases

```
strs = ["dog","racecar","car"]  →  ""     (no common prefix)
strs = ["same","same","same"]  →  "same" (all identical)
strs = ["a"]                   →  "a"    (single element)
strs = ["ab","a"]              →  "a"    (shorter string is prefix)
```

---

## ✅ Code (Java)

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        Arrays.sort(strs);                          // Lexicographic sort
        StringBuilder ans = new StringBuilder();

        String firstStr = strs[0];                  // Lexicographically smallest
        String lastStr  = strs[strs.length - 1];    // Lexicographically largest

        // Only compare the two extremes — middle strings are covered
        for (int i = 0; i < Math.min(firstStr.length(), lastStr.length()); i++) {
            if (firstStr.charAt(i) != lastStr.charAt(i)) {
                return ans.toString();              // Mismatch → stop here
            }
            ans.append(firstStr.charAt(i));         // Common character found
        }
        return ans.toString();
    }
}
```

## ⏱ Complexity Analysis

| | Complexity | Reason |
|---|---|---|
| **Time** | O(N log N + M) | Sorting = O(N log N), prefix scan = O(M) where M = min string length |
| **Space** | O(1) | No extra data structures (StringBuilder is output) |

> 💡 **N** = number of strings, **M** = length of shortest string

## 🔁 Other Approaches — Know All for Interviews

| Approach | Time | Space | Idea |
|---|---|---|---|
| **Sort + Compare Extremes** ✅ | O(N log N) | O(1) | This solution — cleanest |
| **Horizontal Scanning** | O(N·M) | O(1) | Compare prefix with each string one by one |
| **Vertical Scanning** | O(N·M) | O(1) | Column by column across all strings |
| **Divide & Conquer** | O(N·M) | O(M log N) | Split array, merge common prefixes |
| **Trie** | O(N·M) | O(N·M) | Insert all → traverse until branch |

> 🎯 **Interview tip:** Mention the Trie approach as a follow-up for dynamic prefix queries — shows depth!

## 🔑 Why Does Sorting Work? (The Proof Interviewers Love)

```
Sorted order guarantees:  firstStr ≤ every string ≤ lastStr

So:  common_prefix(first, last) ⊆ common_prefix(all strings)
And: common_prefix(all strings) ⊆ common_prefix(first, last)

Therefore: common_prefix(first, last) == common_prefix(all strings) ✅
```

Being able to **explain WHY** this works sets you apart in interviews.

## 📌 Key Takeaways (Revision Flashcard)

- 🟡 **Sort reduces the problem** — only extremes matter after sorting
- 🟡 **Lexicographic sort** places most-different strings at ends
- 🟡 Compare **first vs last** string only — O(M) scan instead of O(N·M)
- 🟡 Return early on **first mismatch** — no need to scan full strings
- 🟡 Time: **O(N log N)** | Space: **O(1)**
