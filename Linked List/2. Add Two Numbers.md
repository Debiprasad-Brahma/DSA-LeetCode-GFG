# 🚀 LeetCode Problem: Add Two Numbers (Linked List)

## Intuition
We are given two non-empty linked lists that represent two non-negative integers, where each node contains a single digit and the digits are stored in reverse order.  
The task is to add these two numbers and return the result as a new linked list, also in reverse order.  

The idea is to **simulate digit-by-digit addition** (like elementary school math), while keeping track of the carry.

---

## Approach
1. Create a dummy node to easily build the result linked list.  
2. Use a pointer (`curr`) to track the current position in the result list.  
3. Maintain a `carry` to handle overflow when the sum of digits ≥ 10.  
4. Traverse both linked lists (`l1` and `l2`) until both are fully processed:
   - Initialize `sum = carry`.  
   - If `l1` exists, add its value to `sum` and move `l1` forward.  
   - If `l2` exists, add its value to `sum` and move `l2` forward.  
   - Create a new node with value `sum % 10` and attach it to the result list.  
   - Update `carry = sum / 10`.  
5. After traversal, if `carry > 0`, append a final node with value `carry`.  
6. Return the list starting from `dummy.next`.

---

## Complexity
- **Time Complexity:**  
  \( O(\max(m, n)) \)  
  We iterate through both linked lists once.

- **Space Complexity:**  
  \( O(\max(m, n)) \)  
  The result list will have at most `max(m, n) + 1` nodes.

---

## Code
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(-1);
        ListNode curr = dummy;
        int carry = 0;

        while (l1 != null || l2 != null) {
            int sum = carry;

            if (l1 != null) {
                sum += l1.val;
                l1 = l1.next;
            }

            if (l2 != null) {
                sum += l2.val;
                l2 = l2.next;
            }

            ListNode node = new ListNode(sum % 10);
            carry = sum / 10;

            curr.next = node;
            curr = curr.next;
        }

        if (carry != 0) {
            curr.next = new ListNode(carry);
        }

        return dummy.next;
    }
}
