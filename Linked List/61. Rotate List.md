# 🔄 Rotate List | Circular Linked List Trick | O(n) Time

## Intuition
To rotate a linked list to the right by `k` places, we can think of the list as a **circle**:
- Connect the tail to the head to form a cycle.
- Then find the new head and break the cycle at the correct spot.

This avoids shifting nodes one by one, which would be inefficient.

---

## Approach
1. **Find the length and tail**:
   - Traverse the list once to find its length `n` and tail node.
   - Connect tail → head to form a circular list.
2. **Normalize k**:
   - Since rotating by `n` results in the same list, use `k = k % n`.
3. **Find the new tail**:
   - The new tail will be at position `(n - k)` from the start.
   - Traverse `(n - k)` steps from the old tail to reach the new tail.
4. **Break the cycle**:
   - The node after the new tail becomes the new head.
   - Break the link to restore a proper singly linked list.
5. Return the new head.

---

## Complexity
- **Time Complexity:** **O(n)** → single pass to calculate length + another to find new tail.  
- **Space Complexity:** **O(1)** → no extra data structures used.  

---

## Code
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode rotateRight(ListNode head, int k) {
        if (head == null || head.next == null || k == 0) return head;

        // Step 1: Find length and tail
        ListNode tail = head;
        int n = 1;
        while (tail.next != null) {
            tail = tail.next;
            n++;
        }

        // Step 2: Make circular
        tail.next = head;

        // Step 3: Normalize k
        k = k % n;
        int step = n - k;

        // Step 4: Find new tail
        ListNode newTail = tail;
        while (step-- > 0) {
            newTail = newTail.next;
        }

        // Step 5: Break the circle
        head = newTail.next;
        newTail.next = null;

        return head;
    }
}
