# 🔗 LeetCode 160 — Intersection of Two Linked Lists

### 🧠 Intuition  
We need to find the **intersection node** of two singly linked lists — the point where both lists converge (share the same reference, not just equal values).

Instead of calculating lengths or using extra space, we can use a **two-pointer technique** that cleverly aligns the traversal lengths of both lists.

---

### 💡 Approach  
1. Use two pointers:
   - `head1` starts at the head of List A.  
   - `head2` starts at the head of List B.  

2. Traverse both lists simultaneously:
   - When a pointer reaches the **end** of its list, redirect it to the **head of the other list**.
   - This ensures both pointers travel the **same total distance** — the combined length of A and B.

3. Eventually:
   - If there’s an intersection, both pointers will meet at that node.  
   - If not, both will reach `null` simultaneously.

---

### ⏱️ Complexity  
- **Time Complexity:** `O(m + n)` — Each list is traversed twice at most.  
- **Space Complexity:** `O(1)` — No extra memory used.

---

### ✅ Code  
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {

    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        if (headA == null || headB == null) return null;

        ListNode head1 = headA;
        ListNode head2 = headB;

        // Traverse until both pointers meet or reach null
        while (head1 != head2) {
            head1 = head1 != null ? head1.next : headB;
            head2 = head2 != null ? head2.next : headA;
        }

        // Either intersection node or null
        return head1;
    }
}
