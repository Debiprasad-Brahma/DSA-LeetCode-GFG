# Leet Code:- 83. Remove Duplicates from Sorted List
## 🧠 Intuition  
The task is to remove duplicate nodes from a sorted linked list.  
Since the list is already sorted, any duplicates will appear consecutively.  
So, we can simply compare each node with its next node and skip any duplicates we find.

---

## 💡 Approach  
1. Initialize a pointer `temp` starting from the head of the linked list.  
2. Traverse the list while `temp` and `temp.next` are not null.  
3. For each node:
   - If the current node’s value equals the next node’s value, skip the next node by adjusting the `next` pointer.  
   - Otherwise, move the pointer forward.  
4. Continue this process until the end of the list.  
5. Return the head of the modified list.

This approach efficiently removes duplicates **in one traversal** without using any extra space.

---

## ⏱️ Complexity  
- **Time Complexity:** `O(n)`  
  Each node is visited once.  
- **Space Complexity:** `O(1)`  
  The operation is performed in place using only a few pointers.

---

## 🧩 Code  
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode deleteDuplicates(ListNode head) {
        ListNode temp = head;

        while (temp != null && temp.next != null) {
            if (temp.val == temp.next.val)
                temp.next = temp.next.next;
            else
                temp = temp.next;
        }
        return head;
    }
}
