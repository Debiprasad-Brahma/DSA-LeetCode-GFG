# LeetCode - Add Two Numbers II (Problem 445)

## Intuition
In this version, the digits of the two numbers are stored in **forward order**.  
We need to add them and return the sum as a linked list, also in forward order.  

The direct digit-by-digit addition is tricky since addition usually happens from the **least significant digit** (rightmost).  
To handle this, we **reverse both input lists**, perform the normal addition like in Problem 2, and then reverse the result again.

---

## Approach
1. **Reverse both lists** (`l1` and `l2`) so digits become aligned from least significant to most significant.  
2. Initialize:
   - `dummy` node for easy result construction.  
   - `carry = 0`.  
3. Traverse both reversed lists until both are null:
   - Start with `sum = carry`.  
   - If `l1` exists, add its value and move forward.  
   - If `l2` exists, add its value and move forward.  
   - Create a new node with value `sum % 10`.  
   - Update `carry = sum / 10`.  
   - Attach the new node to the result list.  
4. After traversal, if `carry > 0`, append a new node.  
5. Finally, **reverse the result list** to restore forward order.  

---

## Complexity
- **Time Complexity:** `O(m + n)`  
  We reverse both lists (`O(m + n)`), traverse them once, and reverse the result.  
- **Space Complexity:** `O(m + n)`  
  Output list has at most `max(m, n) + 1` nodes.  

---

## Code
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverse(ListNode head){
        ListNode curr = head, prev = null, next;
        while(curr != null){
            next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        return prev;
    }

    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        // Step 1: Reverse both lists
        l1 = reverse(l1);
        l2 = reverse(l2);

        ListNode dummy = new ListNode(-1);
        ListNode curr = dummy;
        int carry = 0;

        // Step 2: Add digits
        while(l1 != null || l2 != null){
            int sum = carry;
            if(l1 != null){ sum += l1.val; l1 = l1.next; } 
            if(l2 != null){ sum += l2.val; l2 = l2.next; }

            curr.next = new ListNode(sum % 10);
            carry = sum / 10;
            curr = curr.next;
        }

        // Step 3: Handle leftover carry
        if(carry != 0){
            curr.next = new ListNode(carry);
        }

        // Step 4: Reverse the result to restore forward order
        return reverse(dummy.next);       
    }
}
