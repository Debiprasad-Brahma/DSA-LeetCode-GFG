# Remove Nodes from Linked List Based on Array

## Problem
Given a singly-linked list `head` and an integer array `nums`, remove all nodes from the linked list whose values appear in `nums`.  
Return the modified linked list.

---

## Intuition
We need to **filter out nodes** whose values are present in `nums`.  
A simple approach is to traverse the list and add only the nodes **not in nums** to a new list.

---

## Approach
1. Store all numbers in `nums` inside a `HashSet` for **O(1) lookup**.  
2. Create a `dummy` node to simplify edge cases and maintain the new list.  
3. Traverse the original linked list:
   - If `curr.val` is **not in the set**, create a new node with the same value and attach it to the new list.  
   - Otherwise, skip the node.  
   - Move `curr` forward in every iteration.  
4. Return `dummy.next` as the new head of the filtered list.

---

## Complexity
- **Time Complexity:** `O(n + m)`  
  - `n` = length of the linked list  
  - `m` = length of the `nums` array  
  - Building the `HashSet` takes O(m), traversing the list takes O(n).  

- **Space Complexity:** `O(n + m)`  
  - `HashSet` stores all elements of `nums` (O(m)).  
  - New linked list nodes are created for filtered elements (O(n) in worst case).  

---

## Code
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode modifiedList(int[] nums, ListNode head) {

        HashSet<Integer> arr = new HashSet<>();
        for (int num : nums) {
            arr.add(num);
        }

        ListNode dummy = new ListNode(-1);
        ListNode temp = dummy;
        ListNode curr = head;

        while(curr != null){
            if (!arr.contains(curr.val)) {
                ListNode node = new ListNode(curr.val);
                temp.next = node; 
                temp = temp.next;
            }
            curr = curr.next;
        }

        return dummy.next;
    }
}
