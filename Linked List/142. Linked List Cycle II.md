# 🐢🐇 Detect Cycle in Linked List (Floyd’s Cycle Detection)

## Intuition

If a linked list contains a cycle, two pointers moving at different speeds will eventually meet inside the cycle.

This idea is known as **Floyd’s Cycle Detection Algorithm (Tortoise and Hare Algorithm)**.

- A **slow pointer** moves one step at a time.
- A **fast pointer** moves two steps at a time.

If there is **no cycle**, the fast pointer will eventually reach `null`.  
If there **is a cycle**, the fast pointer will lap the slow pointer and they will meet.

Once the meeting point is found, we can determine the **starting node of the cycle** by resetting one pointer to the head and moving both pointers one step at a time.

The node where they meet again is the **start of the cycle**.

---

## Approach

1. Initialize two pointers:
   - `slow` → moves one step
   - `fast` → moves two steps

2. Traverse the linked list:
   - Move `slow = slow.next`
   - Move `fast = fast.next.next`
   - If they meet, a cycle exists.

3. To find the start of the cycle:
   - Move `slow` back to `head`.
   - Move both `slow` and `fast` one step at a time.

4. The node where they meet again is the **starting node of the cycle**.

5. If the loop finishes without the pointers meeting, return `null` because there is **no cycle**.

---

## Complexity

- **Time complexity:**  
  $$O(n)$$  
  Each pointer traverses the list at most a constant number of times.

- **Space complexity:**  
  $$O(1)$$  
  No extra data structures are used; only two pointers are required.

---

## Code

```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode detectCycle(ListNode head) {
        if (head == null || head.next == null) return null;

        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;

            if (slow == fast) {
                slow = head;

                while (slow != fast) {
                    slow = slow.next;
                    fast = fast.next;
                }
                return slow;
            }
        }

        return null;
    }
}
