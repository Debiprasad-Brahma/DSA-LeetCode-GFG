## 🔗 LeetCode 21 — Merge Two Sorted Lists | Iterative Linked List Approach

### 💡 Intuition
We are given two sorted linked lists `list1` and `list2`.  
The goal is to **merge them into a single sorted linked list** and return its head.

This can be efficiently achieved by using a **dummy node** and iteratively comparing nodes from both lists.

---

### 🧠 Approach
1. Create a **dummy node** to serve as a placeholder for the head of the merged list.  
   - It simplifies edge cases where the merged list might start from either `list1` or `list2`.
2. Use a pointer `cur` to track the end of the new merged list.
3. Compare the current nodes of both lists:
   - If `list1.val <= list2.val`, attach `list1` to `cur.next` and move `list1` forward.
   - Else, attach `list2` to `cur.next` and move `list2` forward.
4. Move `cur` to `cur.next` each time.
5. When one list ends, attach the remaining part of the other list.
6. Return `dummy.next` (skipping the dummy node).

---

### ⏱️ Complexity
- **Time Complexity:** O(n + m) — each list node is visited once.  
- **Space Complexity:** O(1) — iterative approach uses constant extra space.

---

### 💻 Code
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {

    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        ListNode dummy = new ListNode();
        ListNode cur = dummy;

        while (list1 != null && list2 != null) {
            if (list1.val > list2.val) {
                cur.next = list2;
                list2 = list2.next;
            } else {
                cur.next = list1;
                list1 = list1.next;
            }
            cur = cur.next;
        }

        cur.next = (list1 != null) ? list1 : list2;

        return dummy.next;
    }
}
