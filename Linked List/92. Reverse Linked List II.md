# 🧠 Intuition

The problem asks us to reverse a portion of a singly linked list between two positions `left` and `right` (1-indexed).

Instead of extracting the sublist and reversing it separately, we can reverse it **in-place** in one pass.

The key idea is:

- Use a **dummy node** to simplify edge cases (especially when `left = 1`).
- Move a pointer (`prev`) to the node just before position `left`.
- Then repeatedly take the next node and insert it at the beginning of the sublist.
  
This technique is often called the **head-insertion method**.

---

# 🚀 Approach

1. Create a dummy node pointing to `head`.
2. Move `prev` to the node just before position `left`.
3. Let `curr = prev.next` (this is the first node of the sublist).
4. For `right - left` times:
   - Take `curr.next`
   - Move it right after `prev`
   - Adjust pointers accordingly
5. Return `dummy.next`

This reverses the required portion in-place without using extra space.

# Code
```java []
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {

    public ListNode reverseBetween(ListNode head, int left, int right) {
        if (head == null || head.next == null) return head;

        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;

        for (int i = 1; i < left; i++) {
            prev = prev.next;
        }

        ListNode curr = prev.next;

        for (int i = 1; i <= right - left; i++) {
            ListNode temp = prev.next;
            prev.next = curr.next;
            curr.next = curr.next.next;
            prev.next.next = temp;
        }

        return dummy.next;
    }
}

```
