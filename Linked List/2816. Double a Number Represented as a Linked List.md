# Intuition
We are given a number represented as a linked list, where each node contains a single digit.  
The task is to **double the number** and return it as a linked list.  

A straightforward way is:
1. Reverse the list so we can process digits from least significant to most significant.  
2. Traverse through the list, double each digit, and handle carry.  
3. If there’s any remaining carry at the end, append it.  
4. Finally, reverse the list back to restore the original order.  

---

# Approach
1. **Reverse the linked list** → so that the least significant digit comes first and we can easily handle carry.  
2. **Traverse the list**:
   - Multiply the current digit by 2 and add the carry.  
   - Store `mul % 10` as the new digit.  
   - Update `carry = mul / 10`.  
3. **Handle leftover carry**:
   - If after finishing traversal carry > 0, create a new node for it.  
4. **Reverse the list back** → to get the final doubled number in correct order.  

---

# Complexity
- **Time complexity:**  
  Each node is processed once for doubling and twice for reversing, so total is  
  \[
  O(n)
  \]  

- **Space complexity:**  
  Only a few extra pointers and dummy node are used, so  
  \[
  O(1)
  \] (ignoring recursion since we don’t use it).  

---

# Code
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {

    ListNode reverse(ListNode head){
        ListNode curr = head, prev = null, next;
        while(curr != null){
            next = curr.next;
            curr.next = prev;
            prev = curr;
            curr = next;
        }
        return prev;
    }

    public ListNode doubleIt(ListNode head) {
        head = reverse(head);

        ListNode dummy = new ListNode(-1);
        ListNode curr = dummy;
        int carry = 0;
       
        while(head != null){
            int mul = carry + 2 * head.val;
            head = head.next;

            ListNode node = new ListNode(mul % 10);
            carry = mul / 10;

            curr.next = node;
            curr = curr.next;
        }

        if(carry != 0){
            curr.next = new ListNode(carry);
        }

        return reverse(dummy.next);
    }
}
