## 🔁 LeetCode 234 — Palindrome Linked List | ArrayList Comparison Approach

### 💡 Intuition
A **palindrome** is a sequence that reads the same forward and backward.  
To check if a linked list is a palindrome, we can store its elements in a list and compare corresponding values from both ends.

This solution converts the linked list into an `ArrayList`, making element access simple with indices.

---

### 🧠 Approach
1. Traverse the linked list and store all node values in an `ArrayList<Integer>`.
2. Use **two pointers**:
   - `i` starts from the beginning (0)
   - `j` starts from the end (arr.size() - 1)
3. Compare values at both ends:
   - If at any point `arr[i] != arr[j]`, return `false`.
4. If the loop completes without mismatches, return `true`.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — one pass to collect elements and one to compare.  
- **Space Complexity:** O(n) — for storing list elements in an `ArrayList`.

---

### 💻 Code
```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {

    public boolean isPalindrome(ListNode head) {
        List<Integer> arr = new ArrayList<>();
        ListNode temp = head;

        // Step 1: Store linked list values in an array
        while (temp != null) {
            arr.add(temp.val);
            temp = temp.next;
        }

        // Step 2: Two-pointer palindrome check
        int i = 0;
        int j = arr.size() - 1;

        while (i <= j) {
            if (!arr.get(i).equals(arr.get(j))) 
                return false;
            i++;
            j--;
        }

        return true;
    }
}
