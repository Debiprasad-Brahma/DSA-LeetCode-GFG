## 📉 LeetCode 1338 — Reduce Array Size to The Half

### Intuition  
We want to remove the **minimum number of distinct elements** from the array so that **at least half of the array elements are removed**.

Key idea:
- Removing a number removes **all its occurrences**
- So to reduce the array size quickly, we should remove numbers with the **highest frequencies first**

This naturally leads to a **greedy approach**:
> Always remove the most frequent elements first.

---

### Approach  
1. Count the frequency of each number using a `HashMap`.
2. Store all frequencies in a list.
3. Sort the frequency list in **descending order**.
4. Start removing elements (adding frequencies) from the largest frequency:
   - Keep a running sum of removed elements
   - Stop once the removed count is **at least half of the array size**
5. Return how many distinct numbers were removed.

---

### Time & Space Complexity  
- **Time Complexity:** O(n log n)  
  - Frequency count: O(n)  
  - Sorting frequencies: O(n log n)
- **Space Complexity:** O(n)  
  - HashMap + frequency list

---

### Code  
```java
class Solution {

    public int minSetSize(int[] arr) {
        int n = arr.length;

        HashMap<Integer, Integer> map = new HashMap<>();

        // Add values to map
        for (int num : arr) map.put(num, map.getOrDefault(num, 0) + 1);

        // store freq of numbers in a arraylist
        List<Integer> freq = new ArrayList<>(map.values());

        // sort that arraylist in desending oreder
        Collections.sort(freq, Collections.reverseOrder());

        int sum = 0;
        int count = 1;
        for (int i = 0; i < freq.size(); i++) {
            sum += freq.get(i);
            if (sum < (n / 2)) {
                count++;
            } else {
                break;
            }
        }

        return count;
    }
}
