## 🔢 LeetCode 167 — Two Sum II (Using HashMap)

### Intuition  
We are given a **sorted array** and a target value.  
The task is to find **two numbers whose sum equals the target** and return their **1-based indices**.

Even though the array is sorted (which allows a two-pointer approach), this solution uses a **HashMap** to directly track previously seen numbers and their indices.

Key idea:
- For each number, check if its **complement** (`target - number`) has already been seen.
- If yes, we’ve found the required pair.

---

### Approach  
1. Create a HashMap to store:
   - `number → index`
2. Traverse the array:
   - For current number `num`, compute `diff = target - num`
   - If `diff` exists in the map:
     - Return indices of `diff` and `num` (convert to 1-based indexing)
   - Otherwise, store `num` with its index in the map
3. Since the problem guarantees exactly one solution, we will always return inside the loop.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(n)

---

### Code  
```java
class Solution {

    public int[] twoSum(int[] numbers, int target) {
        int n = numbers.length;
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < n; i++) {
            int num = numbers[i];
            int diff = target - num;

            if (map.containsKey(diff)) {
                return new int[] { map.get(diff) + 1, i + 1 };
            } else {
                map.put(num, i);
            }
        }

        return null; // Guaranteed solution exists
    }
}
