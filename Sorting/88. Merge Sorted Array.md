# 🧠 Intuition
Both arrays `nums1` and `nums2` are already **sorted in non-decreasing order**.  
The challenge is that `nums1` has extra space at the end to hold the elements of `nums2`.

If we start merging **from the beginning**, elements in `nums1` would get overwritten before they are compared.

To avoid this, we merge **from the end of the arrays**:
- Compare the **largest remaining elements** of both arrays.
- Place the larger element at the **last available position** in `nums1`.

This way we safely fill the array without overwriting useful values.

---

# 🚀 Approach
1. Initialize three pointers:
   - `i = m - 1` → last valid element in `nums1`
   - `j = n - 1` → last element in `nums2`
   - `idx = m + n - 1` → last position of `nums1`

2. Compare elements from the back:
   - If `nums1[i] >= nums2[j]`, place `nums1[i]` at `nums1[idx]`.
   - Otherwise place `nums2[j]` at `nums1[idx]`.

3. Move the respective pointer (`i` or `j`) and decrease `idx`.

4. Continue until one array is exhausted.

5. If elements remain in `nums2`, copy them into `nums1`.

Note: Remaining elements in `nums1` are already in correct position.

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(m + n)$$  
  Each element from both arrays is processed at most once.

- **Space complexity:**  
  $$O(1)$$  
  The merge is performed in-place without using extra space.

---

# 💻 Code
```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        
        int i = m - 1;
        int j = n - 1;
        int idx = m + n - 1;

        while (i >= 0 && j >= 0) {
            int elem1 = nums1[i];
            int elem2 = nums2[j];

            if (elem1 >= elem2) {
                nums1[idx] = elem1;
                i--;
            } else {
                nums1[idx] = elem2;
                j--;
            }
            idx--;
        }

        while (j >= 0) {
            nums1[idx] = nums2[j];
            j--;
            idx--;
        }
    }
}
