## 📚 LeetCode 274 — H-Index

### Intuition  
The **H-index** is defined as the maximum value `h` such that the researcher has **at least `h` papers** with **at least `h` citations each**.

Key observation:
- If the array is sorted in ascending order, then at index `i`:
  - There are `n - i` papers with citations ≥ `citations[i]`
- So if `citations[i] >= (n - i)`, we’ve found a valid `h`
- The **first** such position gives the **maximum** possible H-index

---

### Approach  
1. Sort the `citations` array in ascending order.
2. Traverse the array from left to right:
   - For each index `i`, compute `h = n - i`
   - If `citations[i] >= h`, return `h`
3. If no valid `h` is found, return `0`

---

### Time & Space Complexity  
- **Time Complexity:** O(n log n) — due to sorting  
- **Space Complexity:** O(1) — sorting in place

---

### Code  
```java
class Solution {

    public int hIndex(int[] citations) {
        int n = citations.length;
        Arrays.sort(citations);

        for (int i = 0; i < n; i++) {
            int h = n - i;
            if (citations[i] >= h) {
                return h;
            }
        }

        return 0;
    }
}
