# Intuition

The pivot index is the position where the **sum of elements on the left** 
is equal to the **sum of elements on the right**.

To avoid recalculating sums repeatedly for each index, we precompute:

- A prefix sum array (`leftSum`)
- A suffix sum array (`rightSum`)

If at any index `i`, `leftSum[i] == rightSum[i]`, then `i` is the pivot index.

---

# Approach

1. Create two arrays:
   - `leftSum[i]` → sum of elements from index `0` to `i`
   - `rightSum[i]` → sum of elements from index `n-1` to `i`

2. Build the prefix sum array:
   - Traverse from left to right.
   - Maintain a running sum.
   - Store cumulative sum in `leftSum[i]`.

3. Build the suffix sum array:
   - Traverse from right to left.
   - Maintain a running sum.
   - Store cumulative sum in `rightSum[i]`.

4. Traverse once more:
   - If `leftSum[i] == rightSum[i]`, return `i`.

5. If no such index exists, return `-1`.

---

# Complexity

- **Time Complexity:** O(n)  
  - One pass for prefix sum  
  - One pass for suffix sum  
  - One pass to find pivot  

- **Space Complexity:** O(n)  
  - Two additional arrays of size `n`

# Code
```java []
class Solution {

    public int pivotIndex(int[] nums) {
        int n = nums.length;

        int[] leftSum = new int[n];
        int[] rightSum = new int[n];

        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += nums[i];
            leftSum[i] = sum;
        }

        sum = 0;
        for (int i = n - 1; i >= 0; i--) {
            sum += nums[i];
            rightSum[i] = sum;
        }


        for(int i = 0; i < n; i++){
            if(leftSum[i] == rightSum[i]) return i;
        }

        return -1;
    }
}

```
