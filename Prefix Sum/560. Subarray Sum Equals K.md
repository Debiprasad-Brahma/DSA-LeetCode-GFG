# Intuition  
We need to determine whether there exists a **continuous subarray of length at least 2** whose sum is a multiple of `k`.

Key observation:
If two prefix sums have the same remainder when divided by `k`, then the subarray between them has a sum divisible by `k`.
Mathematically: (prefixSum[j] - prefixSum[i]) % k == 0
⇒ prefixSum[j] % k == prefixSum[i] % k

So we track remainders using a HashMap.

---

# Approach  
- Maintain a running prefix sum.
- Store the first occurrence of each remainder (`sum % k`) in a HashMap.
- If the same remainder appears again and the index difference is greater than 1, return `true`.
- Initialize the map with `(0 → -1)` to handle subarrays starting from index 0.

---

# Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(min(n, k))

---

# Code
```java []
class Solution {

    public int subarraySum(int[] nums, int k) {
        int n = nums.length;

        Map<Integer, Integer> map = new HashMap<>();
        map.put(0, 1);

        int sum = 0;
        int res = 0;

        for (int num : nums) {
            sum += num;
            res += map.getOrDefault(sum - k, 0);
            map.put(sum, map.getOrDefault(sum, 0) + 1);
        }

        return res;
    }
}

```
