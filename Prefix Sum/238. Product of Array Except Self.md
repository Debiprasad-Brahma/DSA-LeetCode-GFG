# 🧠 Intuition
The goal is to compute an array where each element at index `i` is the **product of all elements except `nums[i]`**, **without using division**.

Instead of recalculating the product for every index (which would be \(O(n^2)\)), we can break the problem into two parts:
- Product of all elements **to the left** of index `i`
- Product of all elements **to the right** of index `i`

So for each index:
answer[i] = (product of elements before i) * (product of elements after i)

To achieve this efficiently:
- Build a **prefix product array (leftProd)**
- Build a **suffix product array (rightProd)**

---

# 🚀 Approach
1. Create two arrays:
   - `leftProd[i]` → product of elements from `0` to `i`
   - `rightProd[i]` → product of elements from `i` to `n-1`

2. Fill `leftProd`:
   - Traverse left → right
   - Keep multiplying elements

3. Fill `rightProd`:
   - Traverse right → left
   - Keep multiplying elements

4. Build result:
   - For index `i`:
     - If `i == 0` → only right side exists → `rightProd[i+1]`
     - If `i == n-1` → only left side exists → `leftProd[i-1]`
     - Else → `leftProd[i-1] * rightProd[i+1]`

5. Store result directly in `nums` and return it.

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(n)$$  
  Three linear passes over the array.

- **Space complexity:**  
  $$O(n)$$  
  Two extra arrays (`leftProd` and `rightProd`) are used.

---

# Code
```java []
class Solution {

    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;

        int[] leftProd = new int[n];
        int[] rightProd = new int[n];

        int prod = 1;
        for (int i = 0; i < n; i++) {
            prod *= nums[i];
            leftProd[i] = prod;
        }

        prod = 1;
        for (int i = n - 1; i >= 0; i--) {
            prod *= nums[i];
            rightProd[i] = prod;
        }

        int[] ans = new int[n];

        for (int i = 0; i < n; i++) {
            if (i == 0) {
                ans[i] = rightProd[i + 1];
            } else if (i == n - 1) {
                ans[i] = leftProd[n - 1 - 1];
            } else {
                ans[i] = rightProd[i + 1] * leftProd[i - 1];
            }
        }

        return ans;
    }
}
```
