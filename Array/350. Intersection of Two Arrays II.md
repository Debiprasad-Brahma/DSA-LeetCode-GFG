# 🧠 Intuition
To find the **intersection of two arrays**, we need to include elements that appear in both arrays, considering their **frequency (duplicates matter)**.

Example:
- nums1 = [1,2,2,1]
- nums2 = [2,2]  
→ Output: [2,2]

So instead of just checking presence, we must:
- Count how many times each number appears in both arrays.
- Take the **minimum frequency** for each common element.

Using **hash maps (frequency maps)** makes this efficient.

---

# 🚀 Approach
1. Create two frequency maps:
   - `map1` → counts elements in `nums1`
   - `map2` → counts elements in `nums2`

2. Determine the **smaller array** to iterate over (optimization).

3. For each element in the smaller array:
   - If it exists in both maps:
     - Get frequencies from both maps.
     - Add the element `min(freq1, freq2)` times to result.
     - Remove the element from both maps to avoid duplicate processing.

4. Convert the result list into an array.

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(n + m)$$  
  - Building both maps takes linear time.
  - Traversing the smaller array is also linear.

- **Space complexity:**  
  $$O(n + m)$$  
  - Two hash maps store frequencies.

---

# 💻 Code
```java
class Solution {

    public int[] intersect(int[] nums1, int[] nums2) {
        Map<Integer, Integer> map1 = new HashMap<>();
        Map<Integer, Integer> map2 = new HashMap<>();
        ArrayList<Integer> arr = new ArrayList<>();

        // Count frequency of nums1
        for (int num : nums1) 
            map1.put(num, map1.getOrDefault(num, 0) + 1);

        // Count frequency of nums2
        for (int num : nums2) 
            map2.put(num, map2.getOrDefault(num, 0) + 1);

        // Choose smaller array for iteration
        int[] smaller = nums1.length < nums2.length ? nums1 : nums2;

        for (int i = 0; i < smaller.length; i++) {
            int temp = smaller[i];

            if (map1.containsKey(temp) && map2.containsKey(temp)) {
                int val1 = map1.get(temp);
                int val2 = map2.get(temp);

                int count = Math.min(val1, val2);

                // Add element min(count1, count2) times
                for (int j = 0; j < count; j++) {
                    arr.add(temp);
                }

                // Remove to prevent duplicate work
                map1.remove(temp);
                map2.remove(temp);
            }
        }

        // Convert ArrayList to array
        int[] ans = new int[arr.size()];
        for (int i = 0; i < ans.length; i++) {
            ans[i] = arr.get(i);
        }

        return ans;
    }
}
