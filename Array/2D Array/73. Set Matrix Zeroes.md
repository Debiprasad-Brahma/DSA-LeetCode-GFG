# 🔢 Set Matrix Zeroes | Extra Space Approach | O(m*n) Time

## Intuition
If an element in the matrix is `0`, its entire **row and column** must be set to `0`.  
Directly modifying the matrix while scanning would corrupt results, since newly set zeroes would spread unnecessarily.  

To avoid this, we:
- First record which rows and columns should be zeroed.
- Then update the matrix in a second pass.

---

## Approach
1. Create two helper arrays:
   - `row[m]` → tracks which rows should become all zeros.
   - `col[n]` → tracks which columns should become all zeros.  
2. First pass:
   - Traverse the matrix.  
   - If `matrix[i][j] == 0`, mark `row[i] = true` and `col[j] = true`.  
3. Second pass:
   - Traverse again.  
   - If `row[i]` or `col[j]` is true, set `matrix[i][j] = 0`.  

---

## Complexity
- **Time Complexity:** **O(m × n)**  
  - Two passes over the matrix.  
- **Space Complexity:** **O(m + n)**  
  - Additional arrays for rows and columns.  

---

## Code
```java
class Solution {
    public void setZeroes(int[][] matrix) {
        int m = matrix.length;
        int n = matrix[0].length;

        boolean[] row = new boolean[m];
        boolean[] col = new boolean[n];

        // Step 1: Mark rows and cols that need to be zeroed
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (matrix[i][j] == 0) {
                    row[i] = true;
                    col[j] = true;
                }
            }
        }

        // Step 2: Set zeros based on markers
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (row[i] || col[j]) {
                    matrix[i][j] = 0;
                }
            }
        }
    }
}
