# Find Row with Maximum Number of Ones in a Binary Matrix

---

## Problem
Given a binary matrix `mat`, find the row that contains the maximum number of `1`s.  
Return the row index along with the count of `1`s in that row.

---

## Intuition
The task is to identify which row has the most `1`s.  
We can solve this by iterating through each row, counting the number of `1`s, and updating the result whenever we find a row with a larger count.

---

## Approach
1. Initialize:
   - `finalcnt = -1` → keeps track of the maximum count of `1`s so far.
   - `ans = new int[2]` → stores the result as `[rowIndex, count]`.
2. Traverse each row:
   - For each row, iterate through its columns and count the number of `1`s.
3. Compare with `finalcnt`:
   - If the current row's count is greater, update `finalcnt` and store the row index with count in `ans`.
4. Return `ans`.

---

## Code

```java
class Solution {
    public int[] rowAndMaximumOnes(int[][] mat) {
        int row = mat.length;
        int col = mat[0].length;

        int finalcnt = -1;
        int []ans = new int[2];

        for(int i=0; i<row; i++){
            int count = 0;
            // count 1s in each column
            for(int j=0; j<col; j++){
                if(mat[i][j] == 1)
                    count++;
            }
            // update if this row has more 1s
            if(count > finalcnt){
                finalcnt = count;
                ans = new int[]{i, count};
            }
        }
        return ans;
    }
}
