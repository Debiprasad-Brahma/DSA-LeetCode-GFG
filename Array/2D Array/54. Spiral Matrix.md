# 🌀 Spiral Matrix Traversal | Boundary Shrinking | O(m*n)

## Intuition
We need to traverse a matrix in **spiral order**:
- Start from the top-left corner.
- Move right → down → left → up.
- Shrink the boundaries (`top, bottom, left, right`) after each traversal.
- Stop when all elements are visited.

This can be done by simulating the traversal with 4 boundaries.

---

## Approach
1. Initialize four boundaries:
   - `top = 0`
   - `bottom = matrix.length - 1`
   - `left = 0`
   - `right = matrix[0].length - 1`
2. While `top <= bottom && left <= right`:
   - Traverse the **top row** → move left → right.
   - Traverse the **right column** → move top → bottom.
   - Traverse the **bottom row** (if still valid) → move right → left.
   - Traverse the **left column** (if still valid) → move bottom → top.
3. After each traversal, adjust the boundary inward:
   - `top++`, `bottom--`, `left++`, `right--`.
4. Continue until all elements are visited.

---

## Complexity
- **Time Complexity:** **O(m × n)** → each element is visited once.  
- **Space Complexity:** **O(1)** (ignoring output list).  

---

## Code
```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> res = new ArrayList<>();
        int top = 0, bottom = matrix.length - 1;
        int left = 0, right = matrix[0].length - 1;

        while (top <= bottom && left <= right) {
            // Traverse top row
            for (int i = left; i <= right; i++) {
                res.add(matrix[top][i]);
            }
            top++;

            // Traverse right column
            for (int i = top; i <= bottom; i++) {
                res.add(matrix[i][right]);
            }
            right--;

            // Traverse bottom row
            if (top <= bottom) {
                for (int i = right; i >= left; i--) {
                    res.add(matrix[bottom][i]);
                }
                bottom--;
            }

            // Traverse left column
            if (left <= right) {
                for (int i = bottom; i >= top; i--) {
                    res.add(matrix[i][left]);
                }
                left++;
            }
        }

        return res;
    }
}
