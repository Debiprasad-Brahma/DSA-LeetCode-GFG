## 🔄 LeetCode 566 — Reshape the Matrix

### Intuition  
Matrix reshaping means converting a matrix into a new shape **without changing the order of elements**.

Important observation:
- Reshaping is only possible if the **total number of elements** remains the same.
- If `row * col != r * c`, reshaping is impossible and we must return the original matrix.

---

### Approach  
1. Calculate the number of rows (`row`) and columns (`col`) in the original matrix.
2. Check if reshaping is possible:
   - If `row * col != r * c`, return the original matrix.
3. Create a new matrix of size `r × c`.
4. Traverse the original matrix row-wise.
5. Fill the new matrix row-wise using two pointers (`a`, `b`) to track the current position.
6. Move to the next row when a column is fully filled.

---

### Time & Space Complexity  
- **Time Complexity:** O(row × col)  
- **Space Complexity:** O(r × c)

---

### Code  
```java
class Solution {

    public int[][] matrixReshape(int[][] mat, int r, int c) {
        int row = mat.length;
        int col = mat[0].length;

        // Check if reshape is possible
        if (row * col != r * c) return mat;

        int[][] ans = new int[r][c];
        int a = 0, b = 0;

        // Fill new matrix row-wise
        for (int i = 0; i < row; i++) {
            for (int j = 0; j < col; j++) {
                ans[a][b++] = mat[i][j];
                if (b == c) {
                    b = 0;
                    a++;
                }
            }
        }

        return ans;
    }
}
