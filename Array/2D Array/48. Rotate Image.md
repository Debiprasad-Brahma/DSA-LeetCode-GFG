# 🖼️ Rotate Image | Transpose + Reverse | O(n²) Time

## Intuition
To rotate an `n x n` matrix **90° clockwise**, we can break it into two simple transformations:
1. **Transpose** the matrix (convert rows → columns).
2. **Reverse each row** (to adjust the column order).

This avoids extra space and achieves the rotation in-place.

---

## Approach
1. **Transpose the matrix**:
   - Swap `matrix[i][j]` with `matrix[j][i]` for all `i < j`.
   - This flips the matrix along its diagonal.
2. **Reverse each row**:
   - For every row, reverse its elements to simulate a 90° clockwise rotation.
3. Return the modified matrix (in-place rotation).

---

## Complexity
- **Time Complexity:** **O(n²)** → both transpose and reverse require visiting all elements once.
- **Space Complexity:** **O(1)** → in-place, no extra matrix needed.

---

## Code
```java
class Solution {
    void swap(int i, int j, int[][] matrix) {
        int temp = matrix[i][j];
        matrix[i][j] = matrix[j][i];
        matrix[j][i] = temp;
    }

    void reverse(int[][] matrix) {
        int n = matrix.length;
        for (int i = 0; i < n; i++) {
            int left = 0, right = n - 1;
            while (left < right) {
                int temp = matrix[i][left];
                matrix[i][left] = matrix[i][right];
                matrix[i][right] = temp;
                left++;
                right--;
            }
        }
    }

    public void rotate(int[][] matrix) {
        int n = matrix.length;

        // Step 1: Transpose
        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                swap(i, j, matrix);
            }
        }

        // Step 2: Reverse each row
        reverse(matrix);
    }
}
