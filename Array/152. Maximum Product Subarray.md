# Intuition

The maximum product subarray problem is tricky because:

- Negative numbers can flip the sign of the product.
- An even count of negatives can produce a large positive product.
- Zeros break the product chain.

Instead of tracking min and max at each step, this approach scans the array from:

- **Left to Right (prefix)**
- **Right to Left (suffix)**

Why both directions?

Because the maximum product may depend on removing a prefix part (if first negative causes issue) or removing a suffix part (if last negative causes issue).

By checking both prefix and suffix products at every step, we ensure no case is missed.

---

# Approach

1. Initialize:
   - `maxProd` = nums[0]
   - `prefix = 1`
   - `suffix = 1`

2. Traverse the array once (`i = 0 → n-1`):
   - If `prefix == 0`, reset it to `1`
   - If `suffix == 0`, reset it to `1`
   - Multiply:
     - `prefix *= nums[i]`
     - `suffix *= nums[n - i - 1]`
   - Update:
     - `maxProd = max(maxProd, max(prefix, suffix))`

3. Return `maxProd`

This ensures:
- Negative chains are handled
- Zeros restart the subarray
- Both forward and backward possibilities are checked

---

# Complexity

- **Time Complexity:** O(n)  
  Single pass through the array.

- **Space Complexity:** O(1)  
  Only a few variables are used.

---

# Why This Works

If the number of negative elements in a subarray is:

- **Even →** product is positive and potentially maximum.
- **Odd →** removing either the prefix up to first negative or suffix after last negative may give a better result.

Scanning from both ends automatically covers these scenarios.

# Code
```java []
class Solution {

    public int maxProduct(int[] nums) {
        int n = nums.length;
        int maxProd = nums[0];
        int prefix = 1;
        int sufix = 1;

        for (int i = 0; i < n; i++) {
            if (prefix == 0) prefix = 1;
            if (sufix == 0) sufix = 1;

            prefix *= nums[i];
            sufix *= nums[n - i - 1];

            maxProd = Math.max(maxProd, Math.max(prefix, sufix));
        }

        return maxProd;
    }
}

```
