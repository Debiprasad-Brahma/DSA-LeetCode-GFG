# 🔥 Find Missing & Repeated Values | Boolean Visited Array O(N²) | No Math Formula Needed | Super Clean

---

## 💡 Intuition

A grid of size `n×n` should contain every number from `1` to `n²` **exactly once**.
But one number appears **twice (a)** and one is **missing (b)**.

> Key Insight: Use a **visited boolean array** of size `n²`.  
> - If we try to mark a number already marked → that's **`a` (repeated)**  
> - After full traversal, whichever index is **still unvisited** → that's **`b` (missing)**

Think of it like attendance — mark each student as present. The one called twice is repeated; the one never called is absent.

---

## 🧠 Approach — Boolean Visited Marking

1. Create `isVisited[n*n]` — one slot per number `1` to `n²`.
2. Traverse entire grid left-to-right, top-to-bottom.
3. For each `num = grid[i][j]`:
   - If `isVisited[num-1]` is already `true` → **`a = num`** (repeated)
   - Mark `isVisited[num-1] = true`
4. After traversal, scan `isVisited[]`:
   - First `false` index → **`b = index + 1`** (missing)
5. Return `{a, b}`.

---

## 📊 Dry Run

```
grid = [[1, 3],
        [2, 2]]

n = 2  →  n² = 4  →  numbers should be {1, 2, 3, 4}
```

**isVisited = [false, false, false, false]**  (indices 0→1, 1→2, 2→3, 3→4)

| Step | num | isVisited[num-1] | Action |
|------|-----|------------------|--------|
| (0,0)| 1   | false            | Mark index 0 = true |
| (0,1)| 3   | false            | Mark index 2 = true |
| (1,0)| 2   | false            | Mark index 1 = true |
| (1,1)| 2   | ✅ true!          | **a = 2** (repeated) |

**Scan isVisited:** `[true, true, true, false]`  
→ Index 3 is false → **b = 4** (missing)

**Output:** `[2, 4]` ✅

---

## 🧪 Edge Cases

```
grid = [[1]]                →  impossible (1×1 has only 1 number, can't repeat & miss)
grid = [[2,2],[3,4]]        →  [2, 1]  (2 repeated, 1 missing)
grid = [[9,1,7],[8,9,2],[3,4,6]]  →  [9, 5]
grid = [[1,2],[2,3]]        →  [2, 4]
```

## ✅ Code (Java)

```java
class Solution {

    int[] findAB(int[][] grid) {
        int n = grid.length;

        boolean[] isVisited = new boolean[n * n];  // Index i → number (i+1)

        int a = -1;   // Repeated number
        int b = -1;   // Missing number

        // Step 1: Find the repeated number (a)
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                int num = grid[i][j];
                if (isVisited[num - 1]) {
                    a = num;                        // Already seen → repeated
                }
                isVisited[num - 1] = true;
            }
        }

        // Step 2: Find the missing number (b)
        for (int i = 0; i < isVisited.length; i++) {
            if (!isVisited[i]) b = i + 1;          // Never marked → missing
        }

        return new int[]{a, b};
    }

    public int[] findMissingAndRepeatedValues(int[][] grid) {
        return findAB(grid);
    }
}
```

## ⏱ Complexity Analysis

| | Complexity | Reason |
|---|---|---|
| **Time** | O(N²) | One pass over all N² grid cells + one pass over N² visited array |
| **Space** | O(N²) | Boolean visited array of size N² |

> 💡 Both passes are **linear in input size** (N² elements) → overall O(N²) time, which is optimal since we must read every cell at least once.

## ⚔️ All Approaches Compared

| Approach | Time | Space | Idea |
|---|---|---|---|
| **Visited Array** ✅ | O(N²) | O(N²) | Boolean marking — this solution |
| **Math Formula** | O(N²) | O(1) | Sum & Sum of Squares equations |
| **HashMap Frequency** | O(N²) | O(N²) | Count occurrences, find freq=2 and freq=0 |
| **Sorting** | O(N² log N) | O(N²) | Flatten + sort, find adjacent duplicates |

### 🧮 Math Formula Approach (Space O(1)) — Bonus for Interviews:
```java
// Let repeat = a, missing = b
// S  = sum of all grid values,     expected = n²(n²+1)/2
// S2 = sum of squares of grid,     expected = n²(n²+1)(2n²+1)/6
//
// S  - expected  = a - b          ... (1)
// S2 - expected2 = a² - b²        ... (2)
// From (2)/(1):  a + b = (S2 - expected2) / (S - expected)
// Solve for a and b

long diff = sumGrid - expectedSum;              // a - b
long diffSq = sumSqGrid - expectedSumSq;        // a² - b²
long sumAB  = diffSq / diff;                    // a + b
int a = (int)((diff + sumAB) / 2);
int b = (int)(sumAB - a);
```

## 📌 Key Takeaways (Revision Flashcard)

- 🟡 **Values in range [1, N²]** → use index as hash → `isVisited[num-1]`
- 🟡 **First encounter** → mark visited; **Second encounter** → it's the **repeat**
- 🟡 **Unvisited after full scan** → it's the **missing** number
- 🟡 **Boolean array** is faster than HashMap for range-bounded value problems
- 🟡 Math approach exists for **O(1) space** — know both for interviews
- 🟡 Time: **O(N²)** | Space: **O(N²)**
