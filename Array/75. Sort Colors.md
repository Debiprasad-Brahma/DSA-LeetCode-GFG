# Sort Colors (Dutch National Flag Algorithm)

## Intuition
The problem is to sort an array containing only `0`, `1`, and `2` without using any built-in sort function.  
This is a classic **Dutch National Flag Problem** where:
- `0` represents the first color (Red),
- `1` represents the second color (White),
- `2` represents the third color (Blue).

Instead of counting and rewriting elements, we can solve it in **one pass** by using three pointers.

## Approach
We maintain three pointers:  
- `low` → boundary for placing `0`s.  
- `mid` → current index being processed.  
- `high` → boundary for placing `2`s.  

Steps:
1. Start with `low = 0`, `mid = 0`, and `high = n - 1`.  
2. Traverse the array while `mid <= high`:  
   - If `nums[mid] == 0`, swap with `nums[low]`, and move both `low` and `mid` forward.  
   - If `nums[mid] == 1`, just move `mid` forward.  
   - If `nums[mid] == 2`, swap with `nums[high]` and move `high` backward.  
3. At the end, the array will be sorted in-place.

## Complexity

### Time Complexity
- **O(n)**  
  - Each element is processed at most once.

### Space Complexity
- **O(1)**  
  - Sorting is done **in-place** without extra memory.

## Java Code

```java
class Solution {
    public void sortColors(int[] nums) {
        int n = nums.length;
        int low = 0, mid = 0, high = n - 1;

        while (mid <= high) {
            if (nums[mid] == 0) {
                swap(nums, low, mid);
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                mid++;
            } else { // nums[mid] == 2
                swap(nums, mid, high);
                high--;
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
