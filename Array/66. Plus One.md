## ➕ LeetCode 66 — Plus One

### Intuition  
The number is given as an array of digits, and we need to add **1** to it exactly the way normal addition works.

We always start from the **rightmost digit**:

- If the last digit is **less than 9**, we can simply increase it by `1` and return the array.
- If the last digit is `9`, adding `1` makes it `0` and produces a **carry**.  
  We then move leftward, setting digits to `0` as long as they are `9`.
- At some point, if we find a digit that is **less than 9**, we increase it by `1` and stop.
- If **all digits are 9** (for example `999`), then adding `1` increases the number of digits.  
  In this case, the result becomes `1000`, so we create a new array of size `n + 1`, keep all values `0`, and set the first element to `1`.

This covers all possible cases of carry propagation.

---

### Approach  
1. Traverse the array from right to left.
2. If a digit is less than `9`, increment it and return the array.
3. If a digit is `9`, set it to `0` and continue moving left.
4. If the loop finishes, it means all digits were `9`:
   - Create a new array of size `n + 1`
   - Set the first element to `1`
5. Return the result.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(1)  
  (O(n) only when a new array is created in the all-9s case)

---

### Code  
```java
class Solution {

    public int[] plusOne(int[] digits) {
        for (int i = digits.length - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                digits[i]++;
                return digits;
            }
            digits[i] = 0;
        }

        // Case when all digits are 9
        digits = new int[digits.length + 1];
        digits[0] = 1;
        return digits;
    }
}
