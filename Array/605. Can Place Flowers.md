# Can Place Flowers 🌸

## Intuition
We are given a flowerbed represented by an array, where `0` means an empty plot and `1` means an already planted flower.  
The rule is that **no two flowers can be adjacent**.  
We need to check if we can plant `n` new flowers without violating the rule.  

The idea is simple:  
- Traverse the array.  
- Whenever we find an empty spot (`0`), we check if both its neighbors (left and right) are also empty (or boundaries).  
- If so, we can plant a flower there.  

---

## Approach
1. Iterate through each plot in the flowerbed.  
2. For the current index `i`, check three conditions:
   - `flowerbed[i] == 0` (current spot is empty)  
   - `i == 0 || flowerbed[i-1] == 0` (either it's the first spot or the left neighbor is empty)  
   - `i == size-1 || flowerbed[i+1] == 0` (either it's the last spot or the right neighbor is empty)  
3. If all conditions are satisfied:
   - Plant a flower at `i` → mark `flowerbed[i] = 1`.  
   - Decrease `n` by 1.  
   - If `n == 0`, return `true` early.  
4. After the loop, if `n > 0`, return `false`, otherwise `true`.

---

## Complexity
### Time Complexity:  
- **O(size)** → We iterate once through the flowerbed array.  

### Space Complexity:  
- **O(1)** → We modify the flowerbed in-place without using extra space.  

---

## Code
```java
class Solution {
    public boolean canPlaceFlowers(int[] flowerbed, int n) {
        if(n == 0) return true;

        int size = flowerbed.length;

        for(int i = 0; i < size; i++) {
            if(flowerbed[i] == 0 && 
               (i == 0 || flowerbed[i-1] == 0) && 
               (i == size - 1 || flowerbed[i+1] == 0)) {
                
                flowerbed[i] = 1;
                n--;
                if(n == 0) return true;
            }
        }

        return false;
    }
}
