## 🔎 LeetCode 3159 — Find Occurrences of an Element in an Array | Index Collection Approach

### 💡 Intuition  
We are given:
- An array `nums`
- An integer `x`
- A list of queries where each query asks for the **k-th occurrence of `x`**

Instead of scanning `nums` for every query (which would be slow),  
we can **precompute all indices where `x` occurs** and answer each query in O(1).

If a query asks for an occurrence that doesn’t exist, we return `-1`.

---

### 🧠 Approach  
1. Traverse `nums` once and store **all indices** where `nums[i] == x` in a list.
2. For each query `k`:
   - If `k` is greater than the number of occurrences → return `-1`
   - Otherwise → return the `(k-1)`th index from the list
3. Modify the `queries` array in-place and return it.

---

### ⏱️ Complexity  
- **Time Complexity:**  
  - O(n) to collect occurrences  
  - O(m) to answer queries  
  - **Total:** O(n + m)
- **Space Complexity:** O(n) — for storing indices of `x`

---

### 💻 Code  
```java
class Solution {

    public int[] occurrencesOfElement(int[] nums, int[] queries, int x) {
        int n = nums.length;
        List<Integer> list = new ArrayList<>();

        // Collect all indices where nums[i] == x
        for (int i = 0; i < n; i++) {
            if (nums[i] == x) {
                list.add(i);
            }
        }

        int m = queries.length;
        int listSize = list.size();

        // Answer each query
        for (int i = 0; i < m; i++) {
            int need = queries[i];
            if (need > listSize) {
                queries[i] = -1;
            } else {
                queries[i] = list.get(need - 1);
            }
        }

        return queries;
    }
}
