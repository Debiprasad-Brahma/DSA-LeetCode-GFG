## 💼 LeetCode 826 — Most Profit Assigning Work | Brute-Force Greedy per Worker

### 💡 Intuition  
Each worker can perform **at most one job** whose difficulty is **≤ worker’s strength**.  
Among all such jobs, the worker should choose the one with the **maximum profit**.

Your solution follows a straightforward greedy idea:
- For **each worker**, scan all jobs
- Pick the **best profit** job the worker can handle
- Add it to the total answer

This works correctly because:
- Jobs can be reused by multiple workers
- Workers are independent of each other

---

### 🧠 Approach  

#### Helper Method: `findProfit`
For a given worker strength:
1. Iterate over all jobs
2. If `workerStrength >= difficulty[i]`, consider that job
3. Track the **maximum profit** among all feasible jobs
4. Return the maximum profit found

#### Main Method:
1. For each worker:
   - Call `findProfit`
   - Add the returned profit to the total answer
2. Return the accumulated profit

---

### ⏱️ Complexity  
- **Time Complexity:** O(n × m)  
  - `n` = number of workers  
  - `m` = number of jobs  
- **Space Complexity:** O(1) — no extra data structures

> ⚠️ This solution is correct but **not optimal** for large inputs.  
> The optimized solution uses sorting + prefix max for **O((n+m) log m)**.

---

### 💻 Code  
```java
class Solution {

    private int findProfit(int[] difficulty, int[] profit, int workerStrength) {
        int m = difficulty.length;
        int maxProfit = 0;

        for (int i = 0; i < m; i++) {
            int currStrength = difficulty[i];
            int currProfit = profit[i];

            if (workerStrength >= currStrength) {
                maxProfit = Math.max(maxProfit, currProfit);
            }
        }
        return maxProfit;
    }

    public int maxProfitAssignment(int[] difficulty, int[] profit, int[] worker) {
        int n = worker.length;
        int ans = 0;

        for (int i = 0; i < n; i++) {
            ans += findProfit(difficulty, profit, worker[i]);
        }
        return ans;
    }
}
