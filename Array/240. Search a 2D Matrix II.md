# 🧩 LeetCode 74 — Search a 2D Matrix

## 🧠 Intuition
We are given a 2D matrix where:
- Each row is sorted in ascending order.
- The first element of each row is greater than the last element of the previous row.

We need to determine whether a given target value exists in this matrix.

Instead of flattening the matrix or using binary search twice, we can take advantage of the matrix’s **sorted structure** to search efficiently — just like searching in a Binary Search Tree.

---

## 💡 Approach
1. Start from the **top-right corner** of the matrix (element at `(0, n - 1)`).
2. Compare this element with the target:
   - If it equals the target → return `true`.
   - If it’s **greater** than the target → move **left** (decrement column index `j--`).
   - If it’s **smaller** than the target → move **down** (increment row index `i++`).
3. Continue this process until:
   - You find the target, or  
   - The indices go out of bounds (`i >= m` or `j < 0`).
4. If not found, return `false`.

This method is often called the **staircase search** because you “walk down and left” through the matrix.

---

## ⏱️ Complexity
### Time Complexity:
**O(m + n)**  
At most, we move across one row and one column each iteration.

### Space Complexity:
**O(1)**  
We use only a constant amount of extra space.

---

## 🧮 Code
```java
class Solution {

    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        
        int i = 0;
        int j = n - 1;

        while (i < m && j >= 0) {
            if (matrix[i][j] == target) {
                return true;
            } else if (matrix[i][j] > target) {
                j--;
            } else {
                i++;
            }
        }
        return false;
    }
}
