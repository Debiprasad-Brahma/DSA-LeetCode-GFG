# 🔄 Move Zeroes | Two-Pointer Technique | O(n) Time

## Intuition
We want to move all `0`s to the end of the array while maintaining the **relative order of non-zero elements**.  
A brute force shifting approach would take extra space or multiple passes.  
Instead, we use the **two-pointer approach**:
- Find the first `0` in the array (pointer `j`).  
- Traverse the array from that point onward:
  - Each time we find a non-zero element, **swap it with position `j`** and move `j` forward.  

This ensures that all non-zero elements are shifted left in place, and zeros naturally end up at the end.

---

## Approach
1. Scan the array to find the index of the first `0` → store in `j`.  
2. If no zero is found, return the array as it is.  
3. From `j+1` to end of the array:
   - If the element is non-zero, swap it with `arr[j]` and increment `j`.  
4. Return the modified array.  

---

## Complexity
- **Time Complexity:** **O(n)**  
  - Each element is visited once.  
- **Space Complexity:** **O(1)**  
  - In-place swapping, no extra storage needed.  

---

## Code
```java
class Solution {
    public int[] moveZeroes(int[] arr) {
        int j = -1;
        
        // Find first zero
        for (int i = 0; i < arr.length; i++) {
            if (arr[i] == 0) {
                j = i;
                break;
            }
        }
        
        // No zero found → return original array
        if (j == -1) return arr;

        // Swap non-zero elements with zeros
        for (int i = j + 1; i < arr.length; i++) {
            if (arr[i] != 0) {
                int temp = arr[i];
                arr[i] = arr[j];
                arr[j] = temp;
                j++;
            }
        }
        return arr;
    }
}
