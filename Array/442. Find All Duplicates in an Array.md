## ⚡ Optimal O(1) Space Trick Using Negation — Find All Duplicates in an Array

### 💡 Intuition
The array contains numbers from `1` to `n`, meaning each number ideally corresponds to an index `num - 1`.  
If we visit an index that has already been visited before, it means the same number appeared again — a **duplicate**.

To keep track of visits **without extra space**, we can **negate** the value at each visited index:
- If the value at that index is already negative → it means the number is a duplicate.
- Otherwise, we mark it as visited by negating it.

---

### 🧠 Approach
1. Iterate through all numbers in the array.  
2. For each number `num`, compute its corresponding index → `idx = Math.abs(num) - 1`.  
3. If `nums[idx]` is negative → this number was seen before → add it to the result list.  
4. Else, mark it as visited by negating `nums[idx]`.  
5. Return the list of duplicates at the end.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — each element is processed at most twice.  
- **Space Complexity:** O(1) — no extra data structures used (ignoring output list).  

---

### 💻 Code
```java
class Solution {

    public List<Integer> findDuplicates(int[] nums) {
        List<Integer> ans = new ArrayList<>();

        for (int i = 0; i < nums.length; i++) {
            int idx = Math.abs(nums[i]) - 1;

            if (nums[idx] < 0) {
                ans.add(idx + 1);
            } else {
                nums[idx] = -nums[idx];
            }
        }
        return ans;
    }
}
