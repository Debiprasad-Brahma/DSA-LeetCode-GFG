## 🔁 LeetCode 961 — N-Repeated Element in Size 2N Array

### Intuition  
You are given an array of size `2N` where **exactly one element is repeated `N` times**, and all other elements appear only once.

Key observation:
- Since the repeated element appears many times, **two of its occurrences must be very close to each other**.
- In fact, the repeated number will appear within a distance of at most **3 indices**.

So instead of using extra space or sorting, we can simply check nearby elements.

---

### Approach  
1. Traverse the array from left to right.
2. For each index `i`, check:
   - `nums[i] == nums[i + 1]`
   - `nums[i] == nums[i + 2]`
   - `nums[i] == nums[i + 3]`
3. As soon as a match is found, return that number.
4. Since the problem guarantees a valid answer, this method will always find it.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(1)

---

### Code  
```java
class Solution {

    public int repeatedNTimes(int[] nums) {
        for (int i = 0; i < nums.length - 1; i++) {
            if (nums[i] == nums[i + 1]) return nums[i];
            if (i + 2 < nums.length && nums[i] == nums[i + 2]) return nums[i];
            if (i + 3 < nums.length && nums[i] == nums[i + 3]) return nums[i];
        }
        return -1;
    }
}
