# 🔢 LeetCode 2570 — Merge Two 2D Arrays by Summing Values

### 🧠 Intuition
We are given two 2D integer arrays `nums1` and `nums2`,  
where each element represents a pair `[id, value]`.  

If an `id` appears in both arrays, we need to **sum their values**.  
Finally, we must return a **sorted array** by `id` (in ascending order).  

Using a **map-based approach** simplifies this task —  
we can accumulate sums for each `id` and then build the final 2D result.

---

### 💡 Approach
1. Initialize a `TreeMap<Integer, Integer>` to automatically store pairs sorted by key (`id`).  
2. Traverse both arrays:
   - For each `[id, val]`, insert into the map.
   - If `id` already exists, add to the existing value.
3. After processing both arrays, convert the map entries into a 2D result array.  
4. Return the resulting 2D array.

---

### ⏱️ Complexity
- **Time Complexity:** `O((m + n) log k)`  
  where `m` and `n` are the lengths of `nums1` and `nums2`, and `k` is the number of unique ids (due to TreeMap sorting).
- **Space Complexity:** `O(k)` — For storing entries in the map.

---

### ✅ Code
```java
class Solution {

    public int[][] mergeArrays(int[][] nums1, int[][] nums2) {
        int m = nums1.length;
        int n = nums2.length;

        Map<Integer, Integer> map = new TreeMap<>();

        // Add pairs from nums1
        for (int i = 0; i < m; i++) {
            int id = nums1[i][0];
            int val = nums1[i][1];
            map.put(id, map.getOrDefault(id, 0) + val);
        }

        // Add pairs from nums2
        for (int i = 0; i < n; i++) {
            int id = nums2[i][0];
            int val = nums2[i][1];
            map.put(id, map.getOrDefault(id, 0) + val);
        }

        // Convert map to 2D array
        int[][] res = new int[map.size()][2];
        int idx = 0;

        for (int key : map.keySet()) {
            res[idx][0] = key;
            res[idx][1] = map.get(key);
            idx++;
        }

        return res;
    }
}
