# 🔢 LeetCode 922 — Sort Array by Parity II

### 🧠 Intuition  
We’re given an array where **half the integers are even** and **half are odd**.  
We need to **rearrange the array** so that:
- Elements at **even indices** contain **even numbers**, and  
- Elements at **odd indices** contain **odd numbers**.

A simple way to do this is to use **two pointers** — one for even indices and one for odd indices — and **swap misplaced elements**.

---

### 💡 Approach  
1. Initialize:
   - `i` → points to **even indices** (0, 2, 4, …)
   - `j` → points to **odd indices** (1, 3, 5, …)
2. Traverse the array using these two pointers.
3. If both positions are already correct:
   - Move the respective pointer (`i` or `j`) by 2.
4. If both are misplaced (even at odd index, or vice versa):
   - **Swap** the elements at `i` and `j`.
   - Move both pointers forward by 2.
5. Continue until one pointer reaches the end of the array.

---

### ⏱️ Complexity  
- **Time Complexity:** `O(n)` — Each element is visited at most once.  
- **Space Complexity:** `O(1)` — Sorting done in-place.

---

### ✅ Code  
```java
class Solution {

    public int[] sortArrayByParityII(int[] nums) {
        int i = 0; // even index pointer
        int j = 1; // odd index pointer

        while (i < nums.length && j < nums.length) {
            // If even index has even number, move ahead
            if (i % 2 == 0 && nums[i] % 2 == 0) {
                i += 2;
            } 
            // If odd index has odd number, move ahead
            else if (j % 2 != 0 && nums[j] % 2 != 0) {
                j += 2;
            } 
            // Swap misplaced even and odd numbers
            else {
                int temp = nums[i];
                nums[i] = nums[j];
                nums[j] = temp;
                i += 2;
                j += 2;
            }
        }
        return nums;
    }
}
