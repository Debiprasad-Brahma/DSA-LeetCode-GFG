# 🌿 LeetCode 2105 — Minimum Number of Refills

### 🧠 Intuition
Two gardeners, **Alice** and **Bob**, start watering plants from opposite ends —  
Alice from the **left** and Bob from the **right**.  
Each has a fixed watering capacity.  
If they cannot water the next plant, they must **refill** their can and continue.  
The goal is to count the **minimum number of refills** needed until all plants are watered.  
If both meet at the same plant, the one with **more remaining water** will water it.

---

### 💡 Approach
1. Use **two pointers** — `i` (start) for Alice and `j` (end) for Bob.  
2. Store initial capacities as `val1` and `val2` for refilling reference.  
3. Move inward while `i < j`:
   - If Alice doesn’t have enough water for `plants[i]`, she **refills** and increases `cnt`.
   - Then she waters the plant (`capacityA -= plants[i]`).
   - Similarly, if Bob doesn’t have enough water for `plants[j]`, he refills and increases `cnt`.
   - Then he waters from the right (`capacityB -= plants[j]`).
4. If they meet at the same plant (`i == j`),  
   check if the **maximum of their remaining water** can handle that plant.  
   If not, add one more refill to `cnt`.

---

### ⏱️ Complexity
- **Time Complexity:** `O(n)` — Each plant is visited at most once.  
- **Space Complexity:** `O(1)` — No extra space used except variables.

---

### ✅ Code
```java
class Solution {

    public int minimumRefill(int[] plants, int capacityA, int capacityB) {
        int n = plants.length;

        int val1 = capacityA;
        int val2 = capacityB;

        int i = 0;
        int j = n - 1;
        int cnt = 0;

        while (i < j) {
            // Alice refills from left
            if (capacityA < plants[i]) {
                cnt++;
                capacityA = val1;
            }
            capacityA -= plants[i];
            i++;

            // Bob refills from right
            if (capacityB < plants[j]) {
                cnt++;
                capacityB = val2;
            } 
            capacityB -= plants[j];
            j--;
        }

        if (i == j) {
            if (Math.max(capacityA, capacityB) < plants[i]) cnt++;
        }

        return cnt;
    }
}
