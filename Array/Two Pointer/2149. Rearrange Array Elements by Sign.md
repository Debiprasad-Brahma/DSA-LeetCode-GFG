## 2149. Rearrange Array Elements by Sign�

### 🔍 Intuition
We are given an array `nums` containing **equal numbers of positive and negative integers**.  
We need to rearrange the array so that:
- Positive and negative numbers appear **alternately**, and  
- The **order of appearance** of positives and negatives is preserved.

To achieve this, we can:
1. Separate positive and negative numbers into two lists.
2. Merge them alternately into a new array.

---

### 💡 Approach
1. Create two lists:  
   - `arr1` → to store **positive** numbers  
   - `arr2` → to store **negative** numbers
2. Traverse the original array and fill both lists accordingly.
3. Create a new array `ans` of size `n`.
4. Fill even indices with positives and odd indices with negatives alternately.
5. Return the `ans` array.

---

### ⏱️ Complexity
| Type | Complexity |
|------|-------------|
| **Time Complexity** | O(n) — one pass to split, one pass to merge |
| **Space Complexity** | O(n) — using extra lists for storage |

---

### 💻 Code
```java
class Solution {

    public int[] rearrangeArray(int[] nums) {
        int n = nums.length;
        List<Integer> arr1 = new ArrayList<>();
        List<Integer> arr2 = new ArrayList<>();

        // Step 1: Separate positive and negative values
        for (int i = 0; i < n; i++) {
            if (nums[i] >= 0)
                arr1.add(nums[i]);
            else
                arr2.add(nums[i]);
        }

        int[] ans = new int[n]; // Step 2: Prepare result array

        int posIndex = 0;
        int negIndex = 0;

        // Step 3: Fill array alternately with + and -
        for (int i = 0; i < n; i++) {
            if (i % 2 == 0 && !arr1.isEmpty()) {
                ans[i] = arr1.get(posIndex);
                posIndex++;
            }
            if (i % 2 != 0 && !arr2.isEmpty()) {
                ans[i] = arr2.get(negIndex);
                negIndex++;
            }
        }
        return ans;
    }
}
