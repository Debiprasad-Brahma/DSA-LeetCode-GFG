# 🧠 Intuition
We need to find the **third distinct maximum number** in the array.

Key points:
- **Duplicates should be ignored** (distinct values only)
- If fewer than 3 distinct numbers exist → return the **maximum**

Instead of sorting (which takes \(O(n \log n)\)), we can track:
- **1st max**
- **2nd max**
- **3rd max**

We update these in a single pass.

⚠️ Important challenge:
- Array may contain `Integer.MIN_VALUE`
- So we use `long` initialized with `Long.MIN_VALUE` to safely distinguish real values

---

# 🚀 Approach
1. Initialize:
   - `firstMax`, `secondMax`, `thirdMax` = `Long.MIN_VALUE`

2. Traverse each number:
   - If `num > firstMax`:
     - Shift values → `third = second`, `second = first`, `first = num`
   - Else if `num` lies between first and second:
     - Update second and shift third
   - Else if `num` lies between second and third:
     - Update third

3. This automatically ensures:
   - Values are **distinct** (due to strict comparisons)

4. Final check:
   - If `thirdMax` was never updated → return `firstMax`
   - Else → return `thirdMax`

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(n)$$  
  Single traversal of the array.

- **Space complexity:**  
  $$O(1)$$  
  Only three variables are used.

---

# 💻 Code
```java
class Solution {

    public int thirdMax(int[] nums) {
        long firstMax = Long.MIN_VALUE;
        long secondMax = Long.MIN_VALUE;
        long thirdMax = Long.MIN_VALUE;

        for (int num : nums) {

            if (firstMax < num) {
                thirdMax = secondMax;
                secondMax = firstMax;
                firstMax = num;

            } else if (secondMax < num && num < firstMax) {
                thirdMax = secondMax;
                secondMax = num;

            } else if (thirdMax < num && num < secondMax) {
                thirdMax = num;
            }
        }

        if (thirdMax == Long.MIN_VALUE) return (int) firstMax;

        return (int) thirdMax;
    }
}
