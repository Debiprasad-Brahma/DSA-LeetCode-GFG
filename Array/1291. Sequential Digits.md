# Leet Code - 1291. Sequential Digits
---
## 🧠 Intuition  
A *sequential digit number* is a number where every digit is one more than the previous digit —  
for example: `123`, `4567`, `23456`, etc.  

To solve this problem, we can **precompute all possible sequential digit numbers (from 12 to 123456789)** and then filter out those that fall within the given range `[low, high]`.

---

## 💡 Approach  
1. Predefine all sequential digit numbers in an array — there are only **36 possible sequential numbers** (from 12 up to 123456789).  
2. Iterate through this list and check each number:
   - If the number is less than `low`, skip it.  
   - If it’s greater than `high`, break the loop (since numbers are in ascending order).  
   - Otherwise, add it to the result list.  
3. Return the resulting list.

This approach is simple and efficient since we are only iterating through a small fixed list of numbers.

---

## ⏱️ Complexity  
- **Time Complexity:** `O(36)` → effectively `O(1)`, since the list of sequential digits is constant in size.  
- **Space Complexity:** `O(1)` → only uses a small fixed-size array and result list.

---

## 🧩 Code  
```java
class Solution {
    public List<Integer> sequentialDigits(int low, int high) {
        int[] allNums = {12,23,34,45,56,67,78,89,
                         123,234,345,456,567,678,789,
                         1234,2345,3456,4567,5678,6789,
                         12345,23456,34567,45678,56789,
                         123456,234567,345678,456789,
                         1234567,2345678,3456789,
                         12345678,23456789,
                         123456789};

        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < allNums.length; i++) {
            if (allNums[i] < low) continue;
            if (allNums[i] > high) break;
            ans.add(allNums[i]);
        }
        return ans;
    }
}
