## 🧠 Intuition  
We need to find two numbers in the array whose `(num - 1)` values produce the maximum product.  
Since multiplication increases with larger numbers, the two **largest elements** in the array will always give the maximum product.

---

## 💡 Approach  
1. **Sort the array** in ascending order using `Arrays.sort()`.  
2. The two largest numbers will be at the end:  
   - `nums[nums.length - 1]` → largest element  
   - `nums[nums.length - 2]` → second largest element  
3. Compute the product:  
   \[(nums[nums.length - 1] - 1) * (nums[nums.length - 2] - 1)\]  
4. Return this product as the result.

---

## ⏱️ Complexity  
- **Time Complexity:** `O(n log n)` — due to sorting.  
- **Space Complexity:** `O(1)` — sorting done in-place without extra space.

---

## 🧩 Code  
```java
class Solution {
    public int maxProduct(int[] nums) {
        Arrays.sort(nums);
        return (nums[nums.length - 1] - 1) * (nums[nums.length - 2] - 1);
    }
}
