# 88. Merge Sorted Array
## 🧠 Intuition  
The goal is to merge two sorted arrays, `nums1` and `nums2`, into one sorted array within `nums1`.  
Since `nums1` already has enough space to hold all elements, we can append the elements of `nums2` to `nums1` and then sort the final array.

---

## 💡 Approach  
1. Copy all elements of `nums2` into the remaining slots of `nums1` starting from index `m`.  
2. Use `Arrays.sort()` to sort the merged array in ascending order.  
3. The final sorted result is stored in `nums1`.

This approach is simple but not the most optimal in terms of time complexity since it relies on sorting the combined array.

---

## ⏱️ Complexity  
- **Time Complexity:** `O((m + n) log(m + n))`  
  Sorting the combined array of length `m + n` dominates the runtime.  
- **Space Complexity:** `O(1)`  
  The sorting is done in-place, requiring no additional space apart from a few variables.

---

## 🧩 Code  
```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        for (int i = 0; i < n; i++) {
            nums1[i + m] = nums2[i];
        }
        Arrays.sort(nums1);
    }
}
