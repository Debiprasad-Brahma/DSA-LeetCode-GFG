# Intuition  
The task is to rearrange the numbers into the **next lexicographically greater permutation**.  
If such an arrangement is not possible (i.e., the array is already the largest permutation), rearrange it into the **smallest permutation** (sorted in ascending order).

Key observations:
- A permutation increases when we find a place where the sequence stops being decreasing from the right.
- The part after this position is always in **descending order**.
- By making a small swap and reversing the suffix, we get the next permutation with minimal change.

---

# Approach  

## Step 1: Find the breakpoint `k`
- Traverse the array from left to right.
- Find the **last index `k`** such that: nums[k] < nums[k + 1]

- If no such index exists, the array is fully descending → reverse the whole array and return.

## Step 2: Find the element to swap with
- Starting from the end, find the first index `l` such that: nums[l] > nums[k]
- Swap `nums[k]` and `nums[l]`.
  
## Step 3: Reverse the suffix
- Reverse the subarray from `k + 1` to `n - 1` to get the smallest possible order after the swap.

---

# Time & Space Complexity  
- **Time Complexity:** O(n)  
- **Space Complexity:** O(1)  
(All operations are done in-place)

---

# Code  
```java
class Solution {

  public void nextPermutation(int[] nums) {
      int n = nums.length;
      int k = -1;

      // Step 1: Find the breakpoint
      for (int i = 0; i < n - 1; i++) {
          if (nums[i] < nums[i + 1]) {
              k = i;
          }
      }

      // If no breakpoint, reverse entire array
      if (k == -1) {
          reverse(nums, 0, n - 1);
          return;
      }

      // Step 2: Find element just larger than nums[k]
      int l = n - 1;
      while (nums[l] <= nums[k]) {
          l--;
      }

      // Swap
      int temp = nums[k];
      nums[k] = nums[l];
      nums[l] = temp;

      // Step 3: Reverse suffix
      reverse(nums, k + 1, n - 1);
  }

  void reverse(int[] nums, int i, int j) {
      while (i <= j) {
          int temp = nums[i];
          nums[i] = nums[j];
          nums[j] = temp;
          i++;
          j--;
      }
  }
}
