# Intuition  
The **pivot index** is the index where:
sum of elements on the left == sum of elements on the right
(Excluding the element at the pivot index itself.)

To make this comparison easy, we can precompute:
- A **prefix sum array** (`leftArr`)
- A **suffix sum array** (`rightArr`)

At any index `i`:
- `leftArr[i]` = sum of elements from `0` to `i`
- `rightArr[i]` = sum of elements from `i` to `n-1`

If both are equal, then index `i` is the pivot.

---

### Approach  
1. Create a `leftArr` where each index stores the cumulative sum from the left.
2. Create a `rightArr` where each index stores the cumulative sum from the right.
3. Traverse the array:
   - If `leftArr[i] == rightArr[i]`, return `i`.
4. If no such index exists, return `-1`.

---

### Time & Space Complexity  
- **Time Complexity:** O(n)  
  - One pass to build `leftArr`
  - One pass to build `rightArr`
  - One pass to find the pivot
- **Space Complexity:** O(n)  
  - Extra arrays for prefix and suffix sums

---

# Code
```java []
class Solution {

    public int pivotIndex(int[] nums) {
        int n = nums.length;

        int[] leftArr = new int[n];
        int[] rightArr = new int[n];

        // add values in the leftArr
        int leftSum = 0;
        for (int i = 0; i < n; i++) {
            int curr = nums[i];
            leftSum += curr;
            leftArr[i] = leftSum;
        }

        // add values in the rightArr
        int rightSum = 0;
        for (int i = n - 1; i >= 0; i--) {
            int curr = nums[i];
            rightSum += curr;
            rightArr[i] = rightSum;
        }

        // Find out the index where they both are equal
        for (int i = 0; i < n; i++) {
            if (leftArr[i] == rightArr[i]) {
                return i;
            }
        }

        return -1;
    }
}

```
