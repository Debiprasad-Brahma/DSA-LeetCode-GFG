# 🧩 LeetCode 4 — Median of Two Sorted Arrays

## 🧠 Intuition
The task is to find the **median** of two sorted arrays.  
A straightforward way to solve this problem is to **combine both arrays**, **sort** the merged list, and then find the middle value(s).  
This approach leverages the simplicity of built-in sorting and works well for small to medium inputs.

If the total number of elements is:
- **Odd** → The median is the middle element.  
- **Even** → The median is the average of the two middle elements.

---

## 💡 Approach
1. Create a new list to store elements from both arrays.
2. Add all elements from `nums1` and `nums2` into this list.
3. Sort the combined list using `Collections.sort()`.
4. Find the median:
   - If the size is **odd**, return the middle element.
   - If the size is **even**, return the average of the two middle elements.
5. Return the result as a `double` for precision.

This is a **brute-force** approach that is easy to understand and implement.

---

## ⏱️ Complexity
### Time Complexity:
**O((m + n) log(m + n))**  
- We merge both arrays (`O(m + n)`) and then sort them (`O((m + n) log(m + n))`).

### Space Complexity:
**O(m + n)**  
- Because we store all elements from both arrays in a new list.

---

## 🧮 Code
```java
import java.util.*;

class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        List<Integer> list = new ArrayList<>();

        // Merge both arrays
        for (int num : nums1) list.add(num);
        for (int num : nums2) list.add(num);

        // Sort the combined list
        Collections.sort(list);

        int n = list.size();

        // If odd, return middle element
        if (n % 2 != 0) {
            return list.get(n / 2);
        } 
        // If even, return average of two middle elements
        else {
            int mid = n / 2;
            return (list.get(mid) + list.get(mid - 1)) / 2.0;
        }
    }
}
