# Kids With the Greatest Number of Candies

### Intuition
We need to determine whether each kid can have the **greatest number of candies** if given some extra candies.  
The trick is to first find the **current maximum candies** among all kids.  
Then, for each kid, check if their candies plus the `extraCandies` is at least equal to this maximum.  

---

### Approach
1. Find the **maximum number of candies** among all kids.  
2. Iterate through each kid’s candies:  
   - If `candies[i] + extraCandies >= max`, that kid can reach the maximum, so mark `true`.  
   - Otherwise, mark `false`.  
3. Store results in a `List<Boolean>` and return it.  

---

### Complexity
- **Time Complexity:**  
  - Finding the max → \(O(n)\).  
  - Checking each kid → \(O(n)\).  
  - **Total = \(O(n)\).**

- **Space Complexity:**  
  - Only output list storage → \(O(n)\).  

---

### Code (Java)

```java
import java.util.*;

class Solution {
    public List<Boolean> kidsWithCandies(int[] candies, int extraCandies) {
        int max = 0;

        // Step 1: Find maximum candies
        for (int i = 0; i < candies.length; i++) {
            max = Math.max(max, candies[i]);
        }

        List<Boolean> ans = new ArrayList<>();

        // Step 2: Check each kid
        for (int can : candies) {
            if (can + extraCandies >= max)
                ans.add(true);
            else
                ans.add(false);
        }

        return ans;
    }
}
