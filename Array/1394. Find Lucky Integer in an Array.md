# Find Lucky Integer in an Array

## Intuition
We need to find the largest integer in the array whose frequency is equal to its value.  
Example: If `2` appears `2` times, it's a "lucky" integer.

## Approach
1. Use a frequency array (`freq`) of size `501` (since the constraint ensures numbers are ≤ 500).
2. Count the occurrences of each number in the array.
3. Iterate through the frequency array:
   - If `freq[i] == i`, then `i` is a lucky integer.
   - Keep updating the answer with the latest valid lucky number (ensures the largest lucky integer is returned).
4. If no such integer exists, return `-1`.

## Complexity
- **Time Complexity:**  
  - O(n + m), where `n` is the size of `arr` and `m` is the range of numbers (≤ 500).  
  - Effectively O(n), since 500 is constant.
- **Space Complexity:**  
  - O(m) = O(500) = O(1) (constant extra space for frequency array).

---

## Code
```java
class Solution {
    public int findLucky(int[] arr) {
        int [] freq = new int[501]; // Frequency array
        for(int i : arr){
            freq[i]++; // Count occurrences
        }
        int ans = -1;
        for(int i = 1; i < freq.length; i++){
            if(freq[i] == i) // Check if frequency matches the value
                ans = i; // Update with latest lucky number
        }
        return ans; // Return largest lucky number or -1
    }
}
