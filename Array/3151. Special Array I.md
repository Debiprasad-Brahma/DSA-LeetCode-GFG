# LeetCode: 3151. Special Array I
## Intuition
For an array to be *special*, every adjacent pair must have **different parity** (one even, one odd).  
Thus, if we ever find two consecutive numbers that are both even or both odd, the array is not special.  

---

## Approach
1. If the array length is `1`, it is trivially special.  
2. Iterate through the array from index `0` to `n-2`.  
3. For each pair `(nums[i], nums[i+1])`, check if they have the **same parity**:  
   - Same parity → return `false`.  
   - Different parity → continue.  
4. If no adjacent pair breaks the rule, return `true`.  

---

## Complexity
- **Time Complexity:** `O(n)` – we check each adjacent pair once.  
- **Space Complexity:** `O(1)` – no extra data structures used.  

---

## Code
```java
class Solution {
    public boolean isArraySpecial(int[] nums) {
        // Single element is always special
        if (nums.length == 1) return true;

        // Check consecutive pairs
        for (int i = 0; i < nums.length - 1; i++) {
            if ((nums[i] % 2) == (nums[i + 1] % 2)) {
                return false; // same parity found
            }
        }
        return true; // all pairs have different parity
    }
}
