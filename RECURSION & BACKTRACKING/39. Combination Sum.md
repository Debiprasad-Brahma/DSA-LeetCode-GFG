# 💡 Intuition
We need to explore all possible ways to form the target using available numbers.  
This is a classic **Backtracking** problem where we decide for each element:
1. **Include it** (if it doesn’t exceed the remaining target)
2. **Exclude it** (move to next element)

We recursively build all valid combinations and store the ones that sum up to the target.

---

# ⚙️ Approach
1. Use a helper recursive function `findCombinations` to explore all possibilities.
2. Maintain:
   - `idx` → current index in the `candidates` array  
   - `target` → remaining sum to achieve  
   - `ds` → current combination (dynamic list)  
   - `ans` → list of all valid combinations
3. Base Case:
   - If `idx == candidates.length`, check if `target == 0` and add the combination.
4. Recursive Case:
   - **Include** current number if it’s ≤ target → call recursively with `target - candidates[idx]`.
   - **Exclude** current number → call recursively with `idx + 1`.
5. Use **backtracking** to remove the last chosen element after exploring each path.

---

# ⏱️ Complexity Analysis
* Time Complexity	O(2^n) — Each element can be included or excluded multiple times.
* Space Complexity	O(target) — Due to recursive call stack and combination list.

# Code
```java []
class Solution {

    private void findCombinations(int idx, int[] candidates, int target, List<List<Integer>> ans, List<Integer> ds) {
        if (idx == candidates.length) {
            if (target == 0) {
                ans.add(new ArrayList<>(ds));
            }
            return;
        }

        if (candidates[idx] <= target) {
            ds.add(candidates[idx]);
            findCombinations(idx, candidates, target - candidates[idx], ans, ds);
            ds.remove(ds.size() - 1);
        }
        findCombinations(idx + 1, candidates, target, ans, ds);
    }

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> ans = new ArrayList<>();
        findCombinations(0, candidates, target, ans, new ArrayList<>());
        return ans;
    }
}
```
