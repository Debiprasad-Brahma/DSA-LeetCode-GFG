# 🧠 Intuition
We are counting **good numbers of length `n`** where:
- **Even indices (0-based)** → can have digits: `{0,2,4,6,8}` → **5 choices**
- **Odd indices** → can have prime digits: `{2,3,5,7}` → **4 choices**

So:
- Number of even positions = `(n + 1) / 2`
- Number of odd positions = `n / 2`

Total ways: (5 ^ evenPositions) * (4 ^ oddPositions)


Since `n` can be very large → we must use **fast exponentiation (binary exponentiation)** with modulo.

---

# 🚀 Approach
1. Compute:
   - `noOfEvenIndices = (n + 1) / 2`
   - `noOfOddIndices = n / 2`

2. Use **binary exponentiation** to compute:
   - `5 ^ evenIndices % MOD`
   - `4 ^ oddIndices % MOD`

3. Multiply results:
   - `(even * odd) % MOD`

---

# ⏱ Complexity

- **Time complexity:**  
  $$O(\log n)$$  
  Binary exponentiation reduces power computation.

- **Space complexity:**  
  $$O(\log n)$$ *(due to recursion stack)*

---
# Code
```java []
class Solution {
    static final int MOD = 1000000007;

    long findPower(int num, long pow){
        if(pow == 0) return 1; // base case

        long half = findPower(num, pow / 2);
        long res = (half * half) % MOD;

        if(pow % 2 == 1) res = (num * res) % MOD;

        return res;
    }
    public int countGoodNumbers(long n) {
        long noOfEvenIndices = (n + 1) / 2;
        long noOfOddIndices = n / 2;

        long even = findPower(5, noOfEvenIndices);
        long odd = findPower(4, noOfOddIndices);

        long ans = (even * odd) % MOD;

        return (int) ans;
    }
}

```
