## 🌳 LeetCode 637 — Average of Levels in Binary Tree | Level Order Traversal (BFS)

### 💡 Intuition  
We need to compute the **average value of nodes at each level** of a binary tree.

Key idea:
- Nodes at the same depth belong to the same **level**
- **Breadth-First Search (BFS)** naturally processes the tree level by level
- For each level:
  - Sum all node values
  - Divide by the number of nodes at that level

---

### 🧠 Approach  
1. Use a **Queue** to perform level-order traversal (BFS).
2. Start by adding the root node to the queue.
3. While the queue is not empty:
   - Store the current queue size → number of nodes at this level
   - Initialize `sum = 0`
   - Process exactly `size` nodes:
     - Add their values to `sum`
     - Push their children (left & right) into the queue
   - Compute the average: `sum / size`
   - Add it to the result list
4. Return the list of averages.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n)  
  - Each node is visited exactly once
- **Space Complexity:** O(n)  
  - Queue may store up to one full level of nodes

---

### 💻 Code  
```java
class Solution {

    public List<Double> averageOfLevels(TreeNode root) {
        if (root == null) return new ArrayList<>();

        Queue<TreeNode> que = new LinkedList<>();
        que.add(root);

        List<Double> ans = new ArrayList<>();

        while (!que.isEmpty()) {
            int size = que.size();
            double sum = 0.0;

            for (int i = 0; i < size; i++) {
                TreeNode curr = que.poll();
                sum += curr.val;

                if (curr.left != null) que.add(curr.left);
                if (curr.right != null) que.add(curr.right);
            }
            ans.add(sum / size);
        }
        return ans;
    }
}
