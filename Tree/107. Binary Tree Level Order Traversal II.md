## 🔁 LeetCode 107 — Binary Tree Level Order Traversal II | Bottom-Up BFS

### 💡 Intuition  
This problem requires traversing the tree **level by level (BFS)** but returning the result **from bottom to top**.

A simple trick:
- Perform normal BFS (top → bottom)
- Instead of adding each level to the end of the list, add it at the **front (index 0)**  
This automatically reverses the level order without needing extra operations.

---

### 🧠 Approach  
1. If `root == null`, return an empty list.  
2. Use a queue to perform normal level-order BFS.  
3. For each level:
   - Retrieve all nodes in the current level (`size = queue.size()`)
   - Add their children to the queue
   - Collect node values in a list `row`
4. Instead of `list.add(row)`, do `list.add(0, row)` so the final order is bottom-up.
5. Return the final list.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — each node is visited once.  
- **Space Complexity:** O(n) — queue + result list.

---

### 💻 Code  
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    public List<List<Integer>> levelOrderBottom(TreeNode root) {
        List<List<Integer>> list = new ArrayList<>();
        Queue<TreeNode> que = new LinkedList<>();

        if (root == null) return list;

        que.offer(root);

        while (!que.isEmpty()) {
            List<Integer> row = new ArrayList<>();
            int size = que.size();

            for (int i = 0; i < size; i++) {
                TreeNode front = que.poll();
                row.add(front.val);

                if (front.left != null) que.offer(front.left);
                if (front.right != null) que.offer(front.right);
            }

            list.add(0, row); // add each level at the front
        }

        return list;
    }
}
