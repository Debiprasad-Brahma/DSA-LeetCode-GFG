## 🍃 LeetCode 872 — Leaf-Similar Trees | DFS Leaf Collection Approach

### 💡 Intuition  
Two binary trees are **leaf-similar** if their **leaf value sequences** (values encountered from left to right) are identical.

To determine this, we simply:
1. Collect all leaf values of `root1` into a list (`ls1`)
2. Collect all leaf values of `root2` into another list (`ls2`)
3. Compare both lists

If both sequences match exactly, the trees are leaf-similar.

---

### 🧠 Approach  
- Use a helper DFS method:
  - Visit left subtree → check if leaf → visit right subtree
  - When a node is a leaf (`left == null && right == null`), record its value
- After generating both sequences:
  - If lengths differ → sequences differ
  - Otherwise, use `.equals()` to compare both lists

---

### ⏱️ Complexity  
- **Time Complexity:** O(n + m) — DFS traversal of both trees  
- **Space Complexity:** O(h1 + h2) — recursion stack + leaf list storage  
  (h = height of tree)

---

### 💻 Code  
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    public boolean leafSimilar(TreeNode root1, TreeNode root2) {
        List<Integer> ls1 = new ArrayList<>();
        List<Integer> ls2 = new ArrayList<>();

        dfs(root1, ls1);
        dfs(root2, ls2);

        if (ls1.size() != ls2.size()) return false;

        return ls1.equals(ls2);
    }

    void dfs(TreeNode node, List<Integer> ls) {
        if (node == null) return;

        dfs(node.left, ls);
        if (node.left == null && node.right == null) {
            ls.add(node.val);
        }
        dfs(node.right, ls);
    }
}
