## 🌲 LeetCode 958 — Check Completeness of a Binary Tree | Level-Order (BFS) Approach

### 💡 Intuition  
A **complete binary tree** must satisfy two rules:
1. Every level (except possibly the last) is completely filled.
2. All nodes in the last level appear **as far left as possible**.

A clean way to verify this is using **level-order traversal (BFS)**:
- Once we encounter the **first null child**, every following node must also be `null`.
- If we ever see a *non-null node after a null*, the tree is **not complete**.

---

### 🧠 Approach  
1. If root is null → return false (though some allow empty tree as complete).
2. Use a queue for BFS.
3. Start with `isNull = false`:  
   - Poll nodes from queue.
   - If we encounter a `null`, mark `isNull = true`.
   - If a non-null node appears **after** `isNull` is true → return false.
4. If the BFS ends without violation → return true.

This logic ensures the tree satisfies left-to-right filling.

---

### ⏱️ Complexity  
- **Time Complexity:** O(n) — every node is visited once.  
- **Space Complexity:** O(n) — queue can hold up to one full level of the tree.

---

### 💻 Code  
```java
class Solution {

    public boolean isCompleteTree(TreeNode root) {
        if (root == null) return false;

        Queue<TreeNode> que = new LinkedList<>();
        que.add(root);

        boolean isNull = false;

        while (!que.isEmpty()) {
            TreeNode curr = que.poll();

            if (curr == null) {
                isNull = true;
            } else {
                // If we saw a null earlier but now see a node, it's not complete
                if (isNull) return false;

                que.add(curr.left);
                que.add(curr.right);
            }
        }
        return true;
    }
}
