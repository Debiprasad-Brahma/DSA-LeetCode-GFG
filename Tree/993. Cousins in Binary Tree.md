# 🧩 Is Cousins in Binary Tree

## Intuition
The problem is asking whether two nodes in a binary tree are cousins.  
Two nodes are considered cousins if:
1. They are on the **same level** in the binary tree.
2. They have **different parents**.  

So, the main idea is to perform a **level-order traversal (BFS)** and check both conditions:
- Ensure that `x` and `y` are found at the same depth.  
- Ensure they are not siblings (i.e., not having the same parent).

---

## Approach
1. Perform a **BFS traversal** using a queue.
2. At each level:
   - Track if we find `x` or `y`.
   - Check if they are siblings (children of the same parent).
   - If yes → return `false` immediately.
3. After processing a level:
   - If both `x` and `y` are found at that level → return `true`.
   - If only one is found → return `false` (because they are not at the same level).
4. Continue until the queue is empty.

---

## Complexity
- **Time complexity:**  
  Each node is visited once → **O(n)** where `n` is the number of nodes.
  
- **Space complexity:**  
  In the worst case (when the tree is skewed), the queue can hold up to `O(n)` nodes.  
  So → **O(n)**.

---

## Code
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    public boolean isCousins(TreeNode root, int x, int y) {
        if (root == null) return false;

        Queue<TreeNode> que = new LinkedList<>();
        que.add(root);

        while (!que.isEmpty()) {
            int size = que.size();
            boolean foundX = false;
            boolean foundY = false;

            // Process one level
            for (int i = 0; i < size; i++) {
                TreeNode curr = que.poll();

                // Check if they are siblings
                if (curr.left != null && curr.right != null) {
                    if ((curr.left.val == x && curr.right.val == y) ||
                        (curr.left.val == y && curr.right.val == x)) {
                        return false;
                    }
                }

                if (curr.left != null) {
                    que.add(curr.left);
                    if (curr.left.val == x) foundX = true;
                    if (curr.left.val == y) foundY = true;
                }

                if (curr.right != null) {
                    que.add(curr.right);
                    if (curr.right.val == x) foundX = true;
                    if (curr.right.val == y) foundY = true;
                }
            }

            // Check if both found in the same level
            if (foundX && foundY) return true;
            if (foundX || foundY) return false;
        }

        return false;
    }
}
