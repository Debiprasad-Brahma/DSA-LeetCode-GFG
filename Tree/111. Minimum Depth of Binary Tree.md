## 🌳 LeetCode 111 — Minimum Depth of Binary Tree | Recursive DFS Approach

### 💡 Intuition
The **minimum depth** of a binary tree is the shortest distance from the root node down to the nearest **leaf node** (a node with no children).  

We can use a **recursive depth-first search (DFS)** to explore all paths and find the minimum depth efficiently.

---

### 🧠 Approach
1. **Base Cases:**
   - If the tree is empty (`root == null`), return `0`.
   - If the node is a **leaf node** (`left == null && right == null`), return `1`.

2. For each non-leaf node:
   - Recursively calculate the minimum depth of both left and right subtrees.
   - If one child is `null`, skip it by assigning `Integer.MAX_VALUE` so that the other valid subtree is considered.

3. Return `1 + min(leftDepth, rightDepth)` to include the current node in the count.

---

### ⏱️ Complexity
- **Time Complexity:** O(n) — each node is visited once.  
- **Space Complexity:** O(h) — recursive call stack where `h` is the tree height (O(log n) for balanced, O(n) for skewed trees).

---

### 💻 Code
```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    public int minDepth(TreeNode root) {
        if (root == null) return 0;
        if (root.left == null && root.right == null) return 1;

        int l = root.left != null ? minDepth(root.left) : Integer.MAX_VALUE;
        int r = root.right != null ? minDepth(root.right) : Integer.MAX_VALUE;

        return 1 + Math.min(l, r);
    }
}
