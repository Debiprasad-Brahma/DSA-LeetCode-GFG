## 🔍 LeetCode 700 — Search in a Binary Search Tree | Iterative BST Search

### 💡 Intuition  
In a **Binary Search Tree (BST)**:
- Left subtree contains values **less than** the node
- Right subtree contains values **greater than** the node  

This property allows us to search efficiently by comparing the target value with the current node:

- If `val == root.val` → found  
- If `val < root.val` → search left  
- If `val > root.val` → search right

This makes BST search **O(log n)** on average.

---

### 🧠 Approach  
Use an **iterative** search (no recursion needed):
1. Start from the root.
2. While the current node isn't null:
   - If it matches the target, return the node.
   - If target is larger, move to `root.right`.
   - Else move to `root.left`.
3. If the loop ends, target was not found → return `null`.

This returns the **subtree beginning at the node** containing `val`.

---

### ⏱️ Complexity  
- **Time Complexity:** O(h) — height of the tree (O(log n) average, O(n) worst-case).  
- **Space Complexity:** O(1) — no extra memory used.

---

### 💻 Code  
```java
class Solution {

    public TreeNode searchBST(TreeNode root, int val) {
        while (root != null) {
            if (root.val == val) 
                break;
            else if (val > root.val) 
                root = root.right;
            else 
                root = root.left;
        }
        return root;
    }
}
