# 🌴 Island Perimeter | DFS Flood Fill | O(m × n) Time

## Intuition
The perimeter of an island is determined by the **number of edges that touch water or the grid boundary**.  
We can solve this by exploring each land cell (`1`) and counting how many of its sides face **water (`0`) or out of bounds**.  

Using **DFS flood fill**, we visit every land cell once:
- If the DFS goes out of bounds or into water → add `1` to perimeter.  
- If the DFS goes into an already visited cell (`-1`) → do nothing.  

---

## Approach
1. Iterate through the grid to find the first land cell (`1`).  
2. Start a DFS flood fill from this cell.  
   - Each time DFS hits a boundary or water → increment perimeter count.  
   - Mark visited land as `-1` to avoid re-processing.  
3. Since there’s only one island, return the perimeter after the DFS completes.  

---

## Complexity
- **Time Complexity:** **O(m × n)**  
  - Each cell is visited at most once.  
- **Space Complexity:** **O(m × n)** (recursion stack in the worst case).  

---

## Code
```java
class Solution {
    int peri;

    void dfsUtil(int[][] grid, int i, int j) {
        int m = grid.length;
        int n = grid[0].length;

        // If out of bounds or water -> add to perimeter
        if (i < 0 || i >= m || j < 0 || j >= n || grid[i][j] == 0) {
            peri++;
            return;
        }

        // Already visited
        if (grid[i][j] == -1) {
            return;
        }

        grid[i][j] = -1; // mark as visited

        // Explore 4 directions
        dfsUtil(grid, i + 1, j);
        dfsUtil(grid, i - 1, j);
        dfsUtil(grid, i, j + 1);
        dfsUtil(grid, i, j - 1);
    }

    public int islandPerimeter(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;
        peri = 0;

        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) {
                    dfsUtil(grid, i, j);
                    return peri; // Only one island
                }
            }
        }
        return -1;
    }
}
