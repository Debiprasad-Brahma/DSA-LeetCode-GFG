# 📝 Course Schedule (DFS Cycle Detection)

## 🔎 Intuition
We are asked whether it’s possible to finish all courses given prerequisites.  
This is the same as asking:  

👉 Does the **directed graph** formed by courses and prerequisites contain a **cycle**?  
- If a cycle exists → you get stuck in a loop of prerequisites → **cannot finish**.  
- If no cycle exists → a valid topological order exists → **can finish**.  

Thus, the problem reduces to **cycle detection in a directed graph**.

---

## 🚀 Approach
1. **Graph Representation**  
   - Use an adjacency list to represent course dependencies.  
   - Each edge `[a, b]` means `b → a` (to take course `a`, you must finish course `b`).  

2. **DFS with Cycle Detection**  
   - Maintain two arrays:  
     - `visited[]`: permanently marks nodes that are fully processed.  
     - `pathVisited[]`: tracks nodes currently in the recursion stack.  
   - While exploring neighbors of a node:
     - If a neighbor is not visited → recursively DFS.  
     - If a neighbor is already in the current recursion stack (`pathVisited[neighbor] == true`) → **cycle found**.  

3. **Backtracking**  
   - After finishing DFS for a node, mark `pathVisited[node] = false` (leave recursion stack).  

4. **Result**  
   - If any DFS call detects a cycle → return `false` (cannot finish).  
   - Otherwise, return `true`.  

---

## 💻 Code (Java)

```java
import java.util.*;

class Solution {

    public boolean canFinish(int numCourses, int[][] prerequisites) {
        boolean[] visited = new boolean[numCourses];
        boolean[] pathVisited = new boolean[numCourses];

        // Build adjacency list
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }
        for (int[] pre : prerequisites) {
            adj.get(pre[1]).add(pre[0]); // b → a
        }

        // Run DFS from every unvisited node
        for (int i = 0; i < numCourses; i++) {
            if (!visited[i]) {
                if (dfs(i, adj, visited, pathVisited)) {
                    return false; // cycle found
                }
            }
        }

        return true; // no cycle found
    }

    private boolean dfs(int node, List<List<Integer>> adj, boolean[] visited, boolean[] pathVisited) {
        visited[node] = true;
        pathVisited[node] = true;

        for (int neighbor : adj.get(node)) {
            if (!visited[neighbor]) {
                if (dfs(neighbor, adj, visited, pathVisited)) {
                    return true; // cycle found in recursion
                }
            } else if (pathVisited[neighbor]) {
                return true; // back edge → cycle
            }
        }

        pathVisited[node] = false; // backtrack
        return false;
    }
}

## 🚀 Kahn's Topo Approach
```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        ArrayList<ArrayList<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }

        for (int[] mat : prerequisites) {
            adj.get(mat[1]).add(mat[0]); // b -> a
        }

        int[] indeg = new int[numCourses];

        for (int i = 0; i < numCourses; i++) {
            for (int node : adj.get(i)) {
                indeg[node]++; // all indeg value
            }
        }

        Queue<Integer> que = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if(indeg[i] == 0)
            que.offer(i);
        }

        int cnt = 0;
        while(!que.isEmpty()){
            int node = que.poll();
            cnt++;

            for(int n : adj.get(node)){
                indeg[n]--;
                if(indeg[n] == 0)
                que.add(n);
            }
        }

        return (cnt == numCourses) ? true : false;
    }
}
