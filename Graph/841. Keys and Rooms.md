# 🗝️ Keys and Rooms | DFS Graph Traversal | O(n + e) Time

## Intuition
We are given `n` rooms, each containing keys to other rooms. Starting from room `0`, we need to determine if it’s possible to visit all rooms.  

This is essentially a **graph traversal problem**:  
- Rooms → nodes.  
- Keys → edges.  
We just need to check if all nodes are reachable from node `0`.  

---

## Approach
1. Represent rooms as an adjacency list (`rooms`).  
2. Start a **DFS traversal** from room `0`.  
3. Use a `visited[]` array to mark rooms that have been entered.  
4. Recursively explore all neighbors (keys) from the current room.  
5. After DFS, check if all rooms were visited.  
   - If yes → return `true`.  
   - Otherwise → return `false`.  

---

## Complexity
- **Time Complexity:**  
  Each room and each key is visited at most once → **O(n + e)**,  
  where `n` = number of rooms, `e` = total number of keys.  
- **Space Complexity:**  
  - `visited[]` array → **O(n)**.  
  - DFS recursion stack (worst case) → **O(n)**.  

---

## Code
```java
class Solution {
    public boolean canVisitAllRooms(List<List<Integer>> rooms) {
        int n = rooms.size();
        boolean[] visited = new boolean[n];
        dfsutil(rooms, visited, 0);

        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                return false;
            }
        }
        return true;
    }

    void dfsutil(List<List<Integer>> adj, boolean[] visited, int node) {
        visited[node] = true;
        for (int neighbour : adj.get(node)) {
            if (!visited[neighbour])
                dfsutil(adj, visited, neighbour);
        }
    }
}
