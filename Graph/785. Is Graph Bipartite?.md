# 🎨 Is Graph Bipartite? | BFS Coloring | O(V + E) Time

## Intuition
A graph is **bipartite** if its nodes can be divided into two groups such that no two adjacent nodes belong to the same group.  
This is equivalent to checking if the graph can be **colored with 2 colors** without conflicts.  

We can use **BFS** to attempt coloring:
- Start from an unvisited node, assign color `0`.
- For every neighbor, assign the opposite color (`1 - current`).
- If we ever find a neighbor with the same color → the graph is not bipartite.

---

## Approach
1. Initialize a `color[]` array with `-1` (uncolored).  
2. For each node:
   - If it is uncolored, run a BFS starting from it.  
   - Use a queue to process nodes and assign opposite colors to neighbors.  
   - If a neighbor already has the same color, return `false`.  
3. If all connected components are processed without conflict → return `true`.  

---

## Complexity
- **Time Complexity:** **O(V + E)**  
  - We visit each vertex once and traverse each edge once.  
- **Space Complexity:** **O(V)**  
  - For the `color[]` array and BFS queue.  

---

## Code
```java
class Solution {

    boolean bfsCheck(int start, int[][] graph, int[] color) {
        Queue<Integer> que = new LinkedList<>();
        que.offer(start);
        color[start] = 0; // assign color 0

        while (!que.isEmpty()) {
            int node = que.poll();

            for (int nei : graph[node]) {
                if (color[nei] == -1) {
                    color[nei] = 1 - color[node]; // assign reverse color
                    que.offer(nei);
                } else if (color[nei] == color[node]) {
                    return false; // conflict found
                }
            }
        }
        return true;
    }

    public boolean isBipartite(int[][] graph) {
        int v = graph.length;
        int[] color = new int[v];
        Arrays.fill(color, -1);

        for (int i = 0; i < v; i++) {
            if (color[i] == -1) {
                if (!bfsCheck(i, graph, color)) return false;
            }
        }
        return true;
    }
}
