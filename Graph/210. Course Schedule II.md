# 📘 Course Schedule II (Topological Sort - DFS Approach)

## 🧠 Intuition
The problem asks us to return a valid order in which we can finish all courses, given prerequisite pairs.  
This is a **classic topological sorting** problem on a directed graph:
- Courses = nodes  
- Prerequisites = directed edges (e.g., `a → b` means you must take `a` before `b`).  

If the graph contains a **cycle**, there’s no way to finish all courses, so we return an empty array.  
Otherwise, a **topological order** gives us a valid schedule.

---

## 🚀 Approach
1. **Graph Representation**  
   - Use an adjacency list to store prerequisites.  
   - `adj[course]` contains the list of courses dependent on it.

2. **DFS with Cycle Detection**  
   - Each node has 3 states:  
     - `0` → unvisited  
     - `1` → visiting (in recursion stack)  
     - `2` → visited (fully processed)  
   - While exploring neighbours:
     - If we find a node in `visiting` state again → cycle detected → return empty array.  
     - If neighbour is unvisited, recursively DFS into it.

3. **Topological Order**  
   - After fully processing a node (no cycles in its neighbours), push it into a stack.  
   - Finally, pop elements from the stack to build the valid course order.

---

## ⏱️ Complexity
- **Time Complexity:** `O(V + E)`  
  - `V = numCourses`, `E = prerequisites.length`  
  - We visit each node and edge once in DFS.
- **Space Complexity:** `O(V + E)`  
  - Adjacency list takes `O(E)`  
  - Recursion stack + visited array take `O(V)`

---

## 📝 Code

```java
class Solution {

    public int[] findOrder(int numCourses, int[][] prerequisites) {
        List<List<Integer>> adj = new ArrayList<>();

        // Build adjacency list
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }
        for (int[] pre : prerequisites) {
            adj.get(pre[1]).add(pre[0]);
        }

        Stack<Integer> stk = new Stack<>();
        int[] visited = new int[numCourses]; // 0 = unvisited, 1 = visiting, 2 = visited

        // DFS on each unvisited node
        for (int i = 0; i < numCourses; i++) {
            if (visited[i] == 0) {
                if (!dfs(i, visited, adj, stk)) {
                    return new int[0]; // cycle detected → no valid order
                }
            }
        }

        // Build result from stack
        int[] ans = new int[numCourses];
        for (int i = 0; i < numCourses; i++) {
            if (!stk.isEmpty()) {
                ans[i] = stk.pop();
            }
        }
        return ans;
    }

    private boolean dfs(int node, int[] visited, List<List<Integer>> adj, Stack<Integer> stk) {
        visited[node] = 1; // Mark visiting

        for (int neighbour : adj.get(node)) {
            if (visited[neighbour] == 1) {
                return false; // cycle found
            }
            if (visited[neighbour] == 0) {
                if (!dfs(neighbour, visited, adj, stk)) {
                    return false;
                }
            }
        }

        visited[node] = 2; // mark fully visited
        stk.push(node);
        return true;
    }
}
