# Eventual Safe States (LeetCode 802)

## Intuition
In a directed graph, a node is called **eventual safe** if all paths starting from it eventually lead to a terminal node (a node with no outgoing edges).  
If a node is part of a cycle or leads to a cycle, it is not safe.  

We can detect cycles using **DFS with recursion stack tracking**:
- `vis[i]` → whether node `i` has been visited at least once.
- `pvis[i]` → whether node `i` is currently in the recursion stack.
- If during DFS we revisit a node already in the recursion stack, a cycle is detected → unsafe node.
- Otherwise, if all children of a node are safe, then the node itself is safe.

---

## Approach
1. Use DFS to explore each node.
2. Mark the current node as visited (`vis[start] = 1`) and as part of the current recursion stack (`pvis[start] = 1`).
3. Traverse all neighbors:
   - If the neighbor is not visited, recursively DFS into it.
   - If the neighbor is already in the recursion stack, a cycle is found → return `false`.
4. If all neighbors are safe, mark the node as safe and add it to the result list.
5. Reset `pvis[start] = 0` after exploring all children (backtracking).
6. Finally, sort the safe nodes and return.

---

## Complexity
- **Time complexity:**  
  `O(V + E)`  
  - Each node is visited once.  
  - Each edge is traversed once in the DFS.  

- **Space complexity:**  
  `O(V)`  
  - For the recursion stack and `vis`, `pvis` arrays.  
  - Result list also takes `O(V)`.

---

## Code
```java
class Solution {

    private boolean dfs(int[][] graph, int start, int[] vis, int[] pvis, ArrayList<Integer> res) {
        vis[start] = 1;
        pvis[start] = 1;

        for (int node : graph[start]) {
            if (vis[node] == 0) {
                if (!dfs(graph, node, vis, pvis, res)) return false; // Cycle detection
            } else if (pvis[node] == 1) return false; // Cycle detection
        }
        res.add(start);
        pvis[start] = 0;
        return true;
    }

    public List<Integer> eventualSafeNodes(int[][] graph) {
        int n = graph.length;
        ArrayList<Integer> ans = new ArrayList<>();
        int[] vis = new int[n];
        int[] pvis = new int[n];

        for (int i = 0; i < n; i++) {
            vis[i] = 0;
            pvis[i] = 0;
        }

        for (int i = 0; i < n; i++) {
            if (vis[i] == 0) {
                dfs(graph, i, vis, pvis, ans);
            }
        }

        Collections.sort(ans); // Sorting the ans
        return ans;
    }
}
