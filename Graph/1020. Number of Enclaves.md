# 🏝️ Number of Enclaves Problem (LeetCode 1020)

## 🔎 Intuition
We are asked to find the number of land cells (`1`) that are **completely surrounded by water (`0`)**, i.e., they cannot reach the boundary of the grid.  

Key observation:  
- Any land (`1`) that **touches the boundary** (first/last row or column) is **not an enclave**, since it can "walk out" of the grid.  
- So, if we **remove all land cells connected to the boundary**, the remaining land cells are guaranteed to be enclaves.  

This naturally leads to a **flood fill (DFS/BFS)** solution.

---

## 🛠️ Approach
1. Traverse all **boundary cells** (first row, last row, first column, last column).  
2. If a land cell (`1`) is found on the boundary, perform **DFS** (or BFS) to mark the entire connected component as water (`0`).  
   - This ensures that boundary-connected lands are removed.  
3. After processing boundaries, traverse the whole grid again and **count the remaining land cells (`1`)**.  
   - These remaining cells are enclaves.

---

## ⏱️ Complexity Analysis

### Time Complexity
- Each cell is visited **at most once**.  
- Total complexity: **O(m × n)**, where `m` = rows and `n` = columns.  

### Space Complexity
- **DFS:** recursion depth can go up to **O(m × n)** in the worst case.  
- **BFS:** queue may hold all land cells in the worst case → **O(m × n)**.  

---

## 💻 DFS Solution (Java)

```java
class Solution {

    void dfs(int[][] grid, int i, int j){

        if(i < 0 || i >= grid.length || j < 0 || j >= grid[0].length || grid[i][j] == 0){
            return;
        }

        grid[i][j] = 0; // Marking as visited

        // For Left Right Up Down
        dfs(grid, i, j+1);
        dfs(grid, i, j-1);
        dfs(grid, i+1, j);
        dfs(grid, i-1, j);
    }
    public int numEnclaves(int[][] grid) {
        int m = grid.length;
        int n = grid[0].length;


        for(int row=0; row<m; row++){
            // First Column
            if(grid[row][0] == 1) dfs(grid, row, 0);
            
            // Last Column
            if(grid[row][n-1] == 1) dfs(grid, row, n-1);
        }

        for(int colm=0; colm<n; colm++){
            // First Row
            if(grid[0][colm] == 1) dfs(grid, 0, colm);

            // Last Row
            if(grid[m-1][colm] == 1) dfs(grid, m-1, colm);
        }

        int count = 0;
        for(int i=0; i<m; i++){
            for(int j=0; j<n; j++){
                if(grid[i][j] == 1){
                    count++; // count no of 1s present
                }
            }
        }

        return count;
    }
}
```
## 💻 BFS Solution (Java)

```java
import java.util.*;

class Solution {
    public int numEnclaves(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Queue<int[]> q = new LinkedList<>();

        // Add all boundary land cells to queue
        for (int row = 0; row < m; row++) {
            if (grid[row][0] == 1) {
                q.offer(new int[]{row, 0});
                grid[row][0] = 0;
            }
            if (grid[row][n - 1] == 1) {
                q.offer(new int[]{row, n - 1});
                grid[row][n - 1] = 0;
            }
        }

        for (int col = 0; col < n; col++) {
            if (grid[0][col] == 1) {
                q.offer(new int[]{0, col});
                grid[0][col] = 0;
            }
            if (grid[m - 1][col] == 1) {
                q.offer(new int[]{m - 1, col});
                grid[m - 1][col] = 0;
            }
        }

        // Directions for BFS
        int[][] dirs = {{1,0}, {-1,0}, {0,1}, {0,-1}};

        // BFS traversal
        while (!q.isEmpty()) {
            int[] cell = q.poll();
            int i = cell[0], j = cell[1];

            for (int[] d : dirs) {
                int ni = i + d[0], nj = j + d[1];
                if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                    grid[ni][nj] = 0;
                    q.offer(new int[]{ni, nj});
                }
            }
        }

        // Count remaining land cells
        int count = 0;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 1) count++;
            }
        }

        return count;
    }
}
```
