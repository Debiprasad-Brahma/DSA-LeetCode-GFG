# Find Number of Provinces (DFS Approach)

## Problem Overview
Given an `n x n` adjacency matrix `isConnected` representing a network of cities:
- `isConnected[i][j] = 1` means city `i` and city `j` are directly connected.
- `isConnected[i][j] = 0` means they are not directly connected.

A **province** is a group of directly or indirectly connected cities that are isolated from other cities.  
The task is to find the **total number of provinces**.

---

## Intuition
We can think of each city as a node in a graph and each connection as an edge.  
Two cities belong to the same province if there is a path (direct or indirect) between them.  
We can traverse the graph using **Depth First Search (DFS)** and mark visited nodes.  
Each time we start a DFS from an unvisited node, it means we found a **new province**.

---

## Approach
1. **Initialization**
   - Create a `visited` array to track visited cities.
   - Initialize a counter `count` to store the number of provinces.

2. **Traversal**
   - Loop through each city:
     - If the city has not been visited:
       - Run DFS starting from that city.
       - Increment `count` (new province found).

3. **DFS Function**
   - Mark the current city as visited.
   - Recursively visit all directly connected unvisited cities.

---

## Complexity Analysis
- **Time Complexity:**  
  - `O(n^2)` — We potentially check each cell in the adjacency matrix once during DFS traversal.
- **Space Complexity:**  
  - `O(n)` — For the visited array and recursion stack in worst case.

---

## Code
```java
// Leet Code - 547
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        boolean[] visited = new boolean[n];
        int count = 0;
        for (int i = 0; i < n; i++) {
            if (!visited[i]) {
                dfs(visited, isConnected, i);
                count++; // found a new province
            }
        }
        return count;
    }

    void dfs(boolean[] visited, int[][] isConnected, int node){
        visited[node]= true;
        for(int i=0; i< isConnected.length; i++){
           if (isConnected[node][i] == 1 && !visited[i]) {
                dfs(visited, isConnected, i);
            }
        }
    }
}
