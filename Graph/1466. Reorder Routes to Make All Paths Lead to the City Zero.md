# 🔁 LeetCode 1466 — Reorder Routes to Make All Paths Lead to the City Zero

### 🧠 Intuition
We are given a **directed graph** representing city connections.  
Each directed edge `(u → v)` means that there’s a one-way road from city `u` to city `v`.  

Our goal is to find the **minimum number of roads** that must be **reversed** so that **every city can reach city `0`**.

The key observation is that the graph is **connected** (n cities and n-1 roads form a tree structure).  
By performing a **DFS starting from city 0**, we can count how many edges are directed **away from 0**, since those are the ones that need to be reversed.

---

### 💡 Approach
1. Build an **adjacency list** to represent both directions of each road:
   - Store `v` as **positive** for the **original direction** `(u → v)`.
   - Store `-u` as **negative** for the **reverse edge** `(v → u)` to keep track of direction.
2. Perform a **DFS** starting from node `0`.
3. For each neighbor:
   - If it’s not visited, recursively call DFS on it.
   - If the neighbor is **positive**, it means the edge points **away from 0**, so increment the count (edge needs reversal).
   - Continue DFS on both directions to cover the whole graph.
4. Return the total count of reversed edges.

---

### ⏱️ Complexity
- **Time Complexity:** `O(n)` — Each edge and node is visited once.  
- **Space Complexity:** `O(n)` — For adjacency list and recursion stack.

---

### ✅ Code
```java
class Solution {

    int dfs(List<List<Integer>> adj, boolean[] visited, int node){
        visited[node] = true;
        int cnt = 0;

        for(int nei : adj.get(node)){
            if(!visited[Math.abs(nei)]){
                // If the edge is in the original direction (needs to be reversed)
                cnt += dfs(adj, visited, Math.abs(nei)) + (nei > 0 ? 1 : 0);
            }
        }
        return cnt;
    }

    public int minReorder(int n, int[][] connections) {
        List<List<Integer>> adj = new ArrayList<>();
        for(int i=0; i<n; i++)
            adj.add(new ArrayList<>());

        boolean[] visited = new boolean[n];

        // Create adjacency list
        for(int[] arr : connections){
            adj.get(arr[0]).add(arr[1]);   // original direction (u -> v)
            adj.get(arr[1]).add(-arr[0]);  // reverse direction stored as negative
        }

        return dfs(adj, visited, 0);
    }
}
