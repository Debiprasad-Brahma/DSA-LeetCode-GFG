# 🔗 LeetCode 1971 — Find if Path Exists in Graph

### 🧠 Intuition
We are given an **undirected graph** and need to determine whether a **path exists** between two nodes — `source` and `destination`.  
This is a classic **graph traversal** problem that can be solved using **Depth First Search (DFS)** or **Breadth First Search (BFS)**.  

By performing a DFS starting from the `source` node, we can mark all reachable nodes as **visited**.  
If after traversal the `destination` node is marked visited, a valid path exists.

---

### 💡 Approach
1. Convert the given `edges` list into an **adjacency list** representation for efficient traversal.  
2. Use a **recursive DFS** to explore all reachable nodes starting from `source`.  
3. Maintain a `visited` array to prevent revisiting nodes.  
4. After DFS, if `destination` is marked as visited, return `true`; otherwise, return `false`.

---

### ⏱️ Complexity
- **Time Complexity:** `O(V + E)`  
  Each vertex and edge is visited once during DFS.
- **Space Complexity:** `O(V + E)`  
  For the adjacency list and recursion stack.

---

### ✅ Code
```java
class Solution {

    void dfs(List<List<Integer>> adj, boolean[] visited, int node) {
        visited[node] = true;

        for (int neighbour : adj.get(node)) {
            if (!visited[neighbour]) {
                dfs(adj, visited, neighbour);
            }
        }
    }

    public boolean validPath(int n, int[][] edges, int source, int destination) {
        List<List<Integer>> adj = new ArrayList<>();

        // Convert edge list to adjacency list
        for (int i = 0; i < n; i++) {
            adj.add(new ArrayList<>());
        }
        for (int[] arr : edges) {
            adj.get(arr[0]).add(arr[1]);
            adj.get(arr[1]).add(arr[0]);
        }

        boolean[] visited = new boolean[n];
        dfs(adj, visited, source);

        // Check if destination is reachable
        return visited[destination];
    }
}
